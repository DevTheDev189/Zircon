Ayuda y Base de Conocimientos

Preguntas Frecuentes

Todo lo que necesitas saber sobre Zircon Launcher, Gestor de Servidores, sincronización de mods y seguridad.

¿Cómo sincroniza automáticamente Zircon los mods de Minecraft?

Cuando seleccionas un servidor y pulsas JUGAR, el Zircon Launcher se conecta al servidor y recupera su manifiesto criptográfico de mods (BOM). Compara esto con tu carpeta de instancia local, verifica los hashes SHA-512 y las huellas digitales de CurseForge contra los repositorios oficiales, y descarga automáticamente cualquier mod faltante o actualizado.

¿Puedo usar CurseForge o Modrinth para encontrar y descargar mods?

¡Sí! Zircon soporta nativamente tanto Modrinth como CurseForge sin necesidad de claves API. Ya sea configurando una instancia en el Gestor de Servidores o jugando en un servidor, los mods de ambos repositorios se gestionan sin problemas con verificación automática de hashes.

¿Puedo crear instancias offline de un solo jugador?

Sí. El launcher incluye un gestor completo de instancias offline. Puedes crear instancias locales de un solo jugador eligiendo la versión de Minecraft (desde 1.16 hasta la más reciente), el cargador de mods (Fabric, Quilt, Forge, NeoForge), asignación personalizada de RAM y mods locales.

¿Cómo funcionan el Personalizador de Skins y la Biblioteca de Skins Comunitarias?

El selector de skins te permite elegir entre skins guardadas o subir un PNG personalizado, previsualizar tu personaje en 3D rotativo en vivo (con opciones de geometría Steve y Alex) y sincronizar directamente con Mojang. Además, la Biblioteca de Skins Comunitarias te permite explorar miles de skins populares de la comunidad obtenidas en tiempo real vía API y aplicarlas con un clic.

¿Cómo funciona la multiplexación de puerto único?

Zircon Server Manager multiplexa tanto el tráfico estándar del juego de Minecraft (puerto 25565) como el tráfico HTTP REST del manifiesto de mods en el mismo puerto único. Los jugadores simplemente introducen la dirección de tu servidor una vez (ej. play.example.com) y el launcher obtiene el manifiesto de mods y conecta el juego a través del puerto 25565 sin requerir puertos secundarios.

¿Cómo accedo al Panel Web de Administración?

Al iniciar el gestor de servidores, se genera una contraseña de administrador que se imprime en tu consola. Abre tu navegador y navega a http://localhost:25564 (o tu IP privada) para iniciar sesión. Por seguridad, mantén el puerto 25564 local o detrás de una VPN/proxy inverso.

¿Cómo funciona el modo de suspensión/reanudación del servidor?

Cuando todos los jugadores abandonan el servidor, Zircon pausa elegantemente el proceso del servidor de Minecraft para conservar CPU y RAM. Cuando cualquier jugador pulsa JUGAR en su launcher, una intención de unión previa despierta el servidor antes de que el jugador entre en el juego.

¿Necesito una clave API para Modrinth o CurseForge?

No. El soporte para Modrinth y CurseForge está preconfigurado e integrado directamente en Zircon. Los propietarios de servidores y los jugadores pueden buscar, descargar y sincronizar mods desde ambas plataformas inmediatamente sin necesidad de claves API ni configuración manual.

¿Habrá alojamiento cloud gestionado (Zircon Cloud)?

Sí, el alojamiento gestionado sin hardware propio con retención propietaria 'Pause-to-Sleep' está planificado en nuestra hoja de ruta futura. Hoy en día, Zircon Launcher y el Gestor de Servidores autoalojado son 100% gratuitos, de código abierto disponible y listos para que los ejecutes en tu propio PC, homelab o VPS a coste cero.

¿Está segura mi cuenta de Microsoft Minecraft?

Sí. La autenticación se realiza mediante OAuth 2.0 PKCE estándar de Microsoft en tu navegador web del sistema. Tus credenciales se envían directamente a los servidores de inicio de sesión de Microsoft. Zircon nunca ve, gestiona ni almacena tu contraseña de Microsoft.

¿Es Zircon gratuito y de código abierto?

Sí, Zircon es gratuito y de código fuente disponible bajo la Business Source License 1.1 (BSL 1.1). Todo el código base (launcher complementario y gestor de servidores autoalojado) está disponible para inspección pública, auditoría y despliegue personal/comunitario en GitHub.

¿Se verifican los mods descargados por seguridad?

Sí. Los archivos de mods se verifican utilizando hashes criptográficos SHA-512 y huellas murmur2 de CurseForge contra las APIs oficiales de Modrinth y CurseForge antes de ser colocados en tu carpeta de instancia activa.

Windows SmartScreen dice "Windows protegió tu PC" — ¿qué debo hacer?

Esto es estándar para nuevo software de código abierto que aún no ha construido reputación de certificado en Microsoft SmartScreen. Haz clic en Más información y luego haz clic en Ejecutar de todas formas. También puedes inspeccionar el código fuente completo en GitHub por transparencia.

¿Necesito instalar Java manualmente?

No. Zircon detecta automáticamente tu Java del sistema y, si falta una versión requerida (ej. Java 17 o Java 21), descarga y almacena en caché automáticamente el JDK Eclipse Temurin verificado desde Adoptium.

¿Cómo asigno más RAM a Minecraft con mods?

En el Zircon Launcher, haz clic en el icono de Ajustes en la barra lateral. Usa el control deslizante de asignación de memoria para ajustar la RAM asignada (se recomiendan 4 GB a 8 GB para modpacks medianos a grandes).
