Arquitetura & Funcionalidades

Engenharia para Multiplayer Sem Falhas

Tudo o necessário para executar uma comunidade modificada de alto desempenho sem competências de administração de sistemas Linux.

Retenção Pause-to-Sleep

Os hosts tradicionais desperdiçam dinheiro ao manter mundos vazios ativos 24/7. O Zircon Cloud suspende o ciclo de jogo quando há 0 jogadores online, retomando suavemente na conexão do jogador com 100% dos dados de chunk intactos.

Diagnóstico de Crash Zirky AI

Impulsionado pelo DeepSeek-V4-Flash. Quando um servidor falha devido a um mod incompatível ou biblioteca em falta, o Zirky analisa o stack trace e gera um cartão de remediação de 1 clique diretamente na sua consola.

Modrinth & CurseForge no Navegador

Pesquise e instale mais de 100.000 mods, modpacks, shaders e pacotes de recursos diretamente no seu painel de controlo web. Sem transferências manuais via FTP ou caça a JARs.

Scrubbing DDoS Enterprise na Edge

Todo o tráfego Minecraft e telemetria web são roteados através de nós redundantes de scrubbing na edge, filtrando ataques volumétricos e pacotes maliciosos antes de chegarem ao container do seu mundo.

Multiplexação de Porta Única

O gameplay do Minecraft (porta 25565) e a API REST manifest partilham exatamente a mesma porta. Os jogadores conectam-se a domínios limpos como yourserver.zirconmc.net sem necessidade de números de porta.

Snapshots LZ4 Cloud Automatizados

Backups de mundo comprimidos LZ4 de alta velocidade executam-se conforme agendado, sem travamentos no jogo. Restaure checkpoints anteriores com um único clique em caso de desastre.

FAQ Zircon Cloud

Perguntas frequentes sobre a hospedagem gerida Zircon.

Como funciona a retenção Pause-to-Sleep?

Quando o último jogador se desconecta do seu servidor, o Zircon Cloud inicia uma contagem regressiva graciosa de 15 minutos de inatividade. Se nenhum jogador entrar, o container do jogo é suspenso (Pause-to-Sleep). Todo o estado dos chunks, entidades e inventários são descarregados e salvos no disco. Quando um jogador clica em PLAY no Zircon Launcher, o nosso proxy edge acorda a instância sem falhas para os seus jogadores.

Os meus amigos têm de pagar algo para se conectar?

Não. Conectar-se a um servidor Zircon Cloud usando o Zircon Launcher é 100% gratuito para sempre. Os jogadores baixam o launcher cliente, fazem login com a sua conta oficial Microsoft e clicam em entrar.

Posso fazer upload do meu mundo ou modpack existente?

Sim! O Zircon Cloud possui um gestor de ficheiros web integrado e uploader de zip. Pode inserir um save de mundo existente, importar um modpack zip CurseForge/Modrinth, ou migrar diretamente de um servidor local self-hosted Zircon com 1 clique.

Quais loaders e versões do Minecraft são suportados?

O Zircon Cloud suporta Fabric, Quilt, NeoForge e Forge desde o Minecraft 1.7 até às últimas releases modernas. Instâncias Clean Vanilla e Paper/Purpur também são totalmente suportadas.
