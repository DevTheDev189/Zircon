سوالات متداول

همه آنچه باید درباره Zircon Launcher، مدیریت سرور، همگام‌سازی مادها و امنیت بدانید.

Zircon چگونه به صورت خودکار مادهای Minecraft را همگام‌سازی می‌کند؟

وقتی یک سرور را انتخاب کرده و روی PLAY کلیک می‌کنید، Zircon Launcher به سرور متصل شده و مانیفست رمزنگاری‌شده مادها (BOM) آن را دریافت می‌کند. سپس این مانیفست را با پوشه نمونه محلی شما مقایسه کرده، هش‌های SHA-512 و اثر انگشت‌های CurseForge را با مخازن رسمی بررسی می‌کند و هرگونه ماد غایب یا به‌روزشده را به صورت خودکار دانلود می‌کند.

آیا می‌توانم از CurseForge یا Modrinth برای یافتن و دانلود مادها استفاده کنم؟

بله! Zircon به صورت بومی از هر دو Modrinth و CurseForge بدون نیاز به هیچ کلید API پشتیبانی می‌کند. چه در حال پیکربندی نمونه در مدیریت سرور باشید و چه در حال بازی روی سرور، مادها از هر دو مخزن به صورت یکپارچه و با تأیید خودکار هش مدیریت می‌شوند.

آیا می‌توانم نمونه‌های تک‌نفره آفلاین ایجاد کنم؟

بله. لانچر شامل یک مدیر نمونه کامل آفلاین است. شما می‌توانید نمونه‌های تک‌نفره محلی با انتخاب نسخه Minecraft (از 1.16 تا آخرین نسخه)، بارگذار ماد (Fabric, Quilt, Forge, NeoForge)، تخصیص RAM سفارشی و مادهای محلی ایجاد کنید.

Skin Customizer و کتابخانه اسکین‌های انجمن چگونه کار می‌کنند؟

انتخابگر اسکین به شما امکان می‌دهد از بین اسکین‌های ذخیره‌شده انتخاب کنید یا یک فایل PNG سفارشی آپلود نمایید، شخصیت خود را در پیش‌نمایش سه بعدی چرخان زنده (با گزینه‌های هندسی Steve و Alex) ببینید و مستقیماً با Mojang همگام‌سازی کنید. علاوه بر این، کتابخانه اسکین‌های انجمن به شما اجازه می‌دهد هزاران اسکین ترند انجمن را که به صورت زنده از طریق API دریافت می‌شوند مرور کرده و با یک کلیک اعمال کنید.

تکثیر پورت یکتا (Single-port multiplexing) چگونه کار می‌کند؟

Zircon Server Manager ترافیک استاندارد بازی Minecraft (پورت 25565) و ترافیک HTTP REST مانیفست مادها را روی همان پورت واحد تکثیر می‌کند. بازیکنان تنها کافی است آدرس سرور شما را یک بار وارد کنند (مثلاً play.example.com) و لانچر مانیفست مادها را دریافت کرده و اتصال بازی را روی پورت 25565 بدون نیاز به پورت‌های ثانویه برقرار می‌کند.

چگونه به داشبورد وب ادمین دسترسی پیدا کنم؟

وقتی مدیریت سرور را شروع می‌کنید، یک رمز عبور ادمین تولید شده و در کنسول شما چاپ می‌شود. مرورگر خود را باز کنید و به http://localhost:25564 (یا IP خصوصی خود) بروید تا وارد شوید. برای امنیت، پورت 25564 را محلی نگه دارید یا پشت یک VPN/پروکسی معکوس قرار دهید.

حالت خواب/بیداری سرور چگونه کار می‌کند؟

وقتی همه بازیکنان از سرور خارج شوند، Zircon فرآیند سرور Minecraft را به آرامی متوقف می‌کند تا CPU و RAM صرفه‌جویی شود. وقتی هر بازیکن روی PLAY در لانچر خود کلیک کند، یک نیت پیش‌از‌پیوستن سرور را قبل از ورود بازیکن به بازی بیدار می‌کند.

آیا برای Modrinth یا CurseForge به کلید API نیاز دارم؟

خیر. پشتیبانی از هر دو Modrinth و CurseForge از پیش پیکربندی شده و مستقیماً در Zircon جاسازی شده است. مالکان سرور و بازیکنان می‌توانند بلافاصله مادها را از هر دو پلتفرم جستجو، دانلود و همگام‌سازی کنند بدون اینکه نیازی به کلید API یا تنظیمات دستی باشد.

آیا میزبانی ابری مدیریت‌شده (Zircon Cloud) خواهد بود؟

بله، میزبانی مدیریت‌شده بدون سخت‌افزار با نگهداری اختصاصی Pause-to-Sleep در نقشه راه آینده ما برنامه‌ریزی شده است. امروزه، Zircon Launcher و مدیریت سرور خودمیزبان ۱۰۰٪ رایگان، منبع‌باز و آماده اجرا روی PC شخصی، Homelab یا VPS شما بدون هیچ هزینه‌ای هستند.

آیا حساب Microsoft Minecraft من امن است؟

بله. احراز هویت از طریق استاندارد Microsoft OAuth 2.0 PKCE در مرورگر وب سیستم شما انجام می‌شود. اعتبارنامه‌های شما مستقیماً به سرورهای ورود Microsoft ارسال می‌شوند. Zircon هرگز رمز عبور Microsoft شما را نمی‌بیند، پردازش نمی‌کند یا ذخیره نمی‌کند.

آیا Zircon رایگان و متن‌باز است؟

بله، Zircon تحت مجوز Business Source License 1.1 (BSL 1.1) رایگان و منبع‌باز است. کل کدبیس (لانچر همراه و مدیریت سرور خودمیزبان) برای بازرسی عمومی، ممیزی و استقرار شخصی/انجمنی در GitHub در دسترس است.

آیا مادهای دانلودشده برای ایمنی تأیید می‌شوند؟

بله. فایل‌های ماد با استفاده از هش‌های رمزنگاری SHA-512 و اثر انگشت‌های murmur2 CurseForge در برابر APIهای رسمی Modrinth و CurseForge تأیید می‌شوند قبل از اینکه هرگز در پوشه نمونه فعال شما قرار گیرند.

Windows SmartScreen پیام "Windows protected your PC" را نشان می‌دهد — چه کاری باید انجام دهم؟

این امر برای نرم‌افزارهای متن‌باز جدید که هنوز اعتبار گواهی Microsoft SmartScreen را کسب نکرده‌اند، استاندارد است. روی More info کلیک کنید و سپس روی Run anyway کلیک نمایید. همچنین می‌توانید برای شفافیت، کد منبع کامل را در GitHub بررسی کنید.

آیا باید Java را به صورت دستی نصب کنم؟

خیر. Zircon به صورت خودکار Java سیستم شما را شناسایی می‌کند و اگر نسخه مورد نیاز (مثلاً Java 17 یا Java 21) غایب باشد، JDK Eclipse Temurin تأییدشده را از Adoptium به صورت خودکار دانلود و کش می‌کند.

چگونه RAM بیشتری به Minecraft ماددار اختصاص دهم؟

در Zircon Launcher، روی آیکون Settings در نوار کناری کلیک کنید. از اسلایدر تخصیص حافظه برای تنظیم RAM تخصیص‌یافته استفاده کنید (۴ گیگابایت تا ۸ گیگابایت برای مادپک‌های متوسط تا بزرگ توصیه می‌شود).
