Port Unique & Multi-Serveur

Le trafic jeu (25565) et les manifestes web fonctionnent sur le même port unique. Hébergez et gérez plusieurs serveurs ou modpacks depuis un tableau de bord centralisé via navigateur.

Veille quand vide (Économise la RAM)

Quand personne n'est en ligne, le serveur gèle l'exécution JVM pour économiser le CPU et la RAM de l'hôte. Quand un joueur pingue ou clique sur PLAY dans Zircon, il redémarre automatiquement en quelques millisecondes.

Comment fonctionne le Multiplexage de Ports

Les serveurs traditionnels nécessitent des ports séparés pour le jeu, les manifestes web et les consoles admin. Zircon le fait sur le port 25565.

# 1. Démarrer le Gestionnaire de Serveur Zircon ./zircon-server --port 25565 --admin-port 25564 # Adresse Publique : 25565 (sert le protocole Minecraft + manifestes de mods REST) # Panneau Admin Local : http://localhost:25564 (tableau de bord sécurisé avec mot de passe généré)
Sécurité par conception : Le tableau de bord admin (25564) reste local ou derrière votre VPN/proxy inverse. Seul le port Minecraft multiplexé (25565) doit être ouvert vers vos joueurs.
