Aide & Base de connaissances

Questions Fréquentes

Tout ce que vous devez savoir sur Zircon Launcher, le Gestionnaire de serveur, la synchronisation des mods et la sécurité.

Comment Zircon synchronise-t-il automatiquement les mods Minecraft ?

Lorsque vous choisissez un serveur et cliquez sur JOUER, le Zircon Launcher se connecte au serveur et récupère son manifeste cryptographique de mods (BOM). Il compare ce dernier avec votre dossier d'instance local, vérifie les empreintes SHA-512 et CurseForge par rapport aux dépôts officiels, et télécharge automatiquement tous les mods manquants ou mis à jour.

Puis-je utiliser CurseForge ou Modrinth pour trouver et télécharger des mods ?

Oui ! Zircon prend nativement en charge Modrinth et CurseForge sans aucune clé API requise. Que vous configuriez une instance dans le Gestionnaire de serveur ou jouiez sur un serveur, les mods provenant des deux dépôts sont gérés de manière transparente avec une vérification automatique des empreintes.

Puis-je créer des instances hors ligne solo ?

Oui. Le launcher inclut un gestionnaire complet d'instances hors ligne. Vous pouvez créer des instances locales solo avec choix de la version de Minecraft (de 1.16 à la dernière), du chargeur de mods (Fabric, Quilt, Forge, NeoForge), de l'allocation de RAM personnalisée et de mods locaux.

Comment fonctionnent le Personnalisateur de Skins et la Bibliothèque de Skins Communautaire ?

Le sélecteur de skins vous permet de choisir parmi les skins enregistrés ou de télécharger un PNG personnalisé, de prévisualiser votre personnage en 3D rotative en direct (avec options de géométrie Steve et Alex) et de synchroniser directement avec Mojang. De plus, la Bibliothèque de Skins Communautaire vous permet de parcourir des milliers de skins tendance de la communauté récupérés en direct via API et de les appliquer en un clic.

Comment fonctionne le multiplexage sur port unique ?

Zircon Server Manager multiplexe le trafic de jeu Minecraft standard (port 25565) et le trafic HTTP REST du manifeste de mods sur le même port unique. Les joueurs entrent simplement l'adresse de votre serveur une seule fois (par ex. play.example.com) et le launcher récupère le manifeste de mods et établit la connexion au jeu sur le port 25565 sans nécessiter de ports secondaires.

Comment accéder au Tableau de bord Web Admin ?

Lorsque vous démarrez le gestionnaire de serveur, un mot de passe admin est généré et affiché dans votre console. Ouvrez votre navigateur et accédez à http://localhost:25564 (ou votre IP privée) pour vous connecter. Pour des raisons de sécurité, gardez le port 25564 local ou derrière un VPN/proxy inverse.

Comment fonctionne le mode veille/réveil du serveur ?

Lorsque tous les joueurs quittent le serveur, Zircon met gracieusement en pause le processus du serveur Minecraft pour économiser le CPU et la RAM. Lorsqu'un joueur clique sur JOUER dans son launcher, une intention de pré-rejoindre réveille le serveur avant que le joueur n'entre en jeu.

Ai-je besoin d'une clé API pour Modrinth ou CurseForge ?

Non. La prise en charge de Modrinth et CurseForge est pré-configurée et intégrée directement dans Zircon. Les propriétaires de serveurs et les joueurs peuvent rechercher, télécharger et synchroniser des mods depuis les deux plateformes immédiatement, sans aucune clé API ni configuration manuelle requise.

Y aura-t-il un hébergement cloud géré (Zircon Cloud) ?

Oui, un hébergement géré sans matériel avec rétention propriétaire Pause-to-Sleep est prévu sur notre feuille de route future. Aujourd'hui, Zircon Launcher et le Gestionnaire de serveur auto-hébergé sont 100 % gratuits, source-available et prêts à être exécutés sur votre propre PC, homelab ou VPS à coût zéro.

Mon compte Microsoft Minecraft est-il sécurisé ?

Oui. L'authentification est effectuée via le standard Microsoft OAuth 2.0 PKCE dans votre navigateur web système. Vos identifiants sont soumis directement aux serveurs de connexion Microsoft. Zircon ne voit, ne manipule et ne stocke jamais votre mot de passe Microsoft.

Zircon est-il gratuit et open source ?

Oui, Zircon est gratuit et source-available sous la Business Source License 1.1 (BSL 1.1). L'intégralité du code base (launcher compagnon et gestionnaire de serveur auto-hébergé) est disponible pour inspection publique, audit et déploiement personnel/communautaire sur GitHub.

Les mods téléchargés sont-ils vérifiés pour la sécurité ?

Oui. Les fichiers de mods sont vérifiés à l'aide d'empreintes cryptographiques SHA-512 et d'empreintes murmur2 CurseForge par rapport aux API officielles Modrinth et CurseForge avant d'être placés dans votre dossier d'instance actif.

Windows SmartScreen indique « Windows a protégé votre PC » — que dois-je faire ?

C'est standard pour les nouveaux logiciels open source qui n'ont pas encore établi la réputation de certificat Microsoft SmartScreen. Cliquez sur Plus d'infos puis sur Exécuter quand même. Vous pouvez également inspecter le code source complet sur GitHub pour plus de transparence.

Dois-je installer Java manuellement ?

Non. Zircon détecte automatiquement le Java de votre système, et si une version requise (par ex. Java 17 ou Java 21) est manquante, il télécharge et met en cache automatiquement le JDK Eclipse Temurin vérifié depuis Adoptium.

Comment allouer plus de RAM à Minecraft moddé ?

Dans le Zircon Launcher, cliquez sur l'icône Paramètres dans la barre latérale. Utilisez le curseur d'allocation mémoire pour ajuster la RAM allouée (4 Go à 8 Go sont recommandés pour les modpacks moyens à grands).
