Συχνές Ερωτήσεις

Όλα όσα χρειάζεται να γνωρίζετε για το Zircon Launcher, το Server Manager, τον συγχρονισμό mods και την ασφάλεια.

Πώς συγχρονίζει αυτόματα το Zircon τα Minecraft mods;

Όταν επιλέγετε έναν server και πατάτε PLAY, το Zircon Launcher συνδέεται στον server και ανακτά το κρυπτογραφικό manifest των mods (BOM). Το συγκρίνει με τον τοπικό φάκελο της instance σας, επαληθεύει τα hashes SHA-512 και τα fingerprints του CurseForge εναντίον των επίσημων repositories, και κατεβάζει αυτόματα οποιοδήποτε λείπον ή ενημερωμένο mod.

Μπορώ να χρησιμοποιήσω το CurseForge ή το Modrinth για να βρω και να κατεβάσω mods;

Ναι! Το Zircon υποστηρίζει εγγενώς τόσο το Modrinth όσο και το CurseForge χωρίς να απαιτούνται API keys. Είτε ρυθμίζετε μια instance στο Server Manager είτε παίζετε σε έναν server, τα mods και από τα δύο repositories διαχειρίζονται απρόσκοπτα με αυτόματη επαλήθευση hash.

Μπορώ να δημιουργήσω offline instances για single-player;

Ναι. Ο launcher περιλαμβάνει πλήρη διαχειριστή offline instances. Μπορείτε να δημιουργήσετε τοπικές instances για single-player με επιλογή έκδοσης Minecraft (από 1.16 έως την πιο πρόσφατη), loader mods (Fabric, Quilt, Forge, NeoForge), προσαρμοσμένη κατανομή RAM και τοπικά mods.

Πώς λειτουργούν ο Skin Customizer και η Community Skin Library;

Ο επιλογέας skin σας επιτρέπει να επιλέξετε από αποθηκευμένα skins ή να ανεβάσετε ένα προσαρμοσμένο PNG, να κάνετε προεπισκόπηση του χαρακτήρα σας σε ζωντανό περιστρεφόμενο 3D (με επιλογές γεωμετρίας Steve και Alex) και να συγχρονιστείτε απευθείας με το Mojang. Επιπλέον, η Community Skin Library σας επιτρέπει να περιηγηθείτε σε χιλιάδες δημοφιλή community skins που λαμβάνονται ζωντανά μέσω API και να τα εφαρμόσετε με ένα κλικ.

Πώς λειτουργεί το single-port multiplexing;

Το Zircon Server Manager πολλαπλασιάζει τόσο την τυπική κίνηση παιχνιδιού Minecraft (port 25565) όσο και την κίνηση HTTP REST για το manifest των mods στην ίδια μοναδική θύρα. Οι παίκτες απλώς εισάγουν μία φορά τη διεύθυνση του server σας (π.χ. play.example.com) και ο launcher ανακτά το manifest των mods και συνδέει το παιχνίδι μέσω της θύρας 25565 χωρίς να απαιτούνται δευτερεύουσες θύρες.

Πώς αποκτώ πρόσβαση στο Admin Web Dashboard;

Όταν ξεκινάτε τον server manager, παράγεται ένας κωδικός πρόσβασης admin και εκτυπώνεται στην κονσόλα σας. Ανοίξτε το πρόγραμμα περιήγησής σας και μεταβείτε στη διεύθυνση http://localhost:25564 (ή την ιδιωτική IP σας) για σύνδεση. Για λόγους ασφαλείας, κρατήστε τη θύρα 25564 τοπική ή πίσω από ένα VPN/reverse proxy.

Πώς λειτουργεί η λειτουργία ύπνου/αφύπνισης του server;

Όταν όλοι οι παίκτες φύγουν από τον server, το Zircon σταματά κομψά τη διαδικασία του Minecraft server για εξοικονόμηση CPU και RAM. Όταν κάποιος παίκτης πατήσει PLAY στον launcher του, μια πρόθεση σύνδεσης ξυπνά τον server πριν ο παίκτης εισέλθει στο παιχνίδι.

Χρειάζομαι API key για το Modrinth ή το CurseForge;

Όχι. Η υποστήριξη τόσο για το Modrinth όσο και για το CurseForge είναι προκαθορισμένη και ενσωματωμένη απευθείας στο Zircon. Οι ιδιοκτήτες servers και οι παίκτες μπορούν να αναζητήσουν, να κατεβάσουν και να συγχρονίσουν mods και από τις δύο πλατφόρμες άμεσα, χωρίς να απαιτούνται API keys ή χειροκίνητη ρύθμιση.

Θα υπάρχει διαχειριζόμενη φιλοξενία cloud (Zircon Cloud);

Ναι, η διαχειριζόμενη φιλοξενία zero-hardware με ιδιόκτητη διατήρηση Pause-to-Sleep σχεδιάζεται στο μελλοντικό μας roadmap. Σήμερα, το Zircon Launcher και το self-hosted Server Manager είναι 100% δωρεάν, διαθέσιμα ως πηγαίος κώδικας και έτοιμα για εσάς να τρέξετε στον δικό σας PC, homelab ή VPS χωρίς κόστος.

Είναι ασφαλής ο λογαριασμός μου Microsoft Minecraft;

Ναι. Η αυθεντικοποίηση εκτελείται μέσω του τυπικού Microsoft OAuth 2.0 PKCE στο πρόγραμμα περιήγησης ιστού του συστήματός σας. Τα διαπιστευτήριά σας υποβάλλονται απευθείας στους διακομιστές σύνδεσης της Microsoft. Το Zircon δεν βλέπει, δεν διαχειρίζεται και δεν αποθηκεύει ποτέ τον κωδικό πρόσβασης Microsoft σας.

Είναι το Zircon δωρεάν και open source;

Ναι, το Zircon είναι δωρεάν και διαθέσιμο ως πηγαίος κώδικας υπό την Business Source License 1.1 (BSL 1.1). Όλος ο κώδικας (συνοδευτικός launcher και self-hosted server manager) είναι διαθέσιμος για δημόσια επιθεώρηση, έλεγχο και προσωπική/κοινοτική ανάπτυξη στο GitHub.

Επαληθεύονται τα mods που κατεβάζονται για ασφάλεια;

Ναι. Τα αρχεία των mods επαληθεύονται χρησιμοποιώντας κρυπτογραφικά hashes SHA-512 και murmur2 fingerprints του CurseForge εναντίον των επίσημων APIs του Modrinth και του CurseForge πριν τοποθετηθούν ποτέ στον ενεργό φάκελο της instance σας.

Το Windows SmartScreen λέει "Τα Windows προστάτευσαν τον υπολογιστή σας" — τι πρέπει να κάνω;

Αυτό είναι σύνηθες για νέο λογισμικό open-source που δεν έχει ακόμη χτίσει φήμη πιστοποιητικού στο Microsoft SmartScreen. Κάντε κλικ στο Περισσότερες πληροφορίες και μετά κάντε κλικ στο Εκτέλεση οπωσδήποτε. Μπορείτε επίσης να επιθεωρήσετε τον πλήρη πηγαίο κώδικα στο GitHub για διαφάνεια.

Πρέπει να εγκαταστήσω την Java χειροκίνητα;

Όχι. Το Zircon εντοπίζει αυτόματα την Java του συστήματός σας και, αν λείπει μια απαιτούμενη έκδοση (π.χ. Java 17 ή Java 21), κατεβάζει και προσωρινεύει αυτόματα την επαληθευμένη Eclipse Temurin JDK από το Adoptium.

Πώς δεσμεύω περισσότερη RAM για το modded Minecraft;

Στον Zircon Launcher, κάντε κλικ στο εικονίδιο Ρυθμίσεις στην πλευρική μπάρα. Χρησιμοποιήστε τον ολισθητή κατανομής μνήμης για να προσαρμόσετε τη δεσμευμένη RAM (συνιστώνται 4 GB έως 8 GB για μεσαία έως μεγάλα modpacks).

Έχετε ακόμα ερωτήσεις;

Δείτε τους οδηγούς τεκμηρίωσης βήμα προς βήμα ή ενωθείτε με την κοινότητα open-source στο GitHub.
