Ο Τρόπος Zircon: 1-Click & Play

  • ✓ Μηδενικό ψάξιμο αρχείων — Ο φίλος σας σας δίνει μια διεύθυνση server ή πρόσκληση LAN.
  • ✓ Ένα κλικ — Πατήστε PLAY. Το Zircon ελέγχει τη λίστα mods του server και επαληθεύει κάθε αρχείο ξεχωριστά.
  • ✓ Αυτόματη γρήγορη λήψη — Τα απόντα mods, configs και textures κατεβαίνουν από Modrinth & CurseForge σε δευτερόλεπτα.
  • ✓ Μέσα στο παιχνίδι σε δευτερόλεπτα — Εμφανίζεστε μαζί αμέσως. Χωρίς μεταφορά φακέλων mods.

1. Κρυπτογραφικό Manifest

Ο server μεταδίδει την ακριβή Bill of Materials (BOM) του μέσω της θύρας 25565 — IDs mods, hashes εκδόσεων, loader και configs.

2. Άμεσος Έλεγχος Hash

Ο launcher σκανάρει την τοπική σας εγκατάσταση σε χιλιοστά του δευτερολέπτου, παρακάμπτοντας αρχεία που ήδη έχετε και επισημαίνοντας μόνο όσα λείπουν.

3. Παράλληλη Επαληθευμένη Απόκτηση

Τα απόντα αρχεία κατεβαίνουν παράλληλα απευθείας από τα CDN των Modrinth και CurseForge. Μηδέν κατεστραμμένα JARs, μηδέν ασυμφωνίες εκδόσεων.

Κρυπτογραφικός Συγχρονισμός & Μηχανή Επαλήθευσης Mods

Μην εγκαταλείψετε τους κόσμους, τα keybinds ή τις εγκαταστάσεις modpack σας. Το Zircon εντοπίζει αυτόματα τους εγκατεστημένους launchers και τους μεταφέρει χωρίς απώλειες σε λιγότερο από 2 δευτερόλεπτα.

CurseForge

Ανιχνεύει αυτόματα modpacks, overrides, custom configs & world saves.

Prism Launcher

Εισάγει δενδρικές δομές instances, JVM arguments και world saves.

Modrinth App

Διατηρεί MR packs, index files και custom resource packs.

ATLauncher

Μεταφέρει instances, custom backups & φακέλους texture pack.

Μηδενική απώλεια δεδομένων. Μηδενική χειροκίνητη μεταφορά αρχείων.

Όταν εκκινείτε το Zircon, ο εγγενής ανιχνευτής Rust μας εντοπίζει τα εγκατεστημένα profiles στο σύστημά σας. Επιλέξτε ποια instances θέλετε να εισάγετε και το Zircon μεταναστεύει τα πάντα σε καθαρές, απομονωμένες sandbox περιοχές.

  • 100% Τοπικός Ανίχνευση Εκτός Σύνδεσης: Σκανάρει τυπικούς φακέλους δίσκου χωρίς εξωτερικές μεταφορές στο cloud.
  • Πλήρης Διατήρηση Instance: Διατηρεί ακριβώς τα keybinds, options.txt, resource packs και worlds σας άθικτα.
  • Άμεση Γρήγορη Εκκίνηση: Ρυθμίζει αυτόματα συμβατές εκδόσεις Java και βέλτιστες σημαίες μνήμης.

Client-Side Server Tweaks

Προσθέστε τα δικά σας προαιρετικά client mods, shaders, resource packs και keybindings σε οποιοδήποτε instance server χωρίς να χαλάσετε τον συγχρονισμό.

Διαχειριστείτε πολλούς servers, εξοικονομήστε RAM όσο κοιμάστε και τρέξτε σε μία μόνο θύρα.

Η μηχανή διαχείρισης self-hosted πίσω από το Zircon. Όχι πονοκέφαλοι με Docker, όχι εφιάλτης firewall με πολλές θύρες. Τρέξτε modded servers στους οποίους οι παίκτες σας μπορούν πραγματικά να συνδεθούν χωρίς τεχνική υποστήριξη.

  • Single-Port Multiplexing (25565): Τα game packets και τα REST mod manifests τρέχουν και τα δύο στην προεπιλεγμένη θύρα 25565. Μόνο 1 θύρα για προώθηση.
  • Sleep-When-Empty (RAM Saver): Παγώνει τη μνήμη JVM σε 0% CPU όταν υπάρχουν 0 παίκτες online; αναβιώνει σε χιλιοστά του δευτερολέπτου όταν ένας παίκτης κάνει ping.
  • Ενσωματωμένο Mod Store: Εγκαταστήστε mods, shaders και resource packs με 1 κλικ απευθείας από Modrinth και CurseForge.
  • Ζωντανή Console & Διαχείριση Παικτών: Χρωματισμένα terminal logs, άμεση αποστολή εντολών, οπτικές whitelists, OPs και bans.
  • Auto-Backups & Εισαγωγή World ZIP: Υψηλής ταχύτητας LZ4 snapshots με custom retention, rollback με 1 κλικ και εισαγωγή κόσμου με drag-and-drop.
  • Ζωντανός 2D/3D Χάρτης Κόσμου: Εξερευνήστε αποδοσμένο terrain, biomes και ζωντανές τοποθεσίες παικτών απευθείας στον browser σας.

Συχνές Ερωτήσεις

Όλα όσα χρειάζεται να γνωρίζετε για να ξεκινήσετε με το Zircon.

Πώς συγχρονίζει αυτόματα το Zircon τα mods του Minecraft;

Όταν συνδέεστε σε έναν server και πατάτε PLAY, το Zircon συγκρίνει το δημοσιευμένο manifest Bill of Materials του server με τον τοπικό σας φάκελο client. Οποιαδήποτε απόντα ή ενημερωμένα mods επαληθεύονται μέσω hashes SHA-512 και fingerprints από Modrinth & CurseForge και κατεβαίνουν αμέσως παράλληλα χωρίς χειροκίνητη μεταφορά αρχείων.

Μπορώ να μεταναστεύσω τα instances μου από CurseForge, Prism ή Modrinth;

Ναι! Το Zircon περιλαμβάνει ένα εγγενές εργαλείο Καθολικής Μετανάστευσης με 1 κλικ. Εντοπίζει αυτόματα εγκατεστημένους φακέλους από CurseForge, Prism Launcher, Modrinth App και ATLauncher, επιτρέποντάς σας να εισάγετε τις πλήρεις δενδρικές δομές instances, saves, keybinds και ρυθμίσεις mods σε λιγότερο από δύο δευτερόλεπτα.

Πώς λειτουργεί το Συν-παιχνίδι Split-Screen για 4 Παίκτες στον Καναπέ;

Το Zircon σας επιτρέπει να συνδέσετε έως 4 gamepads (Xbox, PlayStation ή γενικά Bluetooth controllers) και να εκκινήσετε πολλά απομονωμένα παράθυρα παιχνιδιού διατεταγμένα σε ένα seamless split-screen grid στην οθόνη ή την τηλεόρασή σας. Κάθε παίκτης ελέγχει τον δικό του χαρακτήρα με το δικό του gamepad.

Μπορώ να χρησιμοποιήσω CurseForge και Modrinth για να βρω και να κατεβάσω mods;

Ναι! Το Zircon υποστηρίζει εγγενώς αναζήτηση, εγκατάσταση και συγχρονισμό mods απευθείας από τόσο Modrinth όσο και CurseForge χωρίς ανάγκη ρύθμισης API key. Και τα δύο repositories είναι πλήρως ενσωματωμένα out of the box.

Είναι το Zircon δωρεάν και ανοιχτού κώδικα;

Ναι, το Zircon είναι source-available υπό την Business Source License 1.1 (BSL 1.1). Τόσο ο client launcher όσο και ο self-hosted server manager είναι 100% δωρεάν για παίκτες, homelabbers και gaming networks. Ολόκληρη η βάση κώδικα είναι ανοιχτή για δημόσια επιθεώρηση, self-hosting και συνεισφορά κοινότητας στο GitHub.

Είναι ασφαλής ο λογαριασμός μου Microsoft / Minecraft;

Ναι. Η πιστοποίηση performed μέσω standard Microsoft OAuth 2.0 PKCE στον προεπιλεγμένο browser του συστήματός σας. Τα credentials σύνδεσής σας πάνε απευθείας στους login servers της Microsoft και δεν προσπελαύνονται, δεν διαχειρίζονται και δεν αποθηκεύονται ποτέ από το Zircon.

Ποιοι mod loaders και εκδόσεις Minecraft υποστηρίζονται;

Το Zircon υποστηρίζει εγγενώς Fabric, Quilt, Forge και NeoForge. Ο launcher εγκαθιστά αυτόματα την απαιτούμενη έκδοση mod loader και επαληθευμένο Adoptium Temurin Java runtime όταν εκκινείτε ένα instance ή συνδέεστε σε έναν server.
