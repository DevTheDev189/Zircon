Διατήρηση Pause-to-Sleep

Οι παραδοσιακοί hosts σπαταλούν χρήματα τρέχοντας άδεια worlds 24/7. Το Zircon Cloud αναστέλλει το game loop όταν υπάρχουν 0 παίκτες online, επαναλαμβάνοντας ομαλά κατά τη σύνδεση παίκτη με 100% των chunk data intact.

Zirky AI Crash Διαγνωστικά

Υποστηρίζεται από το DeepSeek-V4-Flash. Όταν ένας server crashάρει λόγω ασύμβατου mod ή missing library, ο Zirky αναλύει το stack trace και δημιουργεί μια κάρτα αποκατάστασης 1-κλικ απευθείας στην κονσόλα σας.

Modrinth & CurseForge Μέσα στον Browser

Αναζητήστε και εγκαταστήστε πάνω από 100.000 mods, modpacks, shaders και resource packs απευθείας μέσα στο web control panel σας. Χωρίς χειροκίνητες FTP μεταφορές αρχείων ή ψάξιμο jar.

Enterprise DDoS Edge Scrubbing

Όλη η εισερχόμενη Minecraft κίνηση και τα web telemetry δρομολογούνται μέσω κόμβων edge scrubbing με πλεονασμό, φιλτράροντας ογκώδεις επιθέσεις και κακά packets πριν φτάσουν στο world container σας.

Single-Port Multiplexing

Η Minecraft gameplay (25565) και το REST manifest API μοιράζονται την ακριβώς ίδια θύρα. Οι παίκτες συνδέονται σε καθαρά domains όπως yourserver.zirconmc.net χωρίς να απαιτούνται αριθμοί θυρών.

Αυτοματοποιημένα LZ4 Cloud Snapshots

Γρήγορα LZ4 συμπιεσμένα backups world εκτελούνται προγραμματισμένα με μηδενικό stuttering στο παιχνίδι. Επαναφέρετε προηγούμενα checkpoints με ένα κλικ σε περίπτωση καταστροφής.

Zircon Cloud FAQ

Συχνές ερωτήσεις σχετικά με το managed Zircon hosting.

Πώς λειτουργεί η διατήρηση Pause-to-Sleep;

Όταν ο τελευταίος παίκτης αποσυνδέεται από τον server σας, το Zircon Cloud ξεκινά μια ομαλή αντίστροφη μέτρηση αδράνειας 15 λεπτών. Εάν δεν συνδεθούν παίκτες, το game container αναστέλλεται (Pause-to-Sleep). Όλη η κατάσταση chunk, entities και inventories εκκαθαρίζεται και αποθηκεύεται στον δίσκο. Όταν ένας παίκτης κάνει κλικ στο PLAY στο Zircon Launcher, ο edge proxy μας ξυπνά την instance ομαλά για τους παίκτες σας.

Πρέπει να πληρώσουν κάτι οι φίλοι μου για να συνδεθούν;

Όχι. Η σύνδεση σε έναν server Zircon Cloud χρησιμοποιώντας το Zircon Launcher είναι 100% δωρεάν για πάντα. Οι παίκτες κατεβάζουν το client launcher, συνδέονται με τον επίσημο λογαριασμό Microsoft και κάνουν κλικ στο join.

Μπορώ να ανεβάσω το υπάρχον world ή modpack μου;

Ναι! Το Zircon Cloud διαθέτει ολοκληρωμένο web file manager και zip uploader. Μπορείτε να ανεβάσετε ένα υπάρχον world save, να εισάγετε ένα modpack zip από CurseForge/Modrinth, ή να μεταναστεύσετε απευθείας από έναν τοπικό self-hosted Zircon server με 1 κλικ.

Ποιοι loaders και Minecraft versions υποστηρίζονται;

Το Zircon Cloud υποστηρίζει Fabric, Quilt, NeoForge και Forge από το Minecraft 1.7 έως τις πιο πρόσφατες σύγχρονες εκδόσεις. Καθαρές Vanilla και Paper/Purpur instances υποστηρίζονται επίσης πλήρως.
