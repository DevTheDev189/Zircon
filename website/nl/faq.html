Veelgestelde Vragen

Alles wat je moet weten over Zircon Launcher, Server Manager, mod-synchronisatie en beveiliging.

Hoe synchroniseert Zircon automatisch Minecraft mods?

Wanneer je een server kiest en op SPEEL drukt, verbindt de Zircon Launcher zich met de server en haalt het cryptografische mod-manifest (BOM) op. Het vergelijkt dit met je lokale instantie-map, verifieert SHA-512-hashes en CurseForge-fingerprints tegen officiële repositories, en downloadt ontbrekende of bijgewerkte mods automatisch.

Kan ik CurseForge of Modrinth gebruiken om mods te vinden en te downloaden?

Ja! Zircon ondersteunt zowel Modrinth als CurseForge native, zonder dat er API-keys nodig zijn. Of je nu een instantie configureert in de Server Manager of speelt op een server, mods van beide repositories worden naadloos verwerkt met automatische hash-verificatie.

Kan ik offline single-player instanties aanmaken?

Ja. De launcher bevat een volledige offline instantie-manager. Je kunt lokale single-player instanties aanmaken met keuze uit Minecraft-versie (vanaf 1.16 tot de nieuwste), mod-loader (Fabric, Quilt, Forge, NeoForge), aangepaste RAM-toewijzing en lokale mods.

Hoe werken de Skin Customizer en Community Skin Library?

Met de skin-selector kun je kiezen uit opgeslagen skins of een aangepaste PNG uploaden, je karakter bekijken in live roterende 3D (met Steve- en Alex-geometrie-opties) en direct synchroniseren met Mojang. Daarnaast kun je via de Community Skin Library duizenden trending community skins doorbladeren die live via API worden opgehaald en met één klik toepassen.

Hoe werkt single-port multiplexing?

Zircon Server Manager multiplexed zowel standaard Minecraft-gameverkeer (poort 25565) als HTTP REST mod-manifest-verkeer op dezelfde enkele poort. Spelers hoeven slechts één keer het serveradres in te voeren (bijv. play.example.com) en de launcher haalt het mod-manifest op en verbindt het spel via poort 25565 zonder secundaire poorten te vereisen.

Hoe krijg ik toegang tot het Admin Web Dashboard?

Wanneer je de server manager start, wordt een admin-wachtwoord gegenereerd en afgedrukt naar je console. Open je browser en ga naar http://localhost:25564 (of je privé-IP) om in te loggen. Voor de veiligheid houd je poort 25564 lokaal of achter een VPN/reverse proxy.

Hoe werkt de sleep/wake-modus van de server?

Wanneer alle spelers de server verlaten, pauzeert Zircon het Minecraft-serverproces netjes om CPU en RAM te besparen. Wanneer een speler op SPEEL klikt in hun launcher, wekt een pre-join intent de server wakker voordat de speler het spel betreedt.

Heb ik een API-key nodig voor Modrinth of CurseForge?

Nee. Ondersteuning voor zowel Modrinth als CurseForge is vooraf geconfigureerd en gebundeld in Zircon. Servereigenaren en spelers kunnen mods van beide platforms onmiddellijk zoeken, downloaden en synchroniseren zonder dat er API-keys of handmatige setup nodig zijn.

Komt er managed cloud hosting (Zircon Cloud)?

Ja, managed zero-hardware hosting met proprietaire Pause-to-Sleep-retentie staat gepland op onze toekomstige roadmap. Vandaag zijn Zircon Launcher en de self-hosted Server Manager 100% gratis, source-available en klaar om op je eigen PC, homelab of VPS te draaien zonder kosten.

Is mijn Microsoft Minecraft-account veilig?

Ja. Authenticatie wordt uitgevoerd via standaard Microsoft OAuth 2.0 PKCE in je systeemwebbrowser. Je inloggegevens worden rechtstreeks verzonden naar de login-servers van Microsoft. Zircon ziet, behandelt of bewaart nooit je Microsoft-wachtwoord.

Is Zircon gratis en open source?

Ja, Zircon is gratis en source-available onder de Business Source License 1.1 (BSL 1.1). De volledige codebase (companion launcher en self-hosted server manager) is beschikbaar voor publieke inspectie, auditing en persoonlijke/community-deployments op GitHub.

Worden gedownloade mods geverifieerd op veiligheid?

Ja. Mod-bestanden worden geverifieerd met behulp van SHA-512 cryptografische hashes en CurseForge murmur2-fingerprints tegen officiële Modrinth- en CurseForge-API's voordat ze ooit in je actieve instantie-map worden geplaatst.

Windows SmartScreen zegt "Windows heeft uw pc beschermd" — wat moet ik doen?

Dit is standaard voor nieuwe open-source software die nog geen reputatie heeft opgebouwd bij het Microsoft SmartScreen-certificaat. Klik op Meer informatie en klik vervolgens op Toch uitvoeren. Je kunt ook de volledige broncode op GitHub inspecteren voor transparantie.

Moet ik Java handmatig installeren?

Nee. Zircon detecteert automatisch je systeem-Java, en als een vereiste versie (bijv. Java 17 of Java 21) ontbreekt, downloadt en cached het automatisch de geverifieerde Eclipse Temurin JDK van Adoptium.

Hoe wijs ik meer RAM toe aan gemodificeerde Minecraft?

Klik in de Zircon Launcher op het Instellingen-pictogram in de zijbalk. Gebruik de geheugentoewijzingsslider om het toegewezen RAM aan te passen (4 GB tot 8 GB wordt aanbevolen voor medium-tot-large modpacks).
