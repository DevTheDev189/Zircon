Veelgestelde Vragen

Alles wat je moet weten om aan de slag te gaan met Zircon.

Hoe synchroniseert Zircon automatisch Minecraft mods?

Wanneer je een server joined en op PLAY drukt, vergelijkt Zircon de gepubliceerde Bill of Materials manifest van de server met je lokale client map. Alle ontbrekende of bijgewerkte mods worden geverifieerd via Modrinth & CurseForge SHA-512 hashes en fingerprints, en vervolgens direct parallel gedownload zonder handmatig slepen van bestanden.

Kan ik mijn instanties migreren van CurseForge, Prism, of Modrinth?

Ja! Zircon bevat een native 1-klik Universele Migratie tool. Het detecteert automatisch geïnstalleerde directories van CurseForge, Prism Launcher, Modrinth App, en ATLauncher, zodat je je volledige instance trees, saves, keybinds en mod configuraties kunt importeren in minder dan twee seconden.

Hoe werkt 4-Speler Split-Screen Couch Co-op?

Zircon stelt je in staat tot aan 4 gamepads (Xbox, PlayStation, of generieke Bluetooth controllers) aan te sluiten en meerdere geïsoleerde game windows te starten, gerangschikt in een naadloze split-screen grid op je monitor of tv. Elke speler bestuurt zijn eigen karakter met zijn eigen gamepad.

Kan ik CurseForge en Modrinth gebruiken om mods te vinden en te downloaden?

Ja! Zircon ondersteunt natively zoeken, installeren en synchroniseren van mods direct van zowel Modrinth als CurseForge zonder dat API keys nodig zijn. Beide repositories zijn volledig out-of-the-box geïntegreerd.

Is Zircon gratis en open source?

Ja, Zircon is source-available onder de Business Source License 1.1 (BSL 1.1). Zowel de client launcher als de self-hosted server manager zijn 100% gratis voor spelers, homelabbers en gaming netwerken. De hele codebase is openbaar voor inspectie, self-hosting en community contributie op GitHub.

Is mijn Microsoft / Minecraft account veilig?

Ja. Authenticatie wordt uitgevoerd via standaard Microsoft OAuth 2.0 PKCE in je standaard systeem browser. Je login credentials gaan direct naar Microsoft's login servers en worden nooit benaderd, behandeld of opgeslagen door Zircon.

Welke mod loaders en Minecraft versies worden ondersteund?

Zircon ondersteunt natively Fabric, Quilt, Forge, and NeoForge. De launcher installeert automatisch de vereiste mod loader versie en geverifieerde Adoptium Temurin Java runtime wanneer je een instantie start of een server joined.
