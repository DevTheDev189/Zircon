Zircon 启动器

v0.5.0 · Windows · macOS · Linux
免费 & 开源 多平台发布

Zircon 服务器的伴侣启动器。使用 Microsoft 账户登录，添加 您的服务器，然后点击 PLAY — 模组将自动精确同步，并通过 Modrinth & CurseForge 验证。

检测到的平台：Windows
下载 Windows (.exe) .msi 安装包

兼容 64 位 Windows 10 和 11。包含 NSIS 安装程序和 WiX MSI 包。

下载 macOS (.dmg) .app 捆绑包 (.tar.gz)

原生 Apple 磁盘映像 (.dmg)。支持 Apple Silicon (M1/M2/M3/M4) 以及运行 macOS 11.0+ 的 Intel Mac。

下载 .AppImage (通用版) .deb (Debian/Ubuntu) .rpm (Fedora/RHEL)

便携式 .AppImage 适用于 Arch、Fedora、openSUSE、Ubuntu、Debian 和 Manjaro。同时提供原生 .deb 和 .rpm 软件包。

Zircon 服务器管理器

v0.5.0 · Windows & Linux
自托管 Linux & Windows 就绪

每个 Zircon 服务器背后的服务端守护进程：为您的玩家提供精确模组同步， Modrinth & CurseForge 集成，单一公共 TCP 端口复用器，实时控制台，自动备份，以及 内置 Web 管理仪表盘。

下载 Linux (.tar.gz) Windows (.zip) 源代码

生产环境就绪，适用于 Ubuntu、Debian、Fedora、RHEL、Arch Linux 和 Windows Server。可作为 systemd 服务或后台进程独立运行。

设置指南

  1. 安装 — 下载管理器并运行它。首次启动时会生成安全的管理员密码并打印到控制台。
  2. 在 http://localhost:25564 打开仪表盘并使用该密码登录。
  3. 创建实例 & 添加模组 — 管理器会为您下载服务器 JAR。 接受 EULA，选择您的 Minecraft & 加载器版本，并直接从 Modrinth 和 CurseForge 搜索 & 安装模组。
  4. 启动服务器 — 一个公共端口 (25565) 同时服务于 Minecraft 和 HTTP。分享地址，玩家即可加入模组化服务器。
端口 & 防火墙：暴露 25565（Minecraft + Web 复用），并将管理仪表盘 25564 保留在 localhost 或 置于您自己的反向代理之后。
