通用一键迁移

正在从 CurseForge, Prism Launcher, Modrinth App 或 ATLauncher 切换？Zircon 会自动检测磁盘上已安装的启动器配置文件。选择你的实例并在2秒内无损导入到隔离的沙盒中。

  • 无损保留：保留 options.txt、按键绑定、世界存档和自定义纹理。
  • 100% 本地且私密：无外部云转换；完全在你的 PC 上运行。
  • 即时游玩：自动分配最佳 Java 运行时和内存标志。

支持手柄的4人沙发合作模式

将你的 PC 或客厅电视变成一台分屏游戏主机。连接最多4个手柄（Xbox, PlayStation 或普通蓝牙），与朋友和家人并肩游玩 Java 版。

  • 原生手柄输入：平滑的摇杆移动、扳机键和震动支持。
  • 自动网格排列：整洁的2人或4人视口窗口平铺。
  • 独立配置文件：每个象限加载各自的角色皮肤和物品栏。

局域网自动发现与离线世界

与室友或同一 Wi-Fi 下的朋友一起玩？Zircon 自动发现本地服务器，无需输入 IP 地址或转发路由器端口。此外，还可以构建具有专用 RAM 分配的隔离离线单人实例。

  • 局域网自动发现：在你的家庭网络中发现附近的游戏和 Ping 延迟。
  • 自适应内存滑块：轻松为每个实例分配 2 GB 到 32 GB RAM。
  • 自动 Java 解析器：获取经过验证的 Eclipse Temurin JDK，无需手动设置路径。

一键模组游玩

点击 PLAY。Zircon 连接到你的服务器，比较模组清单，通过 Modrinth & CurseForge 验证哈希值，并并行下载仅缺失的文件。

2048 与 Discord 状态显示

在加载包含300个模组的大型模组包时，游玩内置的 2048。Discord 富状态自动向你的朋友广播你当前活跃的模组包和服务器。

3D 皮肤工作室与库

带有实时 3D 视口的已保存皮肤选择器、官方 Mojang 账户同步，以及通过 API 实时拉取热门社区皮肤的内置社区皮肤浏览器。

UI 定制与主题

使用自定义颜色强调色、时尚深色配色方案以及可配置的视图密度来个性化启动器外观，以匹配你的电竞桌面设置。

离线实例与世界导入

导入单人世界并完全离线游玩，无需互联网。为每个实例设置自定义 RAM 分配，并将模组包隔离在单独的沙盒中。

客户端服务器调整

向任何服务器配置文件添加可选的性能模组、着色器、按键绑定和小地图，而不破坏加密清单同步。
