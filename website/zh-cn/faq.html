常见问题解答

关于 Zircon 启动器、服务器管理器、模组同步及安全性的所有须知。

Zircon 如何自动同步 Minecraft 模组？

当你选择服务器并点击 开始游戏 时，Zircon 启动器会连接至服务器并获取其加密的模组清单 (BOM)。它会将其与你本地的实例文件夹进行比对，通过官方仓库验证 SHA-512 哈希值和 CurseForge 指纹，并自动下载任何缺失或更新的模组。

我可以使用 CurseForge 或 Modrinth 查找和下载模组吗？

当然！Zircon 原生支持 Modrinth 和 CurseForge，无需任何 API 密钥。无论是在服务器管理器中配置实例，还是在服务器上游玩，两个平台的模组都能无缝处理，并自动进行哈希验证。

我可以创建单人离线实例吗？

可以。启动器包含完整的离线实例管理器。你可以创建本地单人游戏实例，自由选择 Minecraft 版本（从 1.16 到最新版）、模组加载器（Fabric, Quilt, Forge, NeoForge）、自定义 RAM 分配以及本地模组。

皮肤定制器和社区皮肤库是如何工作的？

皮肤选择器允许你从已保存的皮肤中选择或上传自定义 PNG，在实时旋转的 3D 预览中查看角色（提供 Steve 和 Alex 几何模型选项），并直接同步至 Mojang。此外，社区皮肤库让你可以通过 API 实时浏览数千款热门社区皮肤，并一键应用。

单端口多路复用是如何工作的？

Zircon 服务器管理器在同一端口上同时复用标准 Minecraft 游戏流量（端口 25565）和 HTTP REST 模组清单流量。玩家只需输入一次服务器地址（例如 play.example.com），启动器即可获取模组清单并通过端口 25565 连接游戏，无需额外开放其他端口。

如何访问管理员 Web 控制台？

启动服务器管理器时，系统会生成一个管理员密码并打印到控制台。打开浏览器并访问 http://localhost:25564（或你的私有 IP）进行登录。为了安全起见，请将端口 25564 限制为仅本地访问或置于 VPN/反向代理之后。

服务器的休眠/唤醒模式是如何工作的？

当所有玩家离开服务器后，Zircon 会优雅地暂停 Minecraft 服务器进程以节省 CPU 和 RAM。当任何玩家在启动器中点击“开始游戏”时，预加入意图会在玩家进入游戏前唤醒服务器。

我需要 Modrinth 或 CurseForge 的 API 密钥吗？

不需要。Modrinth 和 CurseForge 的支持均已预先配置并直接捆绑在 Zircon 中。服务器所有者和玩家可以立即搜索、下载和同步来自这两个平台的模组，无需任何 API 密钥或手动设置。

会有托管云主机服务（Zircon Cloud）吗？

是的，我们未来的路线图计划推出带有专有“暂停即休眠”保留功能的零硬件托管服务。目前，Zircon 启动器和自托管服务器管理器完全免费、源代码公开，准备好让你在个人电脑、家庭实验室或 VPS 上以零成本运行。

我的 Microsoft Minecraft 账户安全吗？

是的。认证是通过标准的 Microsoft OAuth 2.0 PKCE 在你的系统浏览器中完成的。你的凭据直接提交给 Microsoft 登录服务器。Zircon 绝不会看到、处理或存储你的 Microsoft 密码。

Zircon 是免费且开源的吗？

是的，Zircon 免费且源代码公开，采用商业源代码许可证 1.1 (BSL 1.1)。整个代码库（配套启动器和自托管服务器管理器）可在 GitHub 上进行公开检查、审计以及个人/社区部署。

下载的模组是否经过安全性验证？

是的。模组文件在放入你的活动实例文件夹之前，会使用 SHA-512 加密哈希和 CurseForge murmur2 指纹，对照官方 Modrinth 和 CurseForge API 进行验证。

Windows SmartScreen 提示“Windows 已保护你的电脑”——我该怎么办？

对于尚未建立 Microsoft SmartScreen 证书信誉的新开源软件来说，这是正常现象。请点击 更多信息，然后点击 仍要运行。你也可以在 GitHub 上审查完整源代码以确保透明度。

我需要手动安装 Java 吗？

不需要。Zircon 会自动检测你系统中的 Java，如果缺少所需版本（例如 Java 17 或 Java 21），它会自动从 Adoptium 下载并缓存经过验证的 Eclipse Temurin JDK。

如何为模组化 Minecraft 分配更多 RAM？

在 Zircon 启动器中，点击侧边栏的 设置 图标。使用内存分配滑块调整分配的 RAM（中大型模组包推荐 4 GB 至 8 GB）。
