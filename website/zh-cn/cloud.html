Zircon Cloud 常见问题

关于托管 Zircon 服务的常见问题。

Pause-to-Sleep 保留是如何工作的？

当最后一名玩家从您的服务器断开连接时，Zircon Cloud 会启动一个优雅的 15 分钟空闲倒计时。如果没有玩家加入，游戏容器将被挂起（Pause-to-Sleep）。所有区块状态、实体和库存都会被刷新并保存到磁盘。当玩家在 Zircon Launcher 中点击 PLAY 时，我们的边缘代理会为玩家的无缝唤醒实例。

我的朋友需要付费才能连接吗？

不需要。使用 Zircon Launcher 连接到 Zircon Cloud 服务器是永久 100% 免费的。玩家下载客户端启动器，使用官方 Microsoft 账户登录，然后点击加入。

我可以上传我现有的世界或整合包吗？

可以！Zircon Cloud 具有集成的 Web 文件管理器和 zip 上传器。您可以放入现有的世界存档，导入 CurseForge/Modrinth 整合包 zip，或者直接从本地自托管的 Zircon 服务器一键迁移。

支持哪些加载器和 Minecraft 版本？

Zircon Cloud 支持从 Minecraft 1.7 到最新现代版本的 Fabric、Quilt、NeoForge 和 Forge。纯净 Vanilla 和 Paper/Purpur 实例也完全支持。
