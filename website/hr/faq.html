Pomoć i baza znanja

Često postavljana pitanja

Sve što trebate znati o Zircon Launcheru, Upravitelju poslužitelja, sinkronizaciji modova i sigurnosti.

Kako Zircon automatski sinkronizira Minecraft modove?

Kada odaberete poslužitelj i kliknete IGRAJ, Zircon Launcher se povezuje s poslužiteljem i preuzima njegov kriptografski manifest modova (BOM). Uspoređuje ga s vašom lokalnom mapom instance, verificira SHA-512 hasheve i CurseForge otiske prstiju protiv službenih repozitorija te automatski preuzima sve nedostajuće ili ažurirane modove.

Mogu li koristiti CurseForge ili Modrinth za pronalaženje i preuzimanje modova?

Da! Zircon izvorno podržava i Modrinth i CurseForge bez potrebe za API ključevima. Bilo da konfigurirate instancu u Upravitelju poslužitelja ili igrate na poslužitelju, modovi s obje platforme obrađuju se besprijekorno uz automatsku provjeru hash vrijednosti.

Mogu li kreirati offline instance za igru jednog igrača?

Da. Pokretač uključuje potpuni upravitelj offline instanci. Možete kreirati lokalne instance za igru jednog igrača s izborom verzije Minecrafta (od 1.16 do najnovije), loadera za modove (Fabric, Quilt, Forge, NeoForge), prilagođenom dodjelom RAM-a i lokalnim modovima.

Kako funkcioniraju Skin Customizer i Biblioteka zajedničkih skinova?

Izbornik skinova omogućuje vam odabir spremljenih skinova ili učitavanje vlastitog PNG-a, pregled svog lika u rotirajućem 3D prikazu uživo (s opcijama geometrije Steve i Alex) te izravnu sinkronizaciju s Mojangom. Uz to, Biblioteka zajedničkih skinova omogućuje pregled tisuća popularnih skinova zajednice preuzetih uživo putem API-ja i njihovu primjenu jednim klikom.

Kako funkcionira multipleksiranje jednog porta?

Zircon Server Manager multipleksira standardni Minecraft promet igre (port 25565) i HTTP REST promet manifest modova na istom portu. Igrači jednostavno unesu adresu vašeg poslužitelja jednom (npr. play.example.com) i pokretač preuzima manifest modova te uspostavlja vezu s igrom preko porta 25565 bez potrebe za sekundarnim portovima.

Kako pristupiti Admin Web nadzornoj ploči?

Kada pokrenete upravitelja poslužitelja, generira se administratorska lozinka koja se ispisuje u konzoli. Otvorite preglednik i idite na http://localhost:25564 (ili vaš privatni IP) kako biste se prijavili. Radi sigurnosti, držite port 25564 lokalnim ili iza VPN-a/reverse proxyja.

Kako funkcionira način spavanja/buđenja poslužitelja?

Kada svi igrači napuste poslužitelj, Zircon elegantno pauzira proces Minecraft poslužitelja radi štednje CPU-a i RAM-a. Kada bilo koji igrač klikne IGRAJ u svom pokretaču, namjera prije ulaska budi poslužitelj prije nego što igrač uđe u igru.

Trebam li API ključ za Modrinth ili CurseForge?

Ne. Podrška za Modrinth i CurseForge je predkonfigurirana i ugrađena izravno u Zircon. Vlasnici poslužitelja i igrači mogu odmah pretraživati, preuzimati i sinkronizirati modove s obje platforme bez ikakvih API ključeva ili ručnog postavljanja.

Hoće li postojati upravljani cloud hosting (Zircon Cloud)?

Da, upravljani hosting bez hardvera s proprietary funkcijom zadržavanja stanja Pause-to-Sleep planiran je na našoj budućoj karti puta. Danas su Zircon Launcher i samostalno hostani Server Manager 100% besplatni, dostupni kao open-source i spremni za pokretanje na vašem PC-u, homelabu ili VPS-u bez troškova.

Je li moj Microsoft Minecraft račun siguran?

Da. Autentifikacija se vrši putem standardnog Microsoft OAuth 2.0 PKCE protokola u vašem sustavnom web pregledniku. Vaše vjerodajnice se šalju izravno Microsoftovim login serverima. Zircon nikada ne vidi, ne obrađuje niti pohranjuje vašu Microsoft lozinku.

Je li Zircon besplatan i open source?

Da, Zircon je besplatan i dostupan kao source-available pod Business Source License 1.1 (BSL 1.1). Cijeli kodni bazen (prateći launcher i samostalno hostani upravitelj poslužitelja) dostupan je za javni uvid, auditorske provjere i osobnu/zajedničku implementaciju na GitHubu.

Jesu li preuzeti modovi verificirani radi sigurnosti?

Da. Datoteke modova verificiraju se korištenjem SHA-512 kriptografskih hash vrijednosti i CurseForge murmur2 otisaka prstiju protiv službenih Modrinth i CurseForge API-ja prije nego što se ikada stave u vašu aktivnu mapu instance.

Windows SmartScreen kaže "Windows je zaštitio vaše računalo" — što trebam učiniti?

Ovo je standardno ponašanje za novi open-source softver koji još nije izgradio reputaciju certifikata Windows SmartScreen. Kliknite Više informacija i zatim kliknite Ipak pokreni. Također možete pregledati cijeli izvorni kod na GitHubu radi transparentnosti.

Moram li ručno instalirati Java?

Ne. Zircon automatski detektira vaš sustavski Java, a ako nedostaje potrebna verzija (npr. Java 17 ili Java 21), automatski preuzima i kešira verificirani Eclipse Temurin JDK s Adoptiuma.

Kako dodijeliti više RAM-a za modificirani Minecraft?

U Zircon Launcheru kliknite ikonu Postavke u bočnoj traci. Koristite klizač za alokaciju memorije kako biste prilagodili dodijeljeni RAM (preporučuje se 4 GB do 8 GB za srednje do velike modpackove).
