สำหรับเจ้าของเซิร์ฟเวอร์และโฮสต์

โฮสต์เซิร์ฟเวอร์ที่มี Mod
เพื่อให้เพื่อนของคุณเข้าร่วมได้อย่างแท้จริง

เอนจิน Self-hosted เบื้องหลัง Zircon: เผยแพร่รายการ Mod ที่แม่นยำไปยังผู้เล่น, มัลติเพล็กซ์ทราฟฟิกเกมและเว็บผ่านพอร์ตเดียว และรวมแดชบอร์ดเบราว์เซอร์แบบครบวงจร

รับตัวจัดการเซิร์ฟเวอร์ อ่านคู่มือการโฮสต์
สถิติระบบ & หลายอินสแตนซ์
แดชบอร์ด & สถิติ: ตรวจสอบ CPU, RAM และอัตรา Tick แบบเรียลไทม์ทั่วทั้งอินสแตนซ์เซิร์ฟเวอร์ของคุณ
ค้นหาจาก CurseForge & Modrinth
เบราว์เซอร์ Mod ในตัว: ค้นหาและติดตั้ง Mod จาก Modrinth & CurseForge ด้วยคลิกเดียว พร้อมการจัดการ Dependency อัตโนมัติ โดยไม่ต้องใช้ API Key
เทอร์มินัลแบบโต้ตอบสด
คอนโซลสด: ส่งคำสั่ง ตรวจสอบบันทึกแบบแยกสี และกรองคำเตือนหรือข้อผิดพลาด
Shaders & Resource Packs
แพ็กภาพ: จัดการ Shaders และ Texture Packs ที่แนะนำ ซึ่งซิงค์อัตโนมัติไปยังผู้เล่นที่เข้าร่วม
ตัวจัดการไฟล์เว็บ & BOM Sync
ตัวจัดการไฟล์: สำรวจไดเรกทอรีเซิร์ฟเวอร์ อัปโหลดไฟล์ และทำเครื่องหมายรายการเพื่อซิงค์กับลูกค้าด้วย "Sync to BOM"
ตัวแก้ไข Config ในเบราว์เซอร์
ตัวแก้ไขโค้ดเว็บ: แก้ไข server.properties, JSON configs และไฟล์เกมด้วยคีย์ลัดและการซิงค์ลูกค้าทันที
ผู้เล่น, ผู้ดูแลระบบ & Whitelist
การควบคุมผู้เล่น: จัดการผู้ใช้ใน Whitelist ระดับสิทธิ์ผู้ดูแลระบบ และรายชื่อแบนแบบมองเห็นได้
สำรองข้อมูลอัตโนมัติ & นำเข้า World ZIP
Snapshot อัตโนมัติ & ZIP: สำรองข้อมูล LZ4 ตามกำหนดเวลาพร้อมการเก็บรักษาที่ปรับแต่งได้ ลากและวางนำเข้าโลกจาก .zip และกู้คืนด้วยคลิกเดียว
แผนที่โลก 2D/3D สด & เรดาร์ผู้เล่น
แผนที่โลกสด: สำรวจภูมิประเทศ Biome และตำแหน่งผู้เล่นแบบเรียลไทม์โดยตรงจากเบราว์เซอร์ของคุณ
การตั้งค่าเซิร์ฟเวอร์ & Sleep Trigger
การตั้งค่าเซิร์ฟเวอร์: การกำหนดค่ามัลติเพล็กซ์พอร์ต, การรวม Modrinth & CurseForge ในตัว และกฎการพักเมื่อไม่ใช้งาน

เทอร์มินัลสด & บันทึกแบบมีสี

รันคำสั่งเซิร์ฟเวอร์โดยตรงจากเบราว์เซอร์ของคุณด้วยการสตรีม stdout/stderr ทันที กรองบันทึกตาม Info, Warn หรือ Error เพื่อแยกข้อยกเว้นของ Mod และติดตามเหตุการณ์ในเกมอย่างรวดเร็ว

  • สตรีม WebSocket สด: บันทึกแบบแยกสีที่อัปเดตโดยไม่มีดีเลย์ในการรีเฟรช
  • ส่งคำสั่ง: ส่งคำสั่ง op แจกไอเทม และจัดการเวลา
  • ตัวกรองระดับบันทึก: สลับสตรีม Info, Warning หรือ Error ได้ทันที
คอนโซลเทอร์มินัลสด

ตัวจัดการไฟล์เว็บ & ตัวแก้ไข Config

ไม่จำเป็นต้องใช้ไคลเอ็นต์ FTP ภายนอกหรือ SSH session สำรวจไฟล์อินสแตนซ์ของคุณ แก้ไข server.properties และ JSON configs ด้วยตัวแก้ไขในตัวที่มี Syntax Highlighting และใช้ "Sync to Clients" เพื่อเผยแพร่ Config ไปยัง Launcher ของผู้เล่นโดยตรง

  • ตัวแก้ไขในเบราว์เซอร์: Syntax highlighting และคีย์ลัดแป้นพิมพ์ (Ctrl+S)
  • ซิงค์ลูกค้าด้วยคลิกเดียว: แจกจ่าย Config ที่แก้ไขไปยังผู้เล่นโดยตรง
  • อัปโหลด & แตกไฟล์: อัปโหลดแพ็ก ZIP และ JAR Mod กำหนดเองได้ง่ายๆ
ตัวแก้ไข server.properties

ไม่มีตั๋วสนับสนุน ไม่มีปัญหาความขัดแย้งของเวอร์ชัน

เซิร์ฟเวอร์ของคุณกำหนด Mod, Shaders และ Configs ผู้เล่นเพียงกด PLAY และเกิดมาพร้อมกับข้อมูลที่ซิงค์กัน

พอร์ตเดียว & หลายเซิร์ฟเวอร์

ทราฟฟิกเกม (25565) และ Web manifests ทำงานบน พอร์ตเดียวเดียวกัน โฮสต์และจัดการหลายเซิร์ฟเวอร์หรือ Modpack จากแดชบอร์ดเบราว์เซอร์กลาง

Sleep-When-Empty (ประหยัด RAM)

เมื่อไม่มีใครออนไลน์ เซิร์ฟเวอร์จะหยุดการทำงานของ JVM เพื่อประหยัด CPU และ RAM ของโฮสต์ เมื่อผู้เล่น Ping หรือกด PLAY ใน Zircon มันจะฟื้นคืนสภาพอัตโนมัติภายในเสี้ยววินาที

ร้านค้า Modrinth & CurseForge

ค้นหาและติดตั้ง Mod, Shaders และ Resource packs ด้วยคลิกเดียวโดยตรงในแผงควบคุมเว็บ การจัดการ Dependency อัตโนมัติและไม่ต้องใช้ API Key

คอนโซลเว็บสด & ผู้เล่น

รันคำสั่ง สตรีมบันทึกเซิร์ฟเวอร์ Minecraft แบบมีสีแบบเรียลไทม์ และจัดการ Whitelist สิทธิ์ผู้ดูแลระบบ และการแบนผู้เล่นแบบมองเห็นได้

File Studio & นำเข้า World ZIP

แก้ไข server.properties และไฟล์ JSON ในเบราว์เซอร์พร้อม Syntax highlighting ลากและวางโลกทั้งหมดจากไฟล์ .zip และผลักดันการเปลี่ยนแปลงไปยังลูกค้าทันที

แผนที่โลก & ตัวชี้วัดประสิทธิภาพ

ตรวจสอบภูมิประเทศที่เรนเดอร์สด Biome และหมุดตำแหน่งผู้เล่นแบบเรียลไทม์ พร้อมกับกราฟตรวจสอบ CPU, RAM และอัตรา Tick (TPS) ภายในเสี้ยววินาที

วิธีทำงานของ Port Multiplexing

เซิร์ฟเวอร์แบบดั้งเดิมต้องการพอร์ตแยกสำหรับเกม, Web manifests และคอนโซลผู้ดูแลระบบ Zircon ทำทุกอย่างบนพอร์ต 25565

# 1. เริ่ม Zircon Server Manager ./zircon-server --port 25565 --admin-port 25564 # ที่อยู่สาธารณะ: 25565 (ให้บริการโปรโตคอล Minecraft + REST mod manifests) # แผงผู้ดูแลระบบท้องถิ่น: http://localhost:25564 (แดชบอร์ดปลอดภัยพร้อมรหัสผ่านที่สร้างขึ้น)
ความปลอดภัยโดยออกแบบ: แดชบอร์ดผู้ดูแลระบบ (25564) ยังคงเป็นท้องถิ่นหรืออยู่เบื้องหลัง VPN/reverse proxy ของคุณ เฉพาะพอร์ต Minecraft ที่มัลติเพล็กซ์แล้ว (25565) เท่านั้นที่ต้อง Forward ไปยังผู้เล่นของคุณ

พร้อมรันเซิร์ฟเวอร์ของคุณหรือยัง?

ดาวน์โหลดตัวจัดการ Self-hosted ฟรีและควบคุมเซิร์ฟเวอร์ Minecraft ของคุณอย่างเต็มที่

รับตัวจัดการเซิร์ฟเวอร์ ดูคู่มือการติดตั้ง

ตัวเปิดเกมและตัวจัดการเซิร์ฟเวอร์ฟรี โอเพนซอร์ส สำหรับ Minecraft ที่มี Mod ซิงค์ Mod ที่แม่นยำได้รับการตรวจสอบทุกครั้งที่เปิดเกมเทียบกับ Modrinth & CurseForge
