วิธีของ Zircon: คลิกเดียวแล้วเล่น

  • ✓ ไม่ต้องตามหาไฟล์ — เพื่อนของคุณให้ที่อยู่เซิร์ฟเวอร์หรือคำเชิญผ่าน LAN ภายในเครื่อง
  • ✓ คลิกเดียว — กด PLAY Zircon จะตรวจสอบรายการ Mod ของเซิร์ฟเวอร์และยืนยันทุกไฟล์
  • ✓ ดาวน์โหลดอัตโนมัติอย่างรวดเร็ว — Mod, Config และ Texture ที่หายไปจะดึงมาจาก Modrinth & CurseForge ในไม่กี่วินาที
  • ✓ เข้าเกมในไม่กี่วินาที — คุณเกิดพร้อมกันทันที ไม่ต้องลากโฟลเดอร์ Mod

1. รายการตรวจสอบด้วยการเข้ารหัส

เซิร์ฟเวอร์จะเผยแพร่ Bill of Materials (BOM) ที่แน่นอนผ่านพอร์ต 25565 — ID ของ Mod, Hash เวอร์ชัน, Loader และ Config

2. ตรวจสอบ Hash ทันที

ตัวเปิดเกมจะสแกนอินสแตนซ์ในเครื่องของคุณภายในมิลลิวินาที ข้ามไฟล์ที่คุณมีอยู่แล้วและระบุเฉพาะสิ่งที่ขาดหาย

3. ดึงข้อมูลที่ตรวจสอบแล้วแบบขนาน

ไฟล์ที่ขาดหายจะดาวน์โหลดแบบขนานโดยตรงจาก CDN ของ Modrinth และ CurseForge ไม่มี JAR เสีย ไม่มีเวอร์ชันไม่ตรงกัน

เมื่อคุณเปิด Zircon ตัวตรวจจับ Rust พื้นฐานของเราจะค้นหาโปรไฟล์ที่ติดตั้งไว้ในระบบของคุณ เลือกอินสแตนซ์ที่ต้องการนำเข้า และ Zircon จะย้ายทุกอย่างไปยัง Sandbox ที่สะอาดและแยกส่วน

  • ตรวจจับในเครื่องแบบออฟไลน์ 100%: สแกนไดเรกทอรีมาตรฐานบนดิสก์โดยไม่มีการอัปโหลดไปยังคลาวด์ภายนอก
  • รักษาอินสแตนซ์อย่างสมบูรณ์: เก็บคีย์ลัด, options.txt, Resource Pack และโลกของคุณไว้อย่างครบถ้วน
  • เปิดเกมเร็วทันที: กำหนดค่าเวอร์ชัน Java ที่ตรงกันและ Flags หน่วยความจำที่เหมาะสมโดยอัตโนมัติ

ศูนย์บัญชาการ Minecraft ใหม่ของคุณ

ทุกอย่างที่คุณเคยอยากให้มีในตัวเปิดเกมอื่นๆ — สร้างขึ้นในแอปเดสก์ท็อปของคุณ

ยื่นจอยเกมให้เพื่อน เล่นด้วยกันบนโซฟา

เปลี่ยน PC หรือทีวีในห้องนั่งเล่นของคุณให้เป็นคอนโซลแบบแบ่งหน้าจอ เชื่อมต่อจอยเกม Xbox, PlayStation หรือ Bluetooth ทั่วไปสูงสุด 4 ตัว และเล่นเกม Java Edition แบบ Mod ข้างกันโดยมีกระเป๋า, มุมมอง และสกินแยกกัน

  • จอยเกมแบบ Plug & Play: การเคลื่อนไหวของอนาล็อกสติกที่ราบรื่นด้วยคอนโทรลเลอร์ Xbox, PlayStation & Bluetooth
  • แบ่งหน้าจออัตโนมัติ: จัดเรียงหน้าต่างแนวนอน/แนวตั้งสำหรับ 2 ผู้เล่น หรือแบบควอดรันต์สำหรับ 4 ผู้เล่นอย่างเรียบร้อย
  • โปรไฟล์ผู้เล่นแยกกัน: แต่ละผู้เล่นใช้สกินตัวละครของตัวเองและกระเป๋าแยกกัน
ตั้งค่าจอยเกมสำหรับ Co-op บนโซฟา 4 ผู้เล่น

ดูดีในเกมด้วยพรีวิว 3D แบบสด

เลิกเดาว่าสกินจะออกมาเป็นอย่างไรก่อนโหลดเกม หมุนตัวละครของคุณในมุมมอง 3D แบบเรียลไทม์ เรียกดูสกินชุมชนยอดนิยมหลายพันรายการที่ดึงมาโดยตรงผ่าน API และซิงค์ไปยังเซิร์ฟเวอร์ทางการของ Mojang ด้วยคลิกเดียว

  • มุมมอง 3D แบบหมุน: เรขาคณิต Steve (Classic) และ Alex (Slim) แบบสดพร้อมพรีวิวผ้าคลุม
  • คลังสกินชุมชนยอดนิยม: ค้นหาสกินหลายพันรายการและนำไปใช้ในไม่กี่วินาที
  • ซิงค์กับ Mojang ด้วยคลิกเดียว: ส่งสกินที่ใช้งานอยู่ของคุณไปยังเซิร์ฟเวอร์ Minecraft ทางการโดยตรง
สตูดิโอสกิน 3D & ซิงค์กับ Mojang

ค้นหาเพื่อนผ่าน Wi-Fi ได้ทันที เข้าร่วมด้วยโค้ด

ไม่ต้องคัดลอกและวาง IP Address ไม่ต้องสร้างเครือข่ายเสมือน Hamachi ไม่ต้องเปิดพอร์ตไฟร์วอลล์เราเตอร์ เมื่อมีคนเปิดโลกหรือเซิร์ฟเวอร์ผ่าน Wi-Fi ภายในเครื่อง มันจะปรากฏขึ้นโดยอัตโนมัติ เล่นผ่านอินเทอร์เน็ต? แชร์โค้ดเข้าร่วม 6 หลักพร้อมการส่งต่อพอร์ต UPnP อัตโนมัติ

  • ค้นหา Wi-Fi ภายในเครื่องอัตโนมัติ: เผยแพร่และตรวจจับเกมใกล้เคียงทันทีทั่วทั้งเครือข่ายของคุณ
  • โค้ดเข้าร่วม 6 หลัก & UPnP: เชื่อมต่อผ่านอินเทอร์เน็ตโดยไม่ต้องตั้งค่าเราเตอร์ด้วยตนเอง
  • Ping & จำนวนผู้เล่นแบบสด: ตรวจสอบจำนวนผู้เล่นและความหน่วงก่อนคลิกเข้าร่วม
ค้นหา LAN อัตโนมัติ & เกมใกล้เคียง

เล่น 2048 ระหว่างที่ Modpack ขนาดใหญ่ของคุณกำลังโหลด

ไม่ต้องจ้องหน้าจอโหลด Minecraft ที่ค้างอีกต่อไป ขณะที่แพ็ก Forge หรือ Fabric ขนาดใหญ่กำลังเริ่ม Texture ให้เล่น 2048 ในหน้าต่างตัวเปิดเกมได้ทันที เมื่อเกมโหลดเสร็จ ก็เข้าสู่เกมได้เลยโดยที่ Discord Rich Presence แสดงให้เพื่อนเห็นว่าคุณกำลังเล่นอะไร

  • มินิเกม 2048 ในตัว: ควบคุมด้วยคีย์บอร์ดเต็มรูปแบบ บันทึกคะแนนสูงสุดถาวร และไม่ใช้หน่วยความจำเพิ่ม
  • Discord Rich Presence: เผยแพร่ Modpack ที่ใช้งานอยู่, IP/ชื่อเซิร์ฟเวอร์ และเวลาที่เล่นไปแล้ว
  • จำกัดทรัพยากรเบื้องหลัง: ระงับ UI ของตัวเปิดเกมระหว่างการเล่นเพื่อให้ Minecraft ใช้ RAM ทั้งหมดของระบบ

ปรับแต่ง UI & ธีม

ปรับแต่งตัวเปิดเกมให้เข้ากับสไตล์ส่วนตัวของคุณด้วยสีเน้นที่กำหนดเอง, พาเลตสีเข้ม และรูปแบบมุมมองที่ปรับได้

เล่นออฟไลน์ & นำเข้าโลก

เล่นได้ทุกที่โดยไม่ต้องมีการเชื่อมต่ออินเทอร์เน็ต นำเข้าโลกผู้เล่นเดี่ยวที่มีอยู่ จัดสรร RAM กำหนดเอง และแยก Modpack

ปรับแต่งฝั่ง Client สำหรับเซิร์ฟเวอร์

เพิ่ม Mod ฝั่ง Client, Shader, Resource Pack และคีย์ลัดที่กำหนดเองลงในอินสแตนซ์เซิร์ฟเวอร์ใดๆ โดยไม่ทำลายการซิงค์

จัดการเซิร์ฟเวอร์หลายตัว ประหยัด RAM ขณะที่คุณนอนหลับ และรันบนพอร์ตเดียว

กลไกการจัดการแบบโฮสต์ตัวเองเบื้องหลัง Zircon ไม่มีปัญหา Docker ไม่มีฝันร้ายเรื่องไฟร์วอลล์หลายพอร์ต รันเซิร์ฟเวอร์แบบ Mod ที่ผู้เล่นของคุณสามารถเชื่อมต่อได้จริงโดยไม่ต้องขอความช่วยเหลือทางเทคนิค

  • Multiplexing พอร์ตเดียว (25565): แพ็กเก็ตเกมและ Manifest Mod REST รันบนพอร์ตเริ่มต้น 25565 ทั้งคู่ ต้องส่งต่อเพียงพอร์ตเดียว
  • Sleep-When-Empty (ประหยัด RAM): หยุดหน่วยความจำ JVM เป็น CPU 0% เมื่อไม่มีผู้เล่นออนไลน์; ปลุกกลับในมิลลิวินาทีเมื่อมีผู้เล่น Ping เข้ามา
  • ร้าน Mod ในตัว: ติดตั้ง Mod, Shader และ Resource Pack ด้วยคลิกเดียวโดยตรงจาก Modrinth และ CurseForge
  • คอนโซลสด & จัดการผู้เล่น: บันทึกเทอร์มินัลแบบมีสี, ส่งคำสั่งทันที, Whitelist แบบภาพ, OP และแบน
  • สำรองข้อมูลอัตโนมัติ & นำเข้าโลก ZIP: Snapshot LZ4 ความเร็วสูงพร้อมการเก็บรักษากำหนดเอง, ถอยกลับด้วยคลิกเดียว และนำเข้าโลกแบบลากและวาง
  • แผนที่โลก 2D/3D แบบสด: สำรวจภูมิประเทศที่เรนเดอร์, ไบโอม และตำแหน่งผู้เล่นแบบสดโดยตรงในเบราว์เซอร์ของคุณ

ทุกอย่างระหว่างคุณกับการเล่น... ทำงานได้

สร้างขึ้นเพื่อคนที่ต้องการ เล่นเกม Minecraft แบบ Mod กับเพื่อน — ไม่ใช่ ใช้เวลาค่ำคืนในการปรับเวอร์ชัน Mod และอ่านบันทึกข้อผิดพลาด

คลิกเดียว คุณก็เข้าเกมแล้ว

กด PLAY แล้ว Zircon จะดาวน์โหลดเวอร์ชัน Minecraft และ Mod Loader ที่ถูกต้อง — Fabric, Quilt, Forge, หรือ NeoForge — ติดตั้ง Mod และพาคุณ เข้าสู่เกมโดยตรง

ซิงค์กับ CurseForge & Modrinth

ค้นหาและดาวน์โหลด Mod จาก Modrinth และ CurseForge พร้อมการตรวจสอบ SHA-512 และลายนิ้วมือในทุกครั้งที่เปิดเกม ไม่มีอะไรขาดหาย ไม่มีอะไรเก่า

เข้าสู่ระบบด้วยบัญชีจริงของคุณ

เข้าสู่ระบบด้วย Microsoft อย่างเป็นทางการ — รหัสผ่านของคุณส่งไปยัง Microsoft เท่านั้น ไม่เคย ผ่าน Zircon ไม่มีการแชร์บัญชี ไม่มีการใช้ Launcher แบบแคร็ก ไม่มีการ绕过ออฟไลน์

ตัวเลือกสกินที่บันทึกไว้พร้อมพรีวิว 3D แบบสด, ซิงค์กับคลาวด์ Mojang อย่างเป็นทางการ และตัวสำรวจสกินชุมชนในแอปที่ดึงสกินยอดนิยมผ่าน API

Shader & แพ็ก ซักนำอัตโนมัติ

เซิร์ฟเวอร์สามารถเสนอ Shader และ Resource Pack ของตัวเองได้ Zircon จะ นำไปใช้เมื่อคุณเข้าร่วม — คุณแค่ตอบตกลงครั้งเดียว แล้วก็เสร็จสิ้น

ผจญภัยคนเดียวก็ได้

สร้างอินสแตนซ์ผู้เล่นเดี่ยวแบบออฟไลน์พร้อม Mod, Shader และ Texture Pack ของตัวเอง ไม่ต้องมีเซิร์ฟเวอร์ — แค่สร้างอย่างสงบสุข

สามขั้นตอน แล้วคุณก็เข้าเกม

เข้าสู่ระบบด้วย Microsoft

คลิกเดียวในเบราว์เซอร์ของคุณ Zircon ใช้กระบวนการ Microsoft อย่างเป็นทางการ — รหัสผ่านของคุณไม่เคยสัมผัสแอปนี้

เลือกเซิร์ฟเวอร์

เซิร์ฟเวอร์ที่คุณบันทึกไว้ เรียงตามล่าสุดที่เล่น — บวกกับคำแนะนำ แต่ละเซิร์ฟเวอร์จะมาพร้อมรายการ Mod ของตัวเอง

กด PLAY

Zircon ซิงค์และตรวจสอบ Mod จาก Modrinth & CurseForge ปลุกเซิร์ฟเวอร์ถ้ามันหลับอยู่, และเชื่อมต่อกับคุณ คุณเกิดในเกม — พร้อม Mod ครบถ้วน เตรียมพร้อม

มาตรฐานวิศวกรรม

สร้างขึ้นเพื่อความเร็วล้วนๆ ด้วย Rust & Vue 3 ที่คอมไพล์แล้ว

ไม่มี Electron Runtime ช้าๆ ที่กินหน่วยความจำพื้นหลังหลายกิกะไบต์ขณะคุณเล่น แกนหลักของ Zircon Desktop Engine เขียนด้วย Rust ที่คอมไพล์ทั้งหมดเพื่อการเริ่มต้นที่ฉับพลัน, การตรวจสอบ Hash ในระดับมิลลิวินาที และ footprint ระบบที่เบาบาง

✓ ฟรี 100% & Open Source

คำถามที่พบบ่อย

ทุกสิ่งที่คุณจำเป็นต้องรู้เกี่ยวกับการเริ่มต้นใช้งาน Zircon

Zircon ซิงค์ Mod Minecraft อัตโนมัติได้อย่างไร?

เมื่อคุณเข้าร่วมเซิร์ฟเวอร์และกด PLAY, Zircon จะเปรียบเทียบ Manifest Bill of Materials ที่เผยแพร่ของเซิร์ฟเวอร์กับโฟลเดอร์ Client ในเครื่องของคุณ Mod ที่ขาดหายหรืออัปเดตใหม่จะถูกตรวจสอบผ่าน Hash SHA-512 และลายนิ้วมือจาก Modrinth & CurseForge จากนั้นดาวน์โหลดทันทีแบบขนานโดยไม่ต้องลากไฟล์ด้วยตนเอง

ฉันสามารถย้ายอินสแตนซ์จาก CurseForge, Prism หรือ Modrinth ได้ไหม?

ได้! Zircon มีเครื่องมือ Universal Migration แบบคลิกเดียวที่เป็น Native มันจะตรวจจับไดเรกทอรีที่ติดตั้งจาก CurseForge, Prism Launcher, Modrinth App และ ATLauncher โดยอัตโนมัติ ทำให้คุณสามารถนำเข้าโครงสร้างอินสแตนซ์, การบันทึก, คีย์ลัด และการตั้งค่า Mod อย่างสมบูรณ์ภายในไม่ถึงสองวินาที

โหมด Co-op แบ่งหน้าจอ 4 ผู้เล่นทำงานอย่างไร?

Zircon อนุญาตให้คุณเชื่อมต่อจอยเกมสูงสุด 4 ตัว (Xbox, PlayStation หรือคอนโทรลเลอร์ Bluetooth ทั่วไป) และเปิดหน้าต่างเกมหลายตัวที่แยกจากกันซึ่งจัดเรียงเป็นกริดแบ่งหน้าจอไร้รอยต่อบนจอแสดงผลหรือทีวีของคุณ ผู้เล่นแต่ละคนควบคุมตัวละครของตัวเองด้วยจอยเกมของตัวเอง

ฉันสามารถใช้ CurseForge และ Modrinth เพื่อค้นหาและดาวน์โหลด Mod ได้ไหม?

ได้! Zircon รองรับการค้นหา, การติดตั้ง และการซิงค์ Mod จากทั้ง Modrinth และ CurseForge โดยตรงโดยไม่ต้องตั้งค่า API Key ทั้งสองแหล่งถูกบูรณาการอย่างสมบูรณ์ตั้งแต่เริ่มต้น

Zircon ฟรีและเป็นโอเพนซอร์สหรือไม่?

ใช่ Zircon เป็น source-available ภายใต้ Business Source License 1.1 (BSL 1.1) ทั้ง Client Launcher และ Self-hosted Server Manager ฟรี 100% สำหรับผู้เล่น, ผู้ใช้ Homelab และเครือข่ายเกม โค้ดทั้งหมดเปิดให้สาธารณชนตรวจสอบ, โฮสต์ตัวเอง และมีส่วนร่วมจากชุมชนบน GitHub

บัญชี Microsoft / Minecraft ของฉันปลอดภัยหรือไม่?

ใช่ การยืนยันตัวตนดำเนินการผ่าน Microsoft OAuth 2.0 PKCE มาตรฐานในเบราว์เซอร์ระบบเริ่มต้นของคุณ ข้อมูลรับรองการเข้าสู่ระบบของคุณส่งไปยังเซิร์ฟเวอร์การเข้าสู่ระบบของ Microsoft โดยตรงและไม่ถูกเข้าถึง, จัดการ หรือเก็บรักษาโดย Zircon

รองรับ Mod Loader และเวอร์ชัน Minecraft อะไรบ้าง?

Zircon รองรับ Fabric, Quilt, Forge และ NeoForge โดยตรง ตัวเปิดเกมจะติดตั้งเวอร์ชัน Mod Loader ที่จำเป็นและ Adoptium Temurin Java Runtime ที่ตรวจสอบแล้วโดยอัตโนมัติเมื่อคุณเปิดอินสแตนซ์หรือเข้าร่วมเซิร์ฟเวอร์

พร้อมที่จะเล่นจริงๆ หรือยัง?

ดาวน์โหลด Launcher ฟรีแบบโอเพนซอร์ส หรือรับตัวจัดการเซิร์ฟเวอร์แบบโฮสต์ตัวเอง

ดาวน์โหลด Launcher (.exe) รับตัวจัดการเซิร์ฟเวอร์ ดูบน GitHub

Launcher และตัวจัดการเซิร์ฟเวอร์ฟรีแบบโอเพนซอร์สสำหรับ Minecraft แบบ Mod ผู้เล่นกด PLAY และได้รับ Mod ตรงตามที่เซิร์ฟเวอร์รัน — ตรวจสอบกับ Modrinth & CurseForge ในทุกครั้งที่เปิดเกม
