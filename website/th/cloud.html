ทุกสิ่งที่จำเป็นสำหรับการรันชุมชน Minecraft ที่มี Mods ประสิทธิภาพสูง โดยไม่ต้องมีความรู้ด้าน Linux sysadmin

การรักษาข้อมูลแบบ Pause-to-Sleep

โฮสต์แบบดั้งเดิมสิ้นเปลืองเงินด้วยการรันโลกที่ว่างเปล่าตลอด 24/7 Zircon Cloud จะระงับเกมลูปเมื่อมีผู้เล่นออนไลน์ 0 คน และกลับมาทำงานอย่างราบรื่นเมื่อมีผู้เล่นเชื่อมต่อ โดยข้อมูล Chunk ทั้งหมดยังคงอยู่ครบถ้วน 100%

การวินิจฉัย Crash ด้วย Zirky AI

ขับเคลื่อนโดย DeepSeek-V4-Flash เมื่อเซิร์ฟเวอร์ล่มเนื่องจาก Mods ที่ไม่เข้ากันหรือขาดไลบรารี Zirky จะวิเคราะห์ Stack Trace และสร้างการ์ดแก้ไขเพียงคลิกเดียวโดยตรงในคอนโซลของคุณ

Modrinth & CurseForge ในเบราว์เซอร์

ค้นหาและติดตั้ง Mods, Modpacks, Shaders และ Resource Packs กว่า 100,000 รายการโดยตรงในแผงควบคุมเว็บ ไม่ต้องโอนไฟล์ผ่าน FTP หรือตามหา JAR เอง

การกรอง DDoS ระดับองค์กรที่ Edge

ทราฟฟิก Minecraft และ Web Telemetry ทั้งหมดที่เข้ามาจะผ่านโหนดกรองที่ Edge ซ้ำซ้อน ซึ่งช่วยกรองการโจมตีแบบ Volumetric และแพ็กเก็ตเสียก่อนจะถึงคอนเทนเนอร์โลกของคุณ

Multiplexing ผ่านพอร์ตเดียว

การเล่นเกม Minecraft (25565) และ REST manifest API ใช้พอร์ตเดียวกัน ผู้เล่นเชื่อมต่อผ่านโดเมนสะอาดเช่น yourserver.zirconmc.net โดยไม่ต้องระบุหมายเลขพอร์ต

Snapshot บนคลาวด์ด้วย LZ4 อัตโนมัติ

สำรองข้อมูลโลกแบบบีบอัดด้วย LZ4 ความเร็วสูงตามกำหนดเวลาโดยไม่ทำให้เกมกระตุก กู้คืนจุดตรวจสอบก่อนหน้าได้เพียงคลิกเดียวหากเกิดเหตุไม่คาดฝัน

ระบบ Pause-to-Sleep ทำงานอย่างไร?

เมื่อผู้เล่นคนสุดท้ายตัดการเชื่อมต่อจากเซิร์ฟเวอร์ของคุณ Zircon Cloud จะเริ่มนับถอยหลัง 15 นาทีอย่างนุ่มนวล หากไม่มีผู้เล่นเข้าร่วม คอนเทนเนอร์เกมจะถูกพัก (Pause-to-Sleep) สถานะ Chunk, Entities และ Inventories ทั้งหมดจะถูกบันทึกและเก็บไว้บนดิสก์ เมื่อผู้เล่นกด PLAY ใน Zircon Launcher โปรкси Edge ของเราจะปลุกอินสแตนซ์อย่างราบรื่นสำหรับผู้เล่นของคุณ

เพื่อนของฉันต้องจ่ายเงินเพื่อเชื่อมต่อหรือไม่?

ไม่ การเชื่อมต่อเซิร์ฟเวอร์ Zircon Cloud โดยใช้ Zircon Launcher ฟรี 100% ตลอดไป ผู้เล่นดาวน์โหลด Client Launcher, เข้าสู่ระบบด้วยบัญชี Microsoft อย่างเป็นทางการ และกดเข้าร่วม

ฉันสามารถอัปโหลดโลกหรือ Modpack ที่มีอยู่ได้ไหม?

ได้! Zircon Cloud มี File Manager เว็บและ Zip Uploader ที่บูรณาการ คุณสามารถวางไฟล์ Save โลกที่มีอยู่ นำเข้า Zip Modpack จาก CurseForge/Modrinth หรือย้ายข้อมูลจากเซิร์ฟเวอร์ Zircon ที่โฮสต์เองในเครื่องโดยตรงเพียงคลิกเดียว

รองรับ Loaders และเวอร์ชัน Minecraft อะไรบ้าง?

Zircon Cloud รองรับ Fabric, Quilt, NeoForge และ Forge ตั้งแต่ Minecraft 1.7 จนถึงเวอร์ชันล่าสุดสมัยใหม่ นอกจากนี้ยังรองรับ Vanilla ล้วนและอินสแตนซ์ Paper/Purpur อย่างสมบูรณ์

เริ่มโฮสต์เองฟรีวันนี้

รัน Zircon Server Manager บน PC หรือ VPS ของคุณพร้อมการซิงค์ Mods อัตโนมัติและการตรวจสอบ Modrinth/CurseForge

รับ Server Manager ดาวน์โหลด Launcher สำหรับผู้เล่น

Launcher และ Server Manager แบบโอเพนซอร์สฟรีสำหรับ Minecraft ที่มี Mods. ผู้เล่นกด PLAY และได้รับ Mods ตรงตามที่เซิร์ฟเวอร์รัน — ตรวจสอบแล้ว กับ Modrinth & CurseForge ทุกครั้งที่เปิดใช้งาน
