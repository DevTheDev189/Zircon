คำถามที่พบบ่อย

ทุกสิ่งที่คุณต้องรู้เกี่ยวกับ Zircon Launcher, ตัวจัดการเซิร์ฟเวอร์, การซิงค์ Mod และความปลอดภัย

Zircon ซิงค์ Minecraft Mods โดยอัตโนมัติได้อย่างไร?

เมื่อคุณเลือกเซิร์ฟเวอร์และกด PLAY, Zircon Launcher จะเชื่อมต่อเข้ากับเซิร์ฟเวอร์และดึงรายการ Manifest ของ Mod แบบเข้ารหัส (BOM) จากนั้นจะเปรียบเทียบกับโฟลเดอร์ Instance ในเครื่องของคุณ ตรวจสอบ SHA-512 hashes และ CurseForge fingerprints กับคลังทางการ แล้วดาวน์โหลด Mod ที่ขาดหายหรือมีการอัปเดตโดยอัตโนมัติ

ฉันสามารถใช้ CurseForge หรือ Modrinth เพื่อค้นหาและดาวน์โหลด Mods ได้ไหม?

ได้! Zircon รองรับทั้ง Modrinth และ CurseForge โดยไม่ต้องใช้ API Keys เลย ไม่ว่าจะเป็นการตั้งค่า Instance ในตัวจัดการเซิร์ฟเวอร์หรือการเล่นบนเซิร์ฟเวอร์ Mods จากทั้งสองแหล่งจะถูกจัดการอย่างราบรื่นพร้อมการตรวจสอบ Hash อัตโนมัติ

ฉันสามารถสร้าง Instance สำหรับเล่นคนเดียวแบบออฟไลน์ได้ไหม?

ได้ ตัวเรียกใช้งานมีระบบจัดการ Instance ออฟไลน์แบบครบถ้วน คุณสามารถสร้าง Instance สำหรับเล่นคนเดียวในเครื่องได้ พร้อมตัวเลือกเวอร์ชัน Minecraft (ตั้งแต่ 1.16 จนถึงเวอร์ชันล่าสุด), ตัวโหลด Mod (Fabric, Quilt, Forge, NeoForge), การกำหนดค่า RAM เอง และ Mods ในเครื่อง

Skin Customizer และ Community Skin Library ทำงานอย่างไร?

ตัวเลือก Skin ช่วยให้คุณเลือกจาก Skin ที่บันทึกไว้หรืออัปโหลดไฟล์ PNG แบบกำหนดเอง ดูตัวอย่างตัวละครในรูปแบบ 3 มิติหมุนได้จริง (พร้อมตัวเลือกโครงสร้าง Steve และ Alex) และซิงค์ไปยัง Mojang ได้โดยตรง นอกจากนี้ Community Skin Library ยังช่วยให้คุณเรียกดู Skin ยอดนิยมจากชุมชนหลายพันรายการที่ดึงข้อมูลสดผ่าน API และนำไปใช้ได้ด้วยการคลิกเพียงครั้งเดียว

Single-port multiplexing ทำงานอย่างไร?

Zircon Server Manager ทำ Multiplexing ทั้งทราฟฟิกเกม Minecraft มาตรฐาน (พอร์ต 25565) และทราฟฟิก HTTP REST สำหรับ Mod manifest บนพอร์ตเดียวกัน ผู้เล่นเพียงกรอกที่อยู่เซิร์ฟเวอร์ของคุณครั้งเดียว (เช่น play.example.com) แล้ว Launcher จะดึง Mod manifest และเชื่อมต่อเกมผ่านพอร์ต 25565 โดยไม่จำเป็นต้องใช้พอร์ตเสริม

ฉันจะเข้าถึง Admin Web Dashboard ได้อย่างไร?

เมื่อคุณเริ่มตัวจัดการเซิร์ฟเวอร์ รหัสผ่านผู้ดูแลระบบจะถูกสร้างขึ้นและแสดงในคอนโซลของคุณ เปิดเบราว์เซอร์และไปที่ http://localhost:25564 (หรือ IP ส่วนตัวของคุณ) เพื่อเข้าสู่ระบบ เพื่อความปลอดภัย ควรให้พอร์ต 25564 เป็น Local หรืออยู่เบื้องหลัง VPN/reverse proxy

โหมด Sleep/Wake ของเซิร์ฟเวอร์ทำงานอย่างไร?

เมื่อผู้เล่นทุกคนออกจากเซิร์ฟเวอร์ Zircon จะหยุดกระบวนการเซิร์ฟเวอร์ Minecraft อย่างนุ่มนวลเพื่อประหยัด CPU และ RAM เมื่อใดก็ตามที่ผู้เล่นกด PLAY ใน Launcher ของพวกเขา ความตั้งใจก่อนเข้าร่วม (pre-join intent) จะปลุกเซิร์ฟเวอร์ขึ้นมาก่อนที่ผู้เล่นจะเข้าเกม

ฉันต้องใช้ API key สำหรับ Modrinth หรือ CurseForge หรือไม่?

ไม่ การรองรับทั้ง Modrinth และ CurseForge ถูกกำหนดค่าล่วงหน้าและรวมอยู่ใน Zircon โดยตรง เจ้าของเซิร์ฟเวอร์และผู้เล่นสามารถค้นหา ดาวน์โหลด และซิงค์ Mods จากทั้งสองแพลตฟอร์มได้ทันทีโดยไม่ต้องใช้ API keys หรือการตั้งค่าด้วยตนเอง

จะมีบริการโฮสติ้งแบบจัดการ (Zircon Cloud) หรือไม่?

ใช่ มีแผนที่จะให้บริการโฮสติ้งแบบจัดการที่ไม่ต้องเตรียมฮาร์ดแวร์เอง พร้อมเทคโนโลยี Pause-to-Sleep เฉพาะของเราในอนาคต ปัจจุบัน Zircon Launcher และตัวจัดการเซิร์ฟเวอร์แบบ Self-hosted ฟรี 100% สามารถตรวจสอบซอร์สโค้ดได้ และพร้อมให้คุณรันบน PC, Homelab หรือ VPS ของคุณเองโดยไม่มีค่าใช้จ่าย

บัญชี Microsoft Minecraft ของฉันปลอดภัยหรือไม่?

ใช่ การยืนยันตัวตนดำเนินการผ่านมาตรฐาน Microsoft OAuth 2.0 PKCE ในเว็บเบราว์เซอร์ของระบบคุณ ข้อมูลรับรองของคุณถูกส่งตรงไปยังเซิร์ฟเวอร์ล็อกอินของ Microsoft Zircon ไม่เคยเห็น จัดการ หรือจัดเก็บรหัสผ่าน Microsoft ของคุณ

Zircon ฟรีและเป็นโอเพ่นซอร์สหรือไม่?

ใช่ Zircon ฟรีและเปิดให้ตรวจสอบซอร์สโค้ดภายใต้ Business Source License 1.1 (BSL 1.1) โค้ดเบสทั้งหมด (ทั้ง Launcher และตัวจัดการเซิร์ฟเวอร์แบบ Self-hosted) พร้อมให้สาธารณชนตรวจสอบ ตรวจสอบความถูกต้อง และติดตั้งสำหรับการใช้งานส่วนตัวหรือชุมชนบน GitHub

Mods ที่ดาวน์โหลดมาได้รับการตรวจสอบความปลอดภัยหรือไม่?

ใช่ ไฟล์ Mods ได้รับการตรวจสอบโดยใช้ SHA-512 cryptographic hashes และ CurseForge murmur2 fingerprints เทียบกับ APIs ทางการของ Modrinth และ CurseForge ก่อนที่จะถูกวางลงในโฟลเดอร์ Instance ที่ใช้งานของคุณ

Windows SmartScreen แจ้งว่า "Windows ได้ปกป้องพีซีของคุณ" — ฉันควรทำอย่างไร?

นี่เป็นเรื่องปกติสำหรับซอฟต์แวร์โอเพ่นซอร์สใหม่ที่ยังไม่ได้สร้างความน่าเชื่อถือของใบรับรอง Microsoft SmartScreen คลิก ข้อมูลเพิ่มเติม แล้วคลิก รันต่อไป คุณยังสามารถตรวจสอบซอร์สโค้ดทั้งหมดบน GitHub เพื่อความโปร่งใสได้

ฉันต้องติดตั้ง Java ด้วยตนเองหรือไม่?

ไม่ Zircon จะตรวจจับ Java ในระบบของคุณโดยอัตโนมัติ และหากขาดเวอร์ชันที่ต้องการ (เช่น Java 17 หรือ Java 21) มันจะดาวน์โหลดและแคช Eclipse Temurin JDK ที่ผ่านการตรวจสอบจาก Adoptium ให้โดยอัตโนมัติ

ฉันจะจัดสรร RAM เพิ่มเติมให้กับ Minecraft ที่มี Mods ได้อย่างไร?

ใน Zircon Launcher ให้คลิกไอคอน การตั้งค่า ในแถบด้านข้าง ใช้ตัวเลื่อนการจัดสรรหน่วยความจำเพื่อปรับจำนวน RAM ที่จัดสรร (แนะนำ 4 GB ถึง 8 GB สำหรับ Modpack ขนาดกลางถึงใหญ่)

ยังมีข้อสงสัยอีกไหม?

ลองอ่านคู่มือเอกสารแบบทีละขั้นตอนของเรา หรือเข้าร่วมชุมชนโอเพ่นซอร์สบน GitHub

อ่านคู่มือการติดตั้ง ดาวน์โหลด GitHub Discussions

Launcher และตัวจัดการเซิร์ฟเวอร์ฟรี โอเพ่นซอร์ส สำหรับ Minecraft ที่มี Mods การซิงค์ Mods แบบแม่นยำได้รับการตรวจสอบในทุกครั้งที่เปิดใช้ เทียบกับ Modrinth & CurseForge
