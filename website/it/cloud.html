Ritenzione Pause-to-Sleep

Gli host tradizionali bruciano denaro facendo girare mondi vuoti 24/7. Zircon Cloud sospende il game loop quando ci sono 0 giocatori online, riprendendo fluidamente alla connessione dei giocatori con il 100% dei dati delle chunk intatti.

Diagnostica Crash Zirky AI

Basato su DeepSeek-V4-Flash. Quando un server crasha a causa di una mod incompatibile o di una libreria mancante, Zirky analizza lo stack trace e genera una scheda di rimedio con 1 click direttamente nella tua console.

Modrinth & CurseForge Nel Browser

Cerca e installa oltre 100.000 mod, modpack, shader e resource pack direttamente nel tuo pannello di controllo web. Niente trasferimenti manuali via FTP o caccia ai jar.

Scrubbing DDoS Enterprise Edge

Tutto il traffico Minecraft in entrata e la telemetria web passano attraverso nodi ridondanti di scrubbing edge, filtrando attacchi volumetrici e pacchetti malevoli prima che raggiungano il container del tuo mondo.

Multiplexing a Porta Singola

Il gameplay di Minecraft (25565) e l'API REST manifest condividono esattamente la stessa porta. I giocatori si connettono a domini puliti come yourserver.zirconmc.net senza numeri di porta richiesti.

Snapshot Cloud LZ4 Automatici

FAQ di Zircon Cloud

Domande frequenti sull'hosting gestito Zircon.

Come funziona la ritenzione Pause-to-Sleep?

Quando l'ultimo giocatore si disconnette dal tuo server, Zircon Cloud avvia un conto alla rovescia di 15 minuti a idle elegante. Se nessun giocatore entra, il container di gioco viene sospeso (Pause-to-Sleep). Tutti gli stati delle chunk, le entità e gli inventari vengono salvati su disco. Quando un giocatore clicca GIOCA nel Zircon Launcher, il nostro proxy edge risveglia l'istanza senza soluzione di continuità per i tuoi giocatori.

I miei amici devono pagare qualcosa per connettersi?

No. Connettersi a un server Zircon Cloud usando il Zircon Launcher è gratuito al 100% per sempre. I giocatori scaricano il launcher client, accedono con il loro account Microsoft ufficiale e cliccano entra.

Posso caricare il mio mondo o modpack esistente?

Sì! Zircon Cloud offre un gestore di file web integrato e un uploader zip. Puoi inserire un salvataggio di mondo esistente, importare uno zip di modpack CurseForge/Modrinth, o migrare direttamente da un server Zircon self-hosted locale con 1 click.

Quali loader e versioni di Minecraft sono supportati?

Zircon Cloud supporta Fabric, Quilt, NeoForge e Forge da Minecraft 1.7 fino alle ultime release moderne. Le istanze Clean Vanilla e Paper/Purpur sono anch'esse pienamente supportate.
