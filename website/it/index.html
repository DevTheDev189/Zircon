Il Modo Zircon: 1 Clic & Play

  • ✓ Zero ricerca file — Il tuo amico ti dà un indirizzo server o un invito LAN locale.
  • ✓ Un clic — Premi PLAY. Zircon controlla la lista mod del server e verifica ogni singolo file.
  • ✓ Download automatico veloce — Le mod mancanti, le configurazioni e le texture vengono scaricate da Modrinth & CurseForge in pochi secondi.
  • ✓ In gioco in pochi secondi — Spawnate insieme immediatamente. Zero trascinamento di cartelle mod.

1. Manifest Crittografico

Il server trasmette la sua esatta Bill of Materials (BOM) sulla porta 25565 — ID mod, hash di versione, loader e configurazioni.

2. Audit Istantaneo degli Hash

Il launcher scansiona la tua istanza locale in millisecondi, saltando i file che possiedi già e segnalando solo quelli mancanti.

3. Recupero Parallelo Verificato

I file mancanti vengono scaricati in parallelo direttamente dalle CDN di Modrinth e CurseForge. Zero JAR corrotti, zero incompatibilità di versione.

Domande Frequenti

Tutto ciò che devi sapere per iniziare con Zircon.

Come sincronizza automaticamente le mod di Minecraft Zircon?

Quando entri in un server e premi PLAY, Zircon confronta il manifest Bill of Materials pubblicato dal server contro la tua cartella client locale. Qualsiasi mod mancante o aggiornata viene verificata tramite hash SHA-512 e fingerprint di Modrinth & CurseForge, quindi scaricata istantaneamente in parallelo senza trascinamento manuale dei file.

Posso migrare le mie istanze da CurseForge, Prism o Modrinth?

Sì! Zircon include un tool nativo di Migrazione Universale con 1 clic. Rileva automaticamente le directory installate da CurseForge, Prism Launcher, Modrinth App e ATLauncher, permettendoti di importare i tuoi alberi di istanza completi, salvataggi, keybind e configurazioni mod in meno di due secondi.

Come funziona la Co-op Locale a Schermo Diviso per 4 Giocatori?

Zircon ti permette di collegare fino a 4 gamepad (controller Xbox, PlayStation o Bluetooth generici) e avviare multiple finestre di gioco isolate disposte in una griglia seamless a schermo diviso sul tuo monitor o TV. Ogni giocatore controlla il proprio personaggio con il proprio gamepad.

Posso usare CurseForge e Modrinth per trovare e scaricare mod?

Sì! Zircon supporta nativamente la ricerca, installazione e sincronizzazione delle mod direttamente sia da Modrinth che da CurseForge con zero configurazione di API key necessaria. Entrambi i repository sono completamente integrati out-of-the-box.

Zircon è gratuito e open source?

Sì, Zircon è source-available sotto la Business Source License 1.1 (BSL 1.1). Sia il launcher client che il server manager self-hosted sono 100% gratuiti per giocatori, homelabber e reti gaming. L'intera codebase è aperta per ispezione pubblica, self-hosting e contributi community su GitHub.

Il mio account Microsoft / Minecraft è sicuro?

Sì. L'autenticazione viene eseguita tramite standard Microsoft OAuth 2.0 PKCE nel tuo browser di sistema predefinito. Le tue credenziali di accesso vanno direttamente ai server di login Microsoft e non sono mai accedute, gestite o archiviate da Zircon.

Quali mod loader e versioni di Minecraft sono supportati?

Zircon supporta nativamente Fabric, Quilt, Forge e NeoForge. Il launcher installa automaticamente la versione richiesta del mod loader e il runtime Java Adoptium Temurin verificato quando avvii un'istanza o entri in un server.
