Häufig gestellte Fragen

Alles, was du über Zircon Launcher, Server Manager, Mod-Synchronisation und Sicherheit wissen musst.

Wie synchronisiert Zircon automatisch Minecraft-Mods?

Wenn du einen Server auswählst und auf PLAY klickst, verbindet sich der Zircon Launcher mit dem Server und ruft dessen kryptografisches Mod-Manifest (BOM) ab. Dieses wird mit deinem lokalen Instanz-Ordner verglichen, SHA-512-Hashes und CurseForge-Fingerprints werden gegen offizielle Repositories verifiziert, und fehlende oder aktualisierte Mods werden automatisch heruntergeladen.

Kann ich CurseForge oder Modrinth nutzen, um Mods zu finden und herunterzuladen?

Ja! Zircon unterstützt nativ sowohl Modrinth als auch CurseForge – ganz ohne API-Schlüssel. Ob beim Konfigurieren einer Instanz im Server Manager oder beim Spielen auf einem Server: Mods aus beiden Repositories werden nahtlos mit automatischer Hash-Verifizierung verarbeitet.

Kann ich Einzelspieler-Offline-Instanzen erstellen?

Ja. Der Launcher enthält einen vollständigen Offline-Instanz-Manager. Du kannst lokale Einzelspieler-Instanzen mit wählbarer Minecraft-Version (1.16 bis neueste), Mod-Loader (Fabric, Quilt, Forge, NeoForge), benutzerdefinierter RAM-Zuweisung und lokalen Mods erstellen.

Wie funktionieren der Skin-Customizer und die Community-Skin-Bibliothek?

Der Skin-Selektor lässt dich aus gespeicherten Skins wählen oder eine eigene PNG hochladen, deinen Charakter in rotierendem Live-3D betrachten (mit Steve- und Alex-Geometrie-Optionen) und direkt mit Mojang synchronisieren. Zusätzlich kannst du in der Community-Skin-Bibliothek Tausende angesagte Community-Skins durchsuchen, die live per API abgerufen werden, und mit einem Klick anwenden.

Wie funktioniert das Single-Port-Multiplexing?

Zircon Server Manager multiplexet sowohl den standardmäßigen Minecraft-Spielverkehr (Port 25565) als auch HTTP-REST-Mod-Manifest-Verkehr über denselben einzelnen Port. Spieler geben einfach einmalig deine Server-Adresse ein (z. B. play.example.com) und der Launcher ruft das Mod-Manifest ab und verbindet das Spiel über Port 25565 – ohne sekundäre Ports erforderlich.

Wie greife ich auf das Admin-Web-Dashboard zu?

Wenn du den Server Manager startest, wird ein Admin-Passwort generiert und in deiner Konsole ausgegeben. Öffne deinen Browser und navigiere zu http://localhost:25564 (oder deiner privaten IP), um dich anzumelden. Aus Sicherheitsgründen halte Port 25564 lokal oder hinter einem VPN/Reverse-Proxy.

Wie funktioniert der Server-Schlaf-/Wach-Modus?

Wenn alle Spieler den Server verlassen, pausiert Zircon den Minecraft-Server-Prozess elegant, um CPU und RAM zu sparen. Wenn ein Spieler in seinem Launcher auf PLAY klickt, weckt eine Pre-Join-Intention den Server auf, bevor der Spieler das Spiel betritt.

Benötige ich einen API-Schlüssel für Modrinth oder CurseForge?

Nein. Sowohl die Modrinth- als auch die CurseForge-Unterstützung sind vorkonfiguriert und direkt in Zircon integriert. Server-Besitzer und Spieler können Mods von beiden Plattformen sofort suchen, herunterladen und synchronisieren – ohne API-Schlüssel oder manuelle Einrichtung.

Wird es verwaltetes Cloud-Hosting geben (Zircon Cloud)?

Ja, verwaltetes Zero-Hardware-Hosting mit proprietärer Pause-to-Sleep-Retention ist auf unserer zukünftigen Roadmap geplant. Heute sind Zircon Launcher und der selbst gehostete Server Manager zu 100 % kostenlos, source-available und bereit, auf deinem eigenen PC, Homelab oder VPS kostenlos zu laufen.

Ist mein Microsoft-Minecraft-Konto sicher?

Ja. Die Authentifizierung erfolgt über standardmäßiges Microsoft OAuth 2.0 PKCE in deinem System-Webbrowser. Deine Anmeldedaten werden direkt an die Microsoft-Login-Server übermittelt. Zircon sieht, verarbeitet oder speichert dein Microsoft-Passwort niemals.

Ist Zircon kostenlos und Open Source?

Ja, Zircon ist kostenlos und source-available unter der Business Source License 1.1 (BSL 1.1). Der gesamte Codebase (Companion-Launcher und selbst gehosteter Server Manager) ist zur öffentlichen Einsicht, Prüfung und persönlichen/Community-Nutzung auf GitHub verfügbar.

Werden heruntergeladene Mods auf Sicherheit überprüft?

Ja. Mod-Dateien werden mit kryptografischen SHA-512-Hashes und CurseForge-murmur2-Fingerprints gegen die offiziellen Modrinth- und CurseForge-APIs verifiziert, bevor sie jemals in deinen aktiven Instanz-Ordner gelangen.

Windows SmartScreen meldet „Windows hat deinen PC geschützt" – was soll ich tun?

Das ist Standard für neue Open-Source-Software, die noch keinen Microsoft-SmartScreen-Zertifikats-Ruf aufgebaut hat. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Du kannst auch den vollständigen Quellcode auf GitHub zur Transparenz einsehen.

Muss ich Java manuell installieren?

Nein. Zircon erkennt automatisch dein System-Java, und wenn eine erforderliche Version (z. B. Java 17 oder Java 21) fehlt, lädt es das verifizierte Eclipse Temurin JDK von Adoptium automatisch herunter und zwischenspeichert es.

Wie weise ich modded Minecraft mehr RAM zu?

Klicke im Zircon Launcher auf das Einstellungen-Symbol in der Seitenleiste. Verwende den Speicherzuweisungs-Schieberegler, um den zugewiesenen RAM anzupassen (4 GB bis 8 GB werden für mittlere bis große Modpacks empfohlen).
