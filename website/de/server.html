Live-Terminal & Farbcodierte Logs

Führe Server-Befehle direkt aus deinem Browser aus mit sofortigem stdout/stderr-Streaming. Filtere Logs nach Info, Warn oder Error, um Mod-Ausnahmen schnell zu isolieren und Spielereignisse zu verfolgen.

  • Live-WebSocket-Stream: Farbcodierte Logs ohne Aktualisungsverzögerung aktualisiert.
  • Befehls-Dispatch: Op-Befehle senden, Gegenstände geben und Zeit verwalten.
  • Log-Level-Filter: Info-, Warn- oder Error-Streams sofort umschalten.

Single-Port & Multi-Server

Spiel-Traffic (25565) und Web-Manifeste laufen auf dem gleichen einzigen Port. Hoste und verwalte mehrere Server oder Modpacks über ein zentrales Browser-Dashboard.

Sleep-When-Empty (RAM sparen)

Wenn niemand online ist, friert der Server die JVM-Ausführung ein, um Host-CPU und RAM zu sparen. Wenn ein Spieler pingt oder in Zircon auf PLAY klickt, wird er automatisch in Millisekunden wiederbelebt.

Wie Port-Multiplexing funktioniert

Traditionelle Server benötigen separate Ports für das Spiel, Web-Manifeste und Admin-Konsolen. Zircon macht es auf Port 25565.

# 1. Zircon Server Manager starten ./zircon-server --port 25565 --admin-port 25564 # Öffentliche Adresse: 25565 (liefert Minecraft-Protokoll + REST-Mod-Manifeste) # Lokales Admin-Panel: http://localhost:25564 (sicheres Dashboard mit generiertem Passwort)
Sicherheit by Design: Das Admin-Dashboard (25564) bleibt lokal oder hinter deinem VPN/Reverse-Proxy. Nur der multiplexed Minecraft-Port (25565) muss an deine Spieler weitergeleitet werden.
