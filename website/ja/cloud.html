アーキテクチャ & 機能

シームレスなマルチプレイのために設計

Linux システム管理者スキルなしで、高性能な MOD 入りコミュニティを運営するために必要なすべて。

Pause-to-Sleep 保持

従来のホスティングは、空の世界を24時間365日稼働させることで資金を浪費します。Zircon Cloud はオンラインプレイヤー数が0の場合にゲームループを一時停止し、プレイヤーが接続するとチャンクデータを100%保持したままスムーズに再開します。

Zirky AI クラッシュ診断

DeepSeek-V4-Flash により駆動。互換性のない MOD やライブラリの欠如によるクラッシュが発生した場合、Zirky がスタックトレースを解析し、コンソール上でワンクリック修復カードを生成します。

Modrinth & CurseForge ブラウザ内統合

Web コントロールパネル内で、10万以上の MOD、MODパック、シェーダー、リソースパックを検索・インストールできます。手動での FTP ファイル転送や jar 探しは不要です。

エンタープライズ級 DDoS エッジスクラブ

すべての Minecraft トラフィックと Web テレメトリは、冗長なエッジスクラブノードを経由し、ワールドコンテナに到達する前にボリューム攻撃や不正パケットをフィルタリングします。

シングルポート多重化

Minecraft ゲームプレイ (25565) と REST マニフェスト API は同じポートを共有します。プレイヤーは yourserver.zirconmc.net のようなクリーンなドメインへ、ポート番号指定なしで接続できます。

自動 LZ4 クラウドスナップショット

高速な LZ4 圧縮ワールドバックアップがスケジュール通りに実行され、ゲームのスタッガーはゼロです。災害が発生した場合でも、ワンクリックで以前のチェックポイントに復元できます。

Zircon Cloud FAQ

管理された Zircon ホスティングに関するよくある質問。

Pause-to-Sleep 保持機能はどのように動作しますか？

最後のプレイヤーがサーバーから切断されると、Zircon Cloud は15分間の優雅なアイドルカウントダウンを開始します。誰も参加しない場合、ゲームコンテナはサスペンド（Pause-to-Sleep）されます。すべてのチャンク状態、エンティティ、インベントリはフラッシュされ、ディスクに保存されます。プレイヤーが Zircon Launcher で PLAY をクリックすると、エッジプロキシがインスタンスをシームレスにウェイクアップさせます。

友達が接続するために何か支払う必要がありますか？

いいえ。Zircon Launcher を使用して Zircon Cloud サーバーに接続することは、永久に100%無料です。プレイヤーはクライアントランチャーをダウンロードし、公式 Microsoft アカウントでサインインして、参加をクリックします。

既存のワールドや MOD パックをアップロードできますか？

はい！Zircon Cloud には統合 Web ファイルマネージャーと ZIP アップローダーが備わっています。既存のワールドセーブをドロップしたり、CurseForge/Modrinth MOD パック ZIP をインポートしたり、ローカルのセルフホスト型 Zircon サーバーからワンクリックで移行したりできます。

どのローダーと Minecraft バージョンがサポートされていますか？

Zircon Cloud は Minecraft 1.7 から最新のモダンリリースまで、Fabric, Quilt, NeoForge, Forge をサポートしています。Clean Vanilla および Paper/Purpur インスタンスも完全にサポートされています。

今日から無料でセルフホスティングを開始

PC または VPS 上で Zircon Server Manager を実行し、MOD の自動同期と Modrinth/CurseForge 検証を行います。

サーバーマネージャーを入手 プレイヤー用ランチャーをダウンロード

MOD 入り Minecraft 向けの無料かつオープンソースのランチャーおよびサーバーマネージャー。 プレイヤーは PLAY を押すだけで、サーバーが実行している正確な MOD を取得 — すべての起動時に Modrinth & CurseForge で検証されます。
