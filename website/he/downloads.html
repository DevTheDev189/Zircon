Zircon Launcher

v0.5.0 · Windows · macOS · Linux
חינמי & קוד פתוח גרסה רב-פלטפורמתית

המפעיל המשלים לשרתי Zircon. התחבר עם Microsoft, הוסף את השרת שלך ולחץ על PLAY — המודים המדויקים מסתנכרנים אוטומטית, מאומתים מול Modrinth & CurseForge.

פלטפורמה מזוהה: Windows
הורד עבור Windows (.exe) מתקין .msi

תואם ל-64-bit Windows 10 ו-11. כולל מתקיני NSIS וחבילות WiX MSI.

הורד עבור macOS (.dmg) חבילת .app (.tar.gz)

דיסק אימג' מקורי של Apple (.dmg). תומך בApple Silicon (M1/M2/M3/M4) ובמחשבי Intel הפועלים עם macOS 11.0 ומעלה.

הורד .AppImage (אוניברסלי) .deb (Debian/Ubuntu) .rpm (Fedora/RHEL)

ה.AppImage הנייד עובד על Arch, Fedora, openSUSE, Ubuntu, Debian ו-Manjaro. חבילות .deb ו.rpm מקוריות זמינות גם כן.

פותחים לראשונה ב-macOS, Windows או Linux? קראו טיפים להגדרה →
Gatekeeper של macOS: אם macOS מציגה הודעה שהאפליקציה לא מאומתת או פגומה, פתחו את הTerminal של המק והריצו:
xattr -cr /Applications/Zircon.app
SmartScreen של Windows: אם מופיע מסך הכחול "Windows protected your PC", לחצו על More info ובחרו Run anyway.
Linux .AppImage: הפכו את ה-AppImage שהורדתם לבן הרצה:
chmod +x Zircon*.AppImage

דרישות מערכת

נתמך בכל מערכות ההפעלה השולחניות העיקריות:

  • Windows 10/11, macOS 11+, או Linux (64-bit x86_64 או Apple Silicon)
  • חשבון Microsoft עם Minecraft: Java Edition — ההתחברות היא הזרם הרשמי של Microsoft
  • מומלץ 4 GB+ RAM לחבילות מודים — המפעיל כולל מחוון RAM מובנה
מה זה עושה בשבילכם: הצטרפות בלחיצה אחת · סנכרון מודים מדויק · הורדות מאומתות מול Modrinth & CurseForge · בידוד פר-שרת · מתאם סקינים עם תצוגה מקדימה 3D · אינסטנסים סינגל-פלייר אופליין · תמיכה בשיידרים וחבילות משאבים.
לא מזוהה עם Mojang או Microsoft. עליכם להיות בעלי Minecraft Java Edition. אין מצב אופליין/לא מאומת למשחק אונליין.

Zircon Server Manager

v0.5.0 · Windows & Linux
ניהול עצמאי מוכן ל-Linux & Windows

הדמון בצד השרת שמאחורי כל שרת Zircon: סנכרון מודים מדויק לשחקנים שלכם, אינטגרציה עם Modrinth & CurseForge, מולטיפלקסר TCP ציבורי יחיד, קונסולה חיה, גיבויים אוטומטיים, ודשבורד ניהול ווב מובנה.

הורד עבור Linux (.tar.gz) Windows (.zip) מקור

מוכן לייצור עבור Ubuntu, Debian, Fedora, RHEL, Arch Linux ו-Windows Server. רץ באופן עצמאי כשירות systemd או כתהליך רקע.

מדריך הגדרה

  1. התקנה — הורידו את המנהל והריצו אותו. סיסמת אדמין מאובטחת נוצרת ומוצגת בקונסולה בהפעלה הראשונה.
  2. פתחו את הדשבורד בכתובת http://localhost:25564 והתחברו עם הסיסמה הזו.
  3. צרו אינסטנס & הוסיפו מודים — המנהל מוריד את JAR השרת עבורכם. קבלו את ה-EULA, בחרו את גרסאות Minecraft & loader, וחפשו & התקינו מודים ישירות מ-Modrinth ו-CurseForge.
  4. הפעילו את השרת — פורט ציבורי אחד (25565) משרת גם Minecraft וגם HTTP. שתפו את הכתובת, ושחקנים מצטרפים עם מודים, מוכנים.
פורטים & firewall: חשפו את 25565 (Minecraft + web multiplexed) והשאירו את דשבורד האדמין 25564 על localhost או מאחורי reverse proxy שלכם.

אחסון מנוהל Zero-Hardware בפיתוח

מעדיפים לא להגדיר port forwarding, כללי NAT firewall, או לתחזק שרת ביתי פיזי? Zircon Cloud יציע אחסון מנוהל turnkey עם שמירת Pause-to-Sleep אוטומטית ואבחונים מבוססי AI בגרסה עתידית. לגרסה v1, בדקו את מנהל השרתים החינמי לניהול עצמאי!

צפה במפת דרכים →

מנוע Pause-to-Sleep

מושהה בצורה נקייה כאשר ריק כדי להפחית עומס על המארח. מתחדש אוטומטית כאשר שחקן לוחץ על התחבר.

קונסולת WebSocket בזמן אמת

גישה לטרמינל החי, טלמטריית CPU/RAM, בעיטות/איסורים של שחקנים, וניהול קבצים מכל דפדפן ווב.

סנכרון מודים אוטומטי

כל השחקנים המשתמשים ב-Zircon Launcher מקבלים אוטומטית מודים, loaders וקונפיגים מאומתים מ-manifest השרת שלכם.

לא בטוחים מה אתם צריכים?

שחקנים מתקינים את הLauncher. בעלי שרתים מריצים את מנהל השרתים לניהול עצמאי Server Manager.
