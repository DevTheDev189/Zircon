Got Questions?

Zircon Cloud FAQ

Frequently asked questions about managed Zircon hosting.

How does Pause-to-Sleep retention work?

When the last player disconnects from your server, Zircon Cloud initiates a graceful 15-minute idle countdown. If no players join, the game container is suspended (Pause-to-Sleep). All chunk state, entities, and inventories are flushed and saved to disk. When a player clicks PLAY in the Zircon Launcher, our edge proxy wakes the instance instantaneously in seconds.

Do my friends have to pay anything to connect?

No. Connecting to a Zircon Cloud server using the Zircon Launcher is 100% free forever. Players download the client launcher, sign in with their official Microsoft account, and click join.

Can I upload my existing world or modpack?

Yes! Zircon Cloud features an integrated web file manager and zip uploader. You can drop in an existing world save, import a CurseForge/Modrinth modpack zip, or migrate directly from a local self-hosted Zircon server with 1 click.

What loaders and Minecraft versions are supported?

Zircon Cloud supports Fabric, Quilt, NeoForge, and Forge from Minecraft 1.7 through the latest modern releases. Clean Vanilla and Paper/Purpur instances are also fully supported.
