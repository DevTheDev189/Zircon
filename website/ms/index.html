1. Manifest Kriptografi

Pelayan menyiarkan Senarai Bahan (BOM) tepat melalui port 25565 — ID mod, hash versi, loader, dan konfigurasi.

2. Audit Hash Segera

3. Penarikan Disahkan Selari

Fail yang hilang dimuat turun secara selari terus dari CDN Modrinth dan CurseForge. Sifarasa JAR rosak, sifarasa ketidakpadanan versi.

Uruskan berbilang pelayan, jimatkan RAM semasa tidur, dan jalankan pada satu port.

Enjin pengurusan hos-sendiri di belakang Zircon. Tiada sakit kepala Docker, tiada mimpi ngeri firewall multi-port. Jalankan pelayan bermod yang pemain anda benar-benar boleh sambung tanpa sokongan teknikal.

  • Multiplexing Port Tunggal (25565): Pek permainan dan manifest mod REST kedua-duanya berjalan pada port lalai 25565. Hanya 1 port untuk dihantar.
  • Tidur Bila Kosong (Penjimatan RAM): Membekukan memori JVM ke CPU 0% apabila 0 pemain dalam talian; hidup semula dalam milisaat apabila pemain ping.
  • Kedai Mod Bersepadu: Pasang mod, shader, dan pakej sumber dengan 1-klik terus dari Modrinth dan CurseForge.
  • Konsol & Pengurusan Pemain Langsung: Log terminal berwarna, penghantaran arahan serta-merta, senarai putih visual, OP, dan sekatan.
  • Sandaran Automatik & Import ZIP Dunia: Snapshot LZ4 berkelajuan tinggi dengan penyimpanan tersuai, rollback 1-klik, dan import dunia seret-dan-tampal.
  • Peta Dunia 2D/3D Langsung: Terokai medan yang dirender, bioma, dan lokasi pemain langsung terus dalam pelayar anda.

Soalan Lazim

Semua yang anda perlu tahu tentang bermula dengan Zircon.

Bagaimana Zircon menyinkronkan mod Minecraft secara automatik?

Apabila anda sertai pelayan dan tekan MAIN, Zircon membandingkan manifest Senarai Bahan yang diterbitkan oleh pelayan terhadap folder klien tempatan anda. Sebarang mod yang hilang atau dikemas kini disahkan melalui hash SHA-512 dan cap jari Modrinth & CurseForge, kemudian dimuat turun serta-merta secara selari tanpa seret fail manual.

Bolehkah saya memigrasikan instens saya dari CurseForge, Prism, atau Modrinth?

Ya! Zircon termasuk alat Migrasi Universal 1-klik asli. Ia mengesan direktori yang dipasang dari CurseForge, Prism Launcher, Modrinth App, dan ATLauncher secara automatik, membolehkan anda mengimport pokok instens lengkap, simpanan, kekunci pintasan, dan konfigurasi mod dalam kurang dari dua saat.

Bagaimana Co-op Sofa Skrin Terbahagi 4-Pemain berfungsi?

Zircon membolehkan anda menyambungkan sehingga 4 gamepad (pengawal Xbox, PlayStation, atau Bluetooth generik) dan melancarkan berbilang tetingkap permainan terasing disusun ke grid skrin terbahagi lancar pada monitor atau TV anda. Setiap pemain mengawal watak mereka sendiri dengan gamepad mereka sendiri.

Bolehkah saya menggunakan CurseForge dan Modrinth untuk mencari dan memuat turun mod?

Ya! Zircon menyokong pencarian, pemasangan, dan penyegerakan mod secara asli terus dari kedua-dua Modrinth dan CurseForge dengan sifarasa konfigurasi kunci API diperlukan. Kedua-dua repositori bersepadu sepenuhnya dari kotak.

Adakah Zircon percuma dan sumber terbuka?

Ya, Zircon tersedia sumber di bawah Lesen Sumber Perniagaan 1.1 (BSL 1.1). Kedua-dua pelancar klien dan pengurus pelayan hos-sendiri adalah 100% percuma untuk pemain, homelabbers, dan rangkaian permainan. Seluruh pangkalan kod terbuka untuk pemeriksaan awam, hos-sendiri, dan sumbangan komuniti di GitHub.

Adakah akaun Microsoft / Minecraft saya selamat?

Ya. Pengesahan dilakukan melalui PKCE OAuth 2.0 Microsoft standard dalam pelayar sistem lalai anda. Kelayakan log masuk anda pergi terus ke pelayan log masuk Microsoft dan tidak pernah diakses, diurus, atau disimpan oleh Zircon.

Loader mod dan versi Minecraft mana yang disokong?

Zircon menyokong Fabric, Quilt, Forge, dan NeoForge secara asli. Pelancar memasang versi loader mod yang diperlukan dan runtime Java Adoptium Temurin disahkan secara automatik apabila anda melancarkan instens atau sertai pelayan.
