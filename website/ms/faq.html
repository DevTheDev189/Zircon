Bantuan & Pangkalan Pengetahuan

Soalan Lazim

Semua yang perlu anda ketahui tentang Zircon Launcher, Pengurus Pelayan, penyegerakan mod, dan keselamatan.

Bagaimana Zircon menyegerakkan mod Minecraft secara automatik?

Apabila anda memilih pelayan dan menekan MAIN, Zircon Launcher akan menyambung ke pelayan tersebut dan mendapatkan manifest mod kriptografi (BOM). Ia membandingkan manifest ini dengan folder instans tempatan anda, mengesahkan hash SHA-512 dan cap jari CurseForge terhadap repositori rasmi, serta memuat turun sebarang mod yang hilang atau dikemas kini secara automatik.

Bolehkah saya menggunakan CurseForge atau Modrinth untuk mencari dan memuat turun mod?

Ya! Zircon menyokong kedua-dua Modrinth dan CurseForge secara asli tanpa memerlukan kunci API. Sama ada mengkonfigurasi instans dalam Pengurus Pelayan atau bermain pada pelayan, mod dari kedua-dua repositori diuruskan dengan lancar melalui pengesahan hash automatik.

Bolehkah saya mencipta instans pemain tunggal luar talian?

Ya. Pelancar ini termasuk pengurus instans luar talian penuh. Anda boleh mencipta instans pemain tunggal tempatan dengan pilihan versi Minecraft (1.16 hingga terkini), pemuat mod (Fabric, Quilt, Forge, NeoForge), peruntukan RAM tersuai, dan mod tempatan.

Bagaimana Pengubahsuai Kulit dan Perpustakaan Kulit Komuniti berfungsi?

Pemilih kulit membolehkan anda memilih daripada kulit yang disimpan atau memuat naik PNG tersuai, melihat pratinjau watak anda dalam 3D berputar langsung (dengan pilihan geometri Steve dan Alex), dan menyegerakkannya terus ke Mojang. Selain itu, Perpustakaan Kulit Komuniti membolehkan anda melayari ribuan kulit komuniti yang trending yang diambil secara langsung melalui API dan menerapkannya dengan satu klik.

Bagaimana multiplexing port tunggal berfungsi?

Zircon Server Manager memultiplekskan kedua-dua trafik permainan Minecraft standard (port 25565) dan trafik manifest mod REST HTTP pada port tunggal yang sama. Pemain hanya perlu memasukkan alamat pelayan anda sekali sahaja (cth: play.example.com) dan pelancar akan mendapatkan manifest mod serta menyambungkan permainan melalui port 25565 tanpa memerlukan port sekunder.

Bagaimana saya mengakses Papan Pemuka Web Admin?

Apabila anda memulakan pengurus pelayan, kata laluan admin dijana dan dicetak ke konsol anda. Buka pelayar web anda dan layari http://localhost:25564 (atau IP peribadi anda) untuk log masuk. Untuk keselamatan, kekalkan port 25564 sebagai lokal atau di belakang VPN/proksi songsang.

Bagaimana mod tidur/bangun pelayan berfungsi?

Apabila semua pemain meninggalkan pelayan, Zircon menjeda proses pelayan Minecraft dengan anggun untuk menjimatkan CPU dan RAM. Apabila mana-mana pemain mengklik MAIN dalam pelancar mereka, niat pra-sertu membangunkan pelayan sebelum pemain memasuki permainan.

Adakah saya memerlukan kunci API untuk Modrinth atau CurseForge?

Tidak. Sokongan untuk kedua-dua Modrinth dan CurseForge telah dikonfigurasikan awal dan dibungkus terus ke dalam Zircon. Pemilik pelayan dan pemain boleh mencari, memuat turun, dan menyegerakkan mod dari kedua-dua platform dengan segera tanpa memerlukan kunci API atau persediaan manual.

Adakah akan ada hosting awan terurus (Zircon Cloud)?

Ya, hosting terurus tanpa perkakasan dengan pengekalan proprietary Pause-to-Sleep dirancang dalam peta jalan masa depan kami. Pada hari ini, Zircon Launcher dan Pengurus Pelayan self-host adalah 100% percuma, sumber tersedia, dan sedia untuk anda jalankan pada PC sendiri, homelab, atau VPS tanpa kos.

Adakah akaun Microsoft Minecraft saya selamat?

Ya. Pengesahan dilakukan melalui Microsoft OAuth 2.0 PKCE standard dalam pelayar web sistem anda. Kelayakan anda dihantar terus ke pelayan log masuk Microsoft. Zircon tidak pernah melihat, mengendalikan, atau menyimpan kata laluan Microsoft anda.

Adakah Zircon percuma dan sumber terbuka?

Ya, Zircon adalah percuma dan sumber tersedia di bawah Business Source License 1.1 (BSL 1.1). Seluruh kod sumber (pelancar pendamping dan pengurus pelayan self-host) tersedia untuk pemeriksaan awam, audit, dan deployment peribadi/komuniti di GitHub.

Adakah mod yang dimuat turun disahkan untuk keselamatan?

Ya. Fail mod disahkan menggunakan hash kriptografi SHA-512 dan cap jari murmur2 CurseForge terhadap API Modrinth dan CurseForge rasmi sebelum ia diletakkan dalam folder instans aktif anda.

Windows SmartScreen berkata "Windows melindungi PC anda" — apa yang harus saya lakukan?

Ini adalah perkara biasa bagi perisian sumber terbuka baharu yang belum membina reputasi sijil Microsoft SmartScreen. Klik Maklumat lanjut dan kemudian klik Jalankan juga. Anda juga boleh memeriksa kod sumber penuh di GitHub untuk ketelusan.

Adakah saya perlu memasang Java secara manual?

Tidak. Zircon mengesan Java sistem anda secara automatik, dan jika versi yang diperlukan (cth: Java 17 atau Java 21) tiada, ia akan memuat turun dan menyimpan cache Eclipse Temurin JDK yang disahkan daripada Adoptium secara automatik.

Bagaimana saya memperuntukkan lebih banyak RAM untuk Minecraft bermotif mod?

Dalam Zircon Launcher, klik ikon Tetapan di bar sisi. Gunakan gelangsar peruntukan memori untuk melaraskan RAM yang diperuntukkan (4 GB hingga 8 GB disyorkan untuk modpack sederhana hingga besar).

Masih mempunyai soalan?
