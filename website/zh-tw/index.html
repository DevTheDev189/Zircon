Zircon 的方式：一鍵即玩

  • ✓ 無需搜尋檔案 — 你的朋友給你一個伺服器地址或本地 LAN 邀請。

啟動器在毫秒內掃描你的本地實例，跳過你已擁有的檔案，僅標記缺失的部分。

常見問題

關於開始使用 Zircon 你需要知道的一切。

Zircon 如何自動同步 Minecraft 模組？

當你加入伺服器並點擊 PLAY 時，Zircon 會將伺服器發布的材料清單 (BOM) 與你的本地客戶端文件夾進行比較。任何缺失或更新的模組都會通過 Modrinth & CurseForge SHA-512 雜湊值和指紋進行驗證，然後無需手動拖拽檔案即可即時平行下載。

我可以從 CurseForge、Prism 或 Modrinth 遷移我的實例嗎？

是的！Zircon 包含一個原生的 1 鍵通用遷移工具。它會自動偵測來自 CurseForge、Prism Launcher、Modrinth App 和 ATLauncher 的已安裝目錄，讓你在不到兩秒鐘的時間內匯入完整的實例樹、存檔、按鍵綁定和模組配置。

4 人分屏沙發合作模式是如何工作的？

Zircon 允許你連接多達 4 個遊戲手柄（Xbox、PlayStation 或通用藍牙控制器）並啟動多個隔離的遊戲窗口，在你的監視器或電視上排列成無縫的分屏網格。每位玩家使用自己的遊戲手柄控制自己的角色。

我可以使用 CurseForge 和 Modrinth 來尋找和下載模組嗎？

是的！Zircon 原生支持直接從 Modrinth 和 CurseForge 搜尋、安裝和同步模組，無需配置任何 API 密鑰。這兩個倉庫都已開箱即用完全整合。

Zircon 是免費且開源的嗎？

是的，Zircon 在商業源許可證 1.1 (BSL 1.1) 下提供源代碼。客戶端啟動器和自託管伺服器管理器對玩家、家庭實驗室用戶和遊戲網絡均 100% 免費。整個代碼庫在 GitHub 上公開供檢查、自託管和社區貢獻。

我的 Microsoft / Minecraft 帳戶安全嗎？

是的。身份驗證通過標準的 Microsoft OAuth 2.0 PKCE 在你的默認系統瀏覽器中執行。你的登錄憑據直接發送到 Microsoft 的登錄服務器，Zircon 從未訪問、處理或存儲它們。

支持哪些模組載入器和 Minecraft 版本？

Zircon 原生支持 Fabric, Quilt, Forge, and NeoForge。當你啟動實例或加入伺服器時，啟動器會自動安裝所需的模組載入器版本和經過驗證的 Adoptium Temurin Java 運行時。
