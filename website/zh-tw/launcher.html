通用一鍵遷移

要從 CurseForge, Prism Launcher, Modrinth App 或 ATLauncher 切換嗎？Zircon 會自動偵測磁碟上已安裝的啟動器配置文件。選擇您的實例並在不到 2 秒內無損匯入到隔離的沙盒中。

  • 無損保留：保留 options.txt、按鍵綁定、世界存檔和自訂材質。
  • 100% 本地與隱私：無外部雲端轉換；完全在您電腦上運行。
  • 即時遊玩：自動分配最佳 Java 執行環境和記憶體參數。

支援手把的 4 人同屏合作

將您的 PC 或客廳電視變成分屏遊戲主機。連接最多 4 個手把（Xbox, PlayStation 或通用藍牙），與朋友和家人並排遊玩 Java 版。

  • 原生手把輸入：流暢的類比搖桿移動、扳機和震動支援。
  • 自動網格排列：整潔的 2 人或 4 人視窗平鋪佈局。
  • 獨立配置文件：每個象限載入各自的角色皮膚和物品欄。

LAN 自動發現與離線世界

與室友或同一 Wi-Fi 下的朋友遊玩？Zircon 自動發現本地伺服器，無需輸入 IP 地址或轉發路由器端口。此外，可建立具有專屬 RAM 分配的隔離離線單人實例。

  • LAN 自動發現：在家用網路中尋找附近的遊戲和 Ping 延遲。
  • 自適應記憶體滑桿：輕鬆為每個實例分配 2 GB 至 32 GB RAM。
  • 自動 Java 解析器：獲取經過驗證的 Eclipse Temurin JDK，無需手動設定路徑。

不再需要搜尋 zip 檔案、解決版本衝突，或花數小時排查崩潰日誌。

一鍵模組化遊玩

點擊 PLAY。Zircon 連接到您的伺服器，比較模組清單，透過 Modrinth & CurseForge 驗證哈希值，並僅平行下載缺失的文件。

2048 與 Discord 狀態顯示

在載入包含 300 個模組的大型模組包時遊玩內建 2048。Discord Rich Presence 自動向您的朋友廣播當前模組包和伺服器資訊。

3D 皮膚工作室與庫

帶有即時 3D 視窗、官方 Mojang 帳戶同步，以及透過 API 即時拉取熱門社群皮膚的應用內社群皮膚瀏覽器之已儲存皮膚選擇器。

UI 客製化與主題

使用自訂顏色強調色、時尚深色調和可配置的視圖密度來個性化啟動器外觀，以匹配您的戰鬥站設置。

離線實例與世界匯入

匯入單人世界並完全離線遊玩，無需互聯網。為每個實例設置自訂 RAM 分配，並將模組包隔離在獨立的沙盒中。

為任何伺服器配置文件添加可選的性能模組、著色器、按鍵綁定和小地圖，而不破壞加密清單同步。
