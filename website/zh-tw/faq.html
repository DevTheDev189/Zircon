常見問題解答

關於 Zircon Launcher、Server Manager、模組同步及安全性，您需要了解的一切。

Zircon 如何自動同步 Minecraft 模組？

當您選擇伺服器並點擊 PLAY 時，Zircon Launcher 會連線至該伺服器並擷取其加密的模組清單 (BOM)。它會將此清單與您的本地實例資料夾進行比對，透過官方儲存庫驗證 SHA-512 雜湊值和 CurseForge 指紋，並自動下載任何缺失或更新的模組。

我可以使用 CurseForge 或 Modrinth 來尋找和下載模組嗎？

是的！Zircon 原生支援 Modrinth 和 CurseForge，且無需任何 API 金鑰。無論是在 Server Manager 中配置實例，還是在伺服器上遊玩，兩個儲存庫的模組都能無縫處理，並具備自動雜湊值驗證功能。

我可以建立單人離線實例嗎？

可以。啟動器內建完整的離線實例管理員。您可以建立本地單人遊戲實例，選擇 Minecraft 版本（從 1.16 到最新版本）、模組載入器（Fabric, Quilt, Forge, NeoForge）、自訂 RAM 分配以及本地模組。

皮膚自訂器和社群皮膚庫是如何運作的？

皮膚選擇器讓您可以從已儲存的皮膚中挑選，或上傳自訂 PNG 檔案，在即時旋轉的 3D 預覽中查看角色（提供 Steve 和 Alex 幾何選項），並直接同步至 Mojang。此外，社群皮膚庫讓您瀏覽透過 API 即時抓取的數千款熱門社群皮膚，並可一鍵套用。

單一埠多工複用是如何運作的？

Zircon Server Manager 在同一個單一埠上同時處理標準的 Minecraft 遊戲流量（埠號 25565）和 HTTP REST 模組清單流量。玩家只需輸入一次伺服器位址（例如 play.example.com），啟動器就會抓取模組清單並透過埠號 25565 連線遊戲，無需使用次要埠號。

我如何存取管理網頁儀表板？

當您啟動伺服器管理器時，系統會生成一個管理密碼並輸出到您的控制台。開啟瀏覽器並前往 http://localhost:25564（或您的私有 IP）進行登入。為了安全起見，請將埠號 25564 保留在本地環境，或將其置於 VPN/反向代理之後。

伺服器的休眠/喚醒模式是如何運作的？

當所有玩家離開伺服器後，Zircon 會優雅地暫停 Minecraft 伺服器程序以節省 CPU 和 RAM。當任何玩家在啟動器中點擊 PLAY 時，預加入意圖會在玩家進入遊戲前喚醒伺服器。

我需要為 Modrinth 或 CurseForge 申請 API 金鑰嗎？

不需要。Modrinth 和 CurseForge 的支援均已預先配置並直接整合進 Zircon。伺服器擁有者和玩家可以立即搜尋、下載和同步來自這兩個平台的模組，完全無需 API 金鑰或手動設定。

未來會有託管雲端服務 (Zircon Cloud) 嗎？

是的，我們未來的路線圖中計畫推出具有專有「暫停即休眠」保留功能的零硬體託管服務。目前，Zircon Launcher 和自架式 Server Manager 均為 100% 免費、原始碼公開，並準備好讓您在自己的 PC、家庭實驗室或 VPS 上以零成本運行。

我的 Microsoft Minecraft 帳戶安全嗎？

是的。身分驗證透過標準的 Microsoft OAuth 2.0 PKCE 在您系統的網頁瀏覽器中執行。您的憑證直接提交給 Microsoft 登入伺服器。Zircon 從未看見、處理或儲存您的 Microsoft 密碼。

Zircon 是免費且開源的嗎？

是的，Zircon 是免費的，並在商業來源授權 1.1 (BSL 1.1) 下提供原始碼。整個程式碼庫（包括配套啟動器和自架式伺服器管理器）均可在 GitHub 上供公眾檢視、稽核以及個人/社群部署。

下載的模組是否經過安全性驗證？

是的。模組檔案在放入您的活動實例資料夾之前，會使用 SHA-512 加密雜湊值和 CurseForge murmur2 指紋，針對官方 Modrinth 和 CurseForge API 進行驗證。

Windows SmartScreen 顯示「Windows 保護了您的電腦」— 我該怎麼辦？

對於尚未建立 Microsoft SmartScreen 憑證信譽的新開源軟體來說，這是標準現象。請點擊 更多資訊，然後點擊 仍要執行。您也可以為了透明度而在 GitHub 上檢視完整原始碼。

我需要手動安裝 Java 嗎？

不需要。Zircon 會自動偵測您系統的 Java，如果缺少所需版本（例如 Java 17 或 Java 21），它會自動從 Adoptium 下載並快取經驗证的 Eclipse Temurin JDK。

我該如何為模組化 Minecraft 分配更多 RAM？

在 Zircon Launcher 中，點擊側邊欄中的 設定 圖示。使用記憶體分配滑桿調整分配的 RAM（建議中型至大型模組包分配 4 GB 至 8 GB）。
