Zircon Cloud 常見問題

關於 Zircon 託管服務的常見問題。

Pause-to-Sleep 狀態保留是如何運作的？

當最後一位玩家從您的伺服器斷線時，Zircon Cloud 會啟動 15 分鐘的優雅閒置倒數計時。如果沒有玩家加入，遊戲容器將被暫停 (Pause-to-Sleep)。所有區塊狀態、實體和物品欄都會刷新並保存到磁碟。當玩家在 Zircon Launcher 中點擊 PLAY 時，我們的邊緣代理會為您的玩家無縫喚醒實例。

我的朋友需要付費才能連線嗎？

不需要。使用 Zircon Launcher 連線到 Zircon Cloud 伺服器永遠是 100% 免費的。玩家下載客戶端啟動器，使用他們的官方 Microsoft 帳號登入，然後點擊加入。

我可以上傳我現有的世界或模組包嗎？

可以！Zircon Cloud 擁有整合的網頁檔案管理器和 zip 上傳器。您可以拖放現有的世界存檔，匯入 CurseForge/Modrinth 模組包 zip，或透過一鍵點擊直接從本地自建的 Zircon 伺服器遷移。

支援哪些載入器和 Minecraft 版本？

Zircon Cloud 支援從 Minecraft 1.7 到最新現代版本的 Fabric、Quilt、NeoForge 和 Forge。純 Vanilla 和 Paper/Purpur 實例也完全受支援。
