Biežāk uzdotie jautājumi

Viss, kas jums jāzina par Zircon Launcher, Server Manager, mod sinhronizāciju un drošību.

Kā Zircon automātiski sinhronizē Minecraft modus?

Kad izvēlaties serveri un nospiežat SPĒLĒT, Zircon Launcher izveido savienojumu ar serveri un iegūst tā kriptogrāfisko mod manifestu (BOM). Tas salīdzina to ar jūsu vietējo instancēs mapi, pārbauda SHA-512 hash vērtības un CurseForge pirkstu nospiedumus pret oficiālajām repozitorijām, un automātiski lejupielādē visus trūkstošos vai atjauninātos modus.

Vai es varu izmantot CurseForge vai Modrinth, lai atrastu un lejupielādētu modus?

Jā! Zircon natīvi atbalsta gan Modrinth, gan CurseForge, bez nepieciešamības pēc API atslēgām. Neatkarīgi no tā, vai konfigurējat instanci Server Manager vai spēlējat uz servera, modus no abām repozitorijām apstrādā nevainojami ar automātisku hash verifikāciju.

Vai es varu izveidot viena spēlētāja offline instances?

Jā. Palaidējā ir iekļauts pilns offline instance manager. Jūs varat izveidot lokālas viena spēlētāja instances, izvēloties Minecraft versiju (no 1.16 līdz jaunākajai), mod loader (Fabric, Quilt, Forge, NeoForge), pielāgotu RAM piešķiršanu un lokālos modus.

Kā darbojas Skin Customizer un Community Skin Library?

Ādas atlasītājs ļauj izvēlēties no saglabātajām ādām vai augšupielādēt pielāgotu PNG, priekšskatīt savu raksturu dzīvā rotējošā 3D (ar Steve un Alex ģeometrijas opcijām) un sinhronizēt tieši ar Mojang. Turklāt Community Skin Library ļauj pārlūkot tūkstošiem populāru kopienas ādu, kas tiek ielādētas reāllaikā caur API, un piemērot tās ar vienu klikšķi.

Kā darbojas vienporta multiplexing?

Zircon Server Manager multiplex gan standarta Minecraft spēles trafiku (ports 25565), gan HTTP REST mod manifestu trafiku uz viena un tā paša porta. Spēlētājiem vienkārši jāievada jūsu servera adrese vienu reizi (piemēram, play.example.com), un palaidējs iegūst mod manifestu un izveido savienojumu spēlei caur portu 25565, neprasa sekundārus portus.

Kā es varu piekļūt Admin Web Dashboard?

Kad sākat server manager, tiek ģenerēta admin parole un izdrukāta jūsu konsolē. Atveriet pārlūkprogrammu un dodieties uz http://localhost:25564 (vai jūsu privāto IP), lai pieslēgtos. Drošības nolūkos turiet portu 25564 lokāli vai aiz VPN/reverse proxy.

Kā darbojas servera miega/modināšanas režīms?

Kad visi spēlētāji pamet serveri, Zircon draudzīgi pauzē Minecraft servera procesu, lai taupītu CPU un RAM. Kad kāds spēlētājs nospiež PLAY savā palaidējā, pirms-pievienošanās nodoms modina serveri pirms spēlētājs ienāk spēlē.

Vai man ir nepieciešama API atslēga Modrinth vai CurseForge?

Nē. Gan Modrinth, gan CurseForge atbalsts ir iepriekš konfigurēts un iepakots tieši Zircon. Serveru īpašnieki un spēlētāji var nekavējoties meklēt, lejupielādēt un sinhronizēt modus no abām platformām, bez nepieciešamības pēc API atslēgām vai manuālas iestatīšanas.

Vai būs pārvaldīts mākoņa hosting (Zircon Cloud)?

Jā, pārvaldīts nulles aparatūras hosting ar proprietāru Pause-to-Sleep saglabāšanu ir plānots mūsu nākotnes ceļvedī. Šodien Zircon Launcher un paš-hosted Server Manager ir 100% bezmaksas, avota-kods ir pieejams, un gatavi, lai jūs tos palaistu savā PC, homelab vai VPS bez maksas.

Vai mans Microsoft Minecraft konts ir drošībā?

Jā. Autentifikācija tiek veikta, izmantojot standarta Microsoft OAuth 2.0 PKCE jūsu sistēmas tīmekļa pārlūkprogrammā. Jūsu akreditācijas dati tiek iesniegti tieši Microsoft login serveriem. Zircon nekad neredz, neapstrādā un neglabā jūsu Microsoft paroli.

Vai Zircon ir bezmaksas un atvērtā pirmkoda?

Jā, Zircon ir bezmaksas un avota-kods ir pieejams saskaņā ar Business Source License 1.1 (BSL 1.1). Vesels koda bāzes (pavadošais palaidējs un paš-hosted server manager) ir pieejams publiskai inspekcijai, auditam un personīgajai/kopienas izvietošanai GitHub.

Vai lejupielādētie modi tiek verificēti drošības nolūkos?

Jā. Mod faili tiek verificēti, izmantojot SHA-512 kriptogrāfiskos hash un CurseForge murmur2 pirkstu nospiedumus pret oficiālajām Modrinth un CurseForge API, pirms tie tiek ievietoti jūsu aktīvajā instance mapē.

Windows SmartScreen saka "Windows aizsargāja jūsu datoru" — ko man darīt?

Tas ir standarta jauniem atvērtā pirmkoda programmatūrām, kas vēl nav izveidojušas Microsoft SmartScreen sertifikāta reputāciju. Noklikšķiniet uz Vairāk informācijas un tad noklikšķiniet uz Palaist tik un tā. Jūs varat arī inspicēt pilnu avota kodu GitHub, lai nodrošinātu pārredzamību.

Vai man ir jāinstalē Java manuāli?

Nē. Zircon automātiski detektē jūsu sistēmas Java, un, ja nepieciešamā versija (piemēram, Java 17 vai Java 21) trūkst, tas automātiski lejupielādē un kešo verificēto Eclipse Temurin JDK no Adoptium.

Kā es varu piešķirt vairāk RAM modificētam Minecraft?

Zircon Launcher noklikšķiniet uz Iestatījumi ikonas sānjoslā. Izmantojiet atmiņas piešķiršanas slīdni, lai pielāgotu piešķirto RAM (4 GB līdz 8 GB ir ieteicams vidēja-lielo modpackiem).
