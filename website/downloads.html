Zircon Launcher

v0.1.0 · Windows 10 / 11
Free & open source ~0.1.0 release

The companion launcher. Sign in with Microsoft, add your server, and hit PLAY — mods sync automatically, verified against Modrinth & CurseForge.

Download for Windows Source

Early development build — releases are published on GitHub. Other platforms are planned as the project matures.

What you need

Three things, then you're set:

  • Windows 10 or 11 with Microsoft Edge WebView2 (preinstalled on modern builds)
  • A Microsoft account with Minecraft: Java Edition — sign-in uses the official OAuth2 + PKCE flow
  • 4 GB+ RAM recommended for modded packs — the launcher includes a RAM slider
What it does for you: one-click join · exact mod sync · hash-verified downloads · per-server isolation · skin customizer with 3D preview · offline single-player instances · shader & resource pack support.
Not affiliated with Mojang or Microsoft. You must own Minecraft Java Edition. There is no offline/unauthenticated mode for online play.

Zircon Server Manager

v0.1.0 · Windows · macOS · Linux
Self-hosted Rust + Axum

The server-side engine: multi-instance, single-port multiplexer, join gate, live console, automated backups, and a bundled admin dashboard.

Download Server Manager Source

Early development build. Binaries are published to GitHub Releases; you can also build from source (below).

Get running in minutes

  1. Install — download the manager and run it. A 16-character admin password is generated and printed to the console on first start.
  2. Open the dashboard at http://localhost:25564 and sign in with that password.
  3. Create an instance — the manager downloads the server JAR for you. Accept the EULA, pick your Minecraft & loader versions, add mods.
  4. Start the server — one public port (25565) serves both Minecraft and HTTP. Share the address, and players join modded, ready.
Ports & firewall: expose 25565 (Minecraft + web multiplexed) and keep the admin dashboard 25564 on localhost or behind your own reverse proxy.

Build from source

Everything lives in one Rust workspace. Requires the Rust toolchain (edition 2021) and Node.js 18+ for the launcher UI.

# Server manager + core
cargo build --workspace
cargo run -p zircon-server

# Companion launcher (Tauri 2 + Vue 3)
cd crates/zircon-launcher
npx @tauri-apps/cli dev

Not sure which one you need?
