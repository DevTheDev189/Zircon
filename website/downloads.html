System Requirements

Supported on all major desktop operating systems:

  • Windows 10/11, macOS 11+, or Linux (64-bit x86_64 or Apple Silicon)
  • A Microsoft account with Minecraft: Java Edition — sign-in is the official Microsoft flow
  • 4 GB+ RAM recommended for modded packs — the launcher includes a built-in RAM slider
What it does for you: one-click join · exact mod sync · Modrinth & CurseForge verified downloads · per-server isolation · skin customizer with 3D preview · offline single-player instances · shader & resource pack support.
Not affiliated with Mojang or Microsoft. You must own Minecraft Java Edition. There is no offline/unauthenticated mode for online play.

Zircon Server Manager

v0.4.11 · Windows & Linux
Self-hosted Linux & Windows Ready

The server-side daemon behind every Zircon server: exact mod sync for your players, Modrinth & CurseForge integration, single public TCP port multiplexer, live console, automated backups, and a bundled web admin dashboard.

Download for Linux (.tar.gz) Windows (.zip) Source

Production ready for Ubuntu, Debian, Fedora, RHEL, Arch Linux and Windows Server. Runs standalone as a systemd service or background process.

Get running in minutes

  1. Install — download the manager and run it. A secure admin password is generated and printed to the console on first start.
  2. Open the dashboard at http://localhost:25564 and sign in with that password.
  3. Create an instance & add mods — the manager downloads the server JAR for you. Accept the EULA, pick your Minecraft & loader versions, and search & install mods directly from Modrinth and CurseForge.
  4. Start the server — one public port (25565) serves both Minecraft and HTTP. Share the address, and players join modded, ready.
Ports & firewall: expose 25565 (Minecraft + web multiplexed) and keep the admin dashboard 25564 on localhost or behind your own reverse proxy.
