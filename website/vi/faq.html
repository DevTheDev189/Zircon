Trợ giúp & Cơ sở kiến thức

Các câu hỏi thường gặp

Mọi thông tin bạn cần biết về Zircon Launcher, Server Manager, đồng bộ mod và bảo mật.

Zircon tự động đồng bộ các mod Minecraft như thế nào?

Khi bạn chọn một server và nhấn CHƠI, Zircon Launcher sẽ kết nối với server đó và tải về manifest mod mã hóa (BOM). Hệ thống so sánh manifest này với thư mục instance cục bộ của bạn, xác minh SHA-512 hashes và dấu vết CurseForge từ các kho lưu trữ chính thức, sau đó tự động tải xuống bất kỳ mod nào bị thiếu hoặc cần cập nhật.

Tôi có thể sử dụng CurseForge hoặc Modrinth để tìm và tải mod không?

Có! Zircon hỗ trợ gốc cả Modrinth và CurseForge mà không cần API keys. Dù là cấu hình instance trong Server Manager hay chơi trên server, các mod từ cả hai nền tảng đều được xử lý liền mạch kèm theo xác minh hash tự động.

Tôi có thể tạo các instance offline cho chế độ một người chơi không?

Có. Launcher bao gồm một trình quản lý instance offline đầy đủ. Bạn có thể tạo các instance cục bộ cho chế độ một người chơi với lựa chọn phiên bản Minecraft (từ 1.16 đến mới nhất), loader mod (Fabric, Quilt, Forge, NeoForge), phân bổ RAM tùy chỉnh và các mod cục bộ.

Skin Customizer và Community Skin Library hoạt động như thế nào?

Trình chọn skin cho phép bạn chọn từ các skin đã lưu hoặc tải lên file PNG tùy chỉnh, xem trước nhân vật trong mô hình 3D xoay trực tiếp (với tùy chọn hình học Steve và Alex), và đồng bộ trực tiếp với Mojang. Ngoài ra, Community Skin Library cho phép bạn duyệt hàng nghìn skin cộng đồng đang thịnh hành được lấy trực tiếp qua API và áp dụng chỉ bằng một cú nhấp chuột.

Cơ chế multiplexing cổng đơn hoạt động như thế nào?

Zircon Server Manager thực hiện multiplexing cả lưu lượng game Minecraft tiêu chuẩn (cổng 25565) và lưu lượng HTTP REST cho manifest mod trên cùng một cổng duy nhất. Người chơi chỉ cần nhập địa chỉ server của bạn một lần (ví dụ: play.example.com) và launcher sẽ tải manifest mod cũng như kết nối game qua cổng 25565 mà không yêu cầu thêm cổng phụ.

Làm cách nào để truy cập Admin Web Dashboard?

Khi bạn khởi động server manager, một mật khẩu quản trị sẽ được tạo và in ra console. Mở trình duyệt và điều hướng tới http://localhost:25564 (hoặc IP riêng tư của bạn) để đăng nhập. Để đảm bảo an toàn, hãy giữ cổng 25564 ở mức cục bộ hoặc đặt sau VPN/reverse proxy.

Chế độ ngủ/thức của server hoạt động như thế nào?

Khi tất cả người chơi rời khỏi server, Zircon tạm dừng quy trình máy chủ Minecraft một cách mượt mà để tiết kiệm CPU và RAM. Khi bất kỳ người chơi nào nhấn CHƠI trong launcher của họ, một ý định tham gia trước sẽ đánh thức server dậy trước khi người chơi vào game.

Tôi có cần API key cho Modrinth hoặc CurseForge không?

Không. Hỗ trợ cho cả Modrinth và CurseForge đều được cấu hình sẵn và tích hợp trực tiếp vào Zircon. Chủ server và người chơi có thể tìm kiếm, tải xuống và đồng bộ mod từ cả hai nền tảng ngay lập tức mà không cần API keys hay thiết lập thủ công.

Sẽ có dịch vụ hosting đám mây được quản lý (Zircon Cloud) chứ?

Có, dịch vụ hosting zero-hardware được quản lý với tính năng giữ lại Pause-to-Sleep độc quyền nằm trong lộ trình tương lai của chúng tôi. Hiện tại, Zircon Launcher và Server Manager tự host hoàn toàn miễn phí, mã nguồn mở và sẵn sàng để bạn chạy trên PC cá nhân, homelab hoặc VPS với chi phí bằng không.

Tài khoản Microsoft Minecraft của tôi có an toàn không?

Có. Xác thực được thực hiện qua tiêu chuẩn Microsoft OAuth 2.0 PKCE trong trình duyệt web hệ thống của bạn. Thông tin đăng nhập của bạn được gửi trực tiếp tới máy chủ đăng nhập của Microsoft. Zircon không bao giờ thấy, xử lý hoặc lưu trữ mật khẩu Microsoft của bạn.

Zircon có miễn phí và mã nguồn mở không?

Có, Zircon miễn phí và mã nguồn mở theo giấy phép Business Source License 1.1 (BSL 1.1). Toàn bộ mã nguồn (bao gồm launcher đi kèm và server manager tự host) đều có sẵn để kiểm tra công khai, kiểm toán và triển khai cá nhân/cộng đồng trên GitHub.

Các mod tải xuống có được xác minh an toàn không?

Có. Các file mod được xác minh bằng SHA-512 cryptographic hashes và murmur2 fingerprints của CurseForge dựa trên các API chính thức của Modrinth và CurseForge trước khi chúng được đưa vào thư mục instance đang hoạt động của bạn.

Windows SmartScreen hiển thị "Windows đã bảo vệ PC của bạn" — tôi nên làm gì?

Đây là tình trạng tiêu chuẩn đối với phần mềm mã nguồn mở mới chưa xây dựng được uy tín chứng nhận Microsoft SmartScreen. Nhấp vào Thêm thông tin và sau đó nhấp vào Vẫn chạy. Bạn cũng có thể kiểm tra toàn bộ mã nguồn trên GitHub để đảm bảo tính minh bạch.

Tôi có cần cài đặt Java thủ công không?

Không. Zircon tự động phát hiện Java trên hệ thống của bạn, và nếu thiếu phiên bản bắt buộc (ví dụ: Java 17 hoặc Java 21), nó sẽ tự động tải xuống và cache Eclipse Temurin JDK đã được xác minh từ Adoptium.

Làm cách nào để phân bổ thêm RAM cho Minecraft có mod?

Trong Zircon Launcher, nhấp vào biểu tượng Cài đặt ở thanh bên. Sử dụng thanh trượt phân bổ bộ nhớ để điều chỉnh RAM được cấp (khuyến nghị 4 GB đến 8 GB cho các modpack vừa và lớn).
