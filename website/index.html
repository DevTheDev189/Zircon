Frequently Asked Questions

Everything you need to know about getting started with Zircon.

How does Zircon automatically sync Minecraft mods?

When you join a server and hit PLAY, Zircon compares the server's published Bill of Materials manifest against your local client folder. Any missing or updated mods are verified via Modrinth & CurseForge SHA-512 hashes and fingerprints, then downloaded instantly in parallel without manual file dragging.

Can I migrate my instances from CurseForge, Prism, or Modrinth?

Yes! Zircon includes a native 1-click Universal Migration tool. It automatically detects installed directories from CurseForge, Prism Launcher, Modrinth App, and ATLauncher, letting you import your complete instance trees, saves, keybinds, and mod configurations in under two seconds.

How does 4-Player Split-Screen Couch Co-op work?

Zircon allows you to connect up to 4 gamepads (Xbox, PlayStation, or generic Bluetooth controllers) and launch multiple isolated game windows arranged into a seamless split-screen grid on your monitor or TV. Each player controls their own character with their own gamepad.

Can I use CurseForge and Modrinth to find and download mods?

Yes! Zircon natively supports searching, installing, and synchronizing mods directly from both Modrinth and CurseForge with zero API key configuration needed. Both repositories are fully integrated out of the box.

Is Zircon free and open source?

Yes, Zircon is source-available under the Business Source License 1.1 (BSL 1.1). Both the client launcher and the self-hosted server manager are 100% free for players, homelabbers, and gaming networks. The entire codebase is open for public inspection, self-hosting, and community contribution on GitHub.

Is my Microsoft / Minecraft account safe?

Yes. Authentication is performed via standard Microsoft OAuth 2.0 PKCE in your default system browser. Your login credentials go directly to Microsoft's login servers and are never accessed, handled, or stored by Zircon.

Which mod loaders and Minecraft versions are supported?

Zircon natively supports Fabric, Quilt, Forge, and NeoForge. The launcher automatically installs the required mod loader version and verified Adoptium Temurin Java runtime when you launch an instance or join a server.
