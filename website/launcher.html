Everything you need

Engineered for seamless modded play

No more hunting zip files, version conflicts, or troubleshooting crash logs for hours.

Zero-Effort Mod Sync

When you hit PLAY, Zircon connects to your server, compares mod manifests, verifies hashes via Modrinth & CurseForge, and installs only missing files.

Official Microsoft Login

Login securely with Microsoft OAuth PKCE in your web browser. Your credentials are sent directly to Microsoft — never stored or touched by Zircon.

3D Skins & Community API

Saved skin selector with 3D viewport, official Mojang account sync, and an online community skin library pulling trending designs live.

Isolated Game Instances

Each server gets its own isolated folder. Mods from Server A will never contaminate or crash Server B or your vanilla installation.

Offline Solo Instances

Build and test your own modpacks locally. Create custom single-player instances with choice of Minecraft version, loader, and dedicated mods.

Auto Shaders & Textures

Servers can automatically offer custom shaders and resource packs. The launcher syncs and applies them so everyone sees the server as intended.
