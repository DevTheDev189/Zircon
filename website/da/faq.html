Hjælp & Vidensbase

Ofte stillede spørgsmål

Alt, du behøver at vide om Zircon Launcher, Server Manager, mod-synkronisering og sikkerhed.

Hvordan synkroniserer Zircon automatisk Minecraft mods?

Når du vælger en server og trykker på SPIL, opretter Zircon Launcher forbindelse til serveren og henter dens kryptografiske mod-manifest (BOM). Den sammenligner dette med din lokale instansmappe, verificerer SHA-512 hashes og CurseForge fingeraftryk mod officielle repositories, og downloader automatisk alle manglende eller opdaterede mods.

Kan jeg bruge CurseForge eller Modrinth til at finde og downloade mods?

Ja! Zircon understøtter begge dele nativt: Modrinth og CurseForge uden behov for API-nøgler. Uanset om du konfigurerer en instans i Server Manager eller spiller på en server, håndteres mods fra begge repositories sømløst med automatisk hash-verifikation.

Kan jeg oprette offline single-player instanser?

Ja. Launcher indeholder en fuld offline instans-manager. Du kan oprette lokale single-player instanser med valg af Minecraft-version (fra 1.16 til nyeste), mod-loader (Fabric, Quilt, Forge, NeoForge), tilpasset RAM-allokering og lokale mods.

Hvordan fungerer Skin Customizer og Community Skin Library?

Skin-vælgeren lader dig vælge mellem gemte skins eller uploade et custom PNG, forhåndsvise din karakter i live roterende 3D (med Steve og Alex geometri-muligheder) og synkronisere direkte til Mojang. Derudover lader Community Skin Library dig browse gennem tusindvis af trendende community skins hentet live via API og anvende dem med ét klik.

Hvordan fungerer single-port multiplexing?

Zircon Server Manager multiplexer både standard Minecraft-spiltrafik (port 25565) og HTTP REST mod-manifest-trafik på den samme enkelte port. Spillere indtaster blot din serveradresse én gang (f.eks. play.example.com), og launcher henter mod-manifestet og forbinder spillet over port 25565 uden behov for sekundære porte.

Hvordan får jeg adgang til Admin Web Dashboard?

Når du starter server manager, genereres en admin-adgangskode og udskrives til din konsol. Åbn din browser og navigér til http://localhost:25564 (eller din private IP) for at logge ind. Af sikkerhedsmæssige årsager bør port 25564 holdes lokal eller bag en VPN/reverse proxy.

Hvordan fungerer serverens sleep/wake-tilstand?

Når alle spillere forlader serveren, sætter Zircon Minecraft-serverprocessen elegant på pause for at skåne CPU og RAM. Når en spiller klikker SPIL i deres launcher, vækkes serveren op af en pre-join-intent, før spilleren træder ind i spillet.

Har jeg brug for en API-nøgle til Modrinth eller CurseForge?

Nej. Både Modrinth og CurseForge-understøttelse er forkonfigureret og bundtet direkte ind i Zircon. Serverejere og spillere kan søge, downloade og synkronisere mods fra begge platforme med det samme uden behov for API-nøgler eller manuel opsætning.

Vil der være administreret cloud-hosting (Zircon Cloud)?

Ja, administreret zero-hardware hosting med proprietær Pause-to-Sleep-retention er planlagt på vores fremtidige roadmap. I dag er Zircon Launcher og den selvhostede Server Manager 100% gratis, kilde-tilgængelig og klar til at køre på din egen PC, homelab eller VPS uden omkostninger.

Er min Microsoft Minecraft-konto sikker?

Ja. Autentificering udføres via standard Microsoft OAuth 2.0 PKCE i din systemwebbrowser. Dine legitimationsoplysninger sendes direkte til Microsofts login-servere. Zircon ser, håndterer eller gemmer aldrig din Microsoft-adgangskode.

Er Zircon gratis og open source?

Ja, Zircon er gratis og kilde-tilgængelig under Business Source License 1.1 (BSL 1.1). Hele kodebasen (den ledsagende launcher og den selvhostede server manager) er tilgængelig til offentlig inspektion, revision og personlig/community-deployment på GitHub.

Verificeres downloadede mods for sikkerhed?

Ja. Mod-filer verificeres ved hjælp af SHA-512 kryptografiske hashes og CurseForge murmur2 fingeraftryk mod officielle Modrinth og CurseForge APIs, før de nogensinde placeres i din aktive instansmappe.

Windows SmartScreen siger "Windows beskyttede din pc" — hvad skal jeg gøre?

Dette er standard for ny open-source software, der endnu ikke har opbygget Microsoft SmartScreen-certifikat omdømme. Klik på Flere oplysninger og derefter på Kør alligevel. Du kan også inspicere hele kildekoden på GitHub for transparens.

Skal jeg installere Java manuelt?

Nej. Zircon registrerer automatisk dit systems Java, og hvis en nødvendig version (f.eks. Java 17 eller Java 21) mangler, downloader og cacher den automatisk den verificerede Eclipse Temurin JDK fra Adoptium.

Hvordan allokerer jeg mere RAM til modded Minecraft?

I Zircon Launcher skal du klikke på Indstillinger-ikonet i sidepanelet. Brug hukommelsesallokeringsskyderen til at justere allokering af RAM (4 GB til 8 GB anbefales til mellemstore til store modpacks).
