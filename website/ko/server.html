서버 소유자 및 호스트를 위한

모드 서버 호스팅
친구들이 실제로 접속할 수 있습니다.

Zircon의 자체 호스팅 엔진: 플레이어에게 정확한 모드 매니페스트를 게시하고, 게임 및 웹 트래픽을 단일 포트에서 멀티플렉싱하며, 완전한 브라우저 대시보드를 포함합니다.

서버 관리자 가져오기 호스팅 가이드 읽기
시스템 통계 & 다중 인스턴스
대시보드 & 통계: 모든 서버 인스턴스에서 실시간 CPU, RAM 및 틱 속도 모니터링.
CurseForge & Modrinth 검색
통합 모드 브라우저: Modrinth 및 CurseForge에서 종속성 해결과 API 키 불필요로 모드를 검색하고 원클릭으로 설치하세요.
실시간 대화형 터미널
실시간 콘솔: 명령어를 전송하고, 색상으로 구분된 로그를 검토하며, 경고 또는 오류 스택을 필터링하세요.
셰이더 & 리소스 팩
비주얼 팩: 추천 셰이더 및 텍스처 팩을 관리하여 접속하는 플레이어에게 자동으로 동기화합니다.
웹 파일 관리자 & BOM 동기화
파일 관리자: 서버 디렉터리를 탐색하고, 파일을 업로드하며, "BOM에 동기화"로 클라이언트 동기화 항목을 표시하세요.
브라우저 내 설정 편집기
웹 코드 편집기: 키보드 단축키와 즉각적인 클라이언트 동기화로 server.properties, JSON 설정 및 게임 파일을 편집하세요.
플레이어, 운영자 & 화이트리스트
플레이어 제어: 화이트리스트 사용자, 운영자 권한 수준 및 금지 목록을 시각적으로 관리하세요.
자동 백업 & 월드 ZIP 가져오기
자동 스냅샷 & ZIP: 구성 가능한 보존 기간이 있는 예약된 LZ4 백업, 드래그 앤 드롭 .zip 월드 가져오기 및 원클릭 복원.
실시간 2D/3D 월드 맵 & 플레이어 레이더
실시간 월드 맵: 브라우저에서 직접 렌더링된 지형, 생물군계 및 실시간 플레이어 위치 핀을 탐색하세요.
서버 설정 & 슬립 트리거
서버 설정: 포트 멀티플렉싱 구성, 내장된 Modrinth 및 CurseForge 통합 및 유휴 상태 슬립 타임아웃 규칙.

실시간 터미널 & 색상 로그

즉각적인 stdout/stderr 스트리밍으로 브라우저에서 서버 명령어를 직접 실행하세요. Info, Warn 또는 Error로 로그를 필터링하여 모드 예외를 빠르게 격리하고 게임 이벤트를 추적하세요.

  • 실시간 WebSocket 스트림: 새로고침 지연 없이 업데이트되는 색상 코딩된 로그.
  • 명령어 디스패치: op 명령어 전송, 아이템 지급 및 시간 관리.
  • 로그 레벨 필터: Info, Warning 또는 Error 스트림을 즉시 전환하세요.
실시간 터미널 콘솔

웹 파일 관리자 & 설정 편집기

외부 FTP 클라이언트나 SSH 세션이 필요 없습니다. 인스턴스 파일을 탐색하고, 내장된 구문 강조 편집기로 server.properties 및 JSON 설정을 편집하며, "클라이언트에 동기화"를 사용하여 설정을 플레이어 런처에 직접 전파하세요.

  • 브라우저 내 편집기: 구문 강조 및 키보드 단축키(Ctrl+S).
  • 원클릭 클라이언트 동기화: 수정된 설정을 플레이어에게 바로 배포하세요.
  • 업로드 & 추출: ZIP 팩 및 커스텀 모드 JAR을 쉽게 업로드하세요.
server.properties 편집기

지원 티켓 없음. 버전 충돌 없음.

서버가 모드, 셰이더 및 설정을 결정합니다. 플레이어는 PLAY를 클릭하고 동기화된 상태로 생성됩니다.

단일 포트 & 다중 서버

게임 트래픽(25565)과 웹 매니페스트가 동일한 단일 포트에서 실행됩니다. 하나의 중앙 집중식 브라우저 대시보드에서 여러 서버 또는 모드팩을 호스팅하고 관리하세요.

비어 있을 때 슬립(RAM 절약)

아무도 온라인이 아닐 때, 서버는 호스트 CPU와 RAM을 절약하기 위해 JVM 실행을 동결합니다. 플레이어가 ping을 하거나 Zircon에서 PLAY를 누르면 밀리초 단위로 자동으로 복구됩니다.

Modrinth & CurseForge 스토어

웹 패널 내에서 모드, 셰이더 및 리소스 팩을 직접 검색하고 원클릭으로 설치하세요. 자동 종속성 해결 및 API 키 불필요.

실시간 웹 콘솔 & 플레이어

명령어를 실행하고, 실시간으로 색상 코딩된 Minecraft 서버 로그를 스트리밍하며, 화이트리스트, 운영자 권한 및 플레이어 금지를 시각적으로 관리하세요.

파일 스튜디오 & 월드 ZIP 가져오기

구문 강조로 브라우저에서 server.properties 및 JSON 파일을 편집하세요. .zip 파일에서 전체 월드를 드래그 앤 드롭으로 가져오고 변경 사항을 클라이언트에 즉시 푸시하세요.

월드 맵 & 성능 지표

렌더링된 지형, 생물군계 및 실시간 플레이어 위치 핀을 초당 단위 CPU, RAM 및 틱 속도(TPS) 모니터링 그래프와 함께 검사하세요.

포트 멀티플렉싱 작동 방식

전통적인 서버는 게임, 웹 매니페스트 및 관리자 콘솔에 별도의 포트가 필요합니다. Zircon은 포트 25565에서 이를 수행합니다.

# 1. Zircon 서버 관리자 시작 ./zircon-server --port 25565 --admin-port 25564 # 공개 주소: 25565 (Minecraft 프로토콜 + REST 모드 매니페스트 제공) # 로컬 관리자 패널: http://localhost:25564 (생성된 비밀번호가 포함된 보안 대시보드)
설계 단계부터 보안: 관리자 대시보드(25564)는 로컬 또는 VPN/리버스 프록시 뒤에 유지됩니다. 플레이어에게는 멀티플렉싱된 Minecraft 포트(25565)만 포워딩하면 됩니다.

서버를 실행할 준비가 되셨나요?

무료 자체 호스팅 관리자를 다운로드하고 Minecraft 서버를 완전히 제어하세요.
