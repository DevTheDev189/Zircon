도움말 & 지식 베이스

자주 묻는 질문

Zircon Launcher, 서버 관리자, 모드 동기화 및 보안에 대해 알아야 할 모든 정보.

Zircon은 Minecraft 모드를 자동으로 어떻게 동기화하나요?

서버를 선택하고 PLAY 버튼을 누르면, Zircon 런처가 서버에 연결하여 암호화된 모드 매니페스트(BOM)를 가져옵니다. 이를 로컬 인스턴스 폴더와 비교하고, 공식 저장소에 대한 SHA-512 해시 및 CurseForge 지문을 검증한 후, 누락되거나 업데이트된 모드를 자동으로 다운로드합니다.

CurseForge 또는 Modrinth를 사용하여 모드를 찾고 다운로드할 수 있나요?

네! Zircon은 API 키 없이 Modrinth와 CurseForge를 모두 네이티브로 지원합니다. 서버 관리자에서 인스턴스를 구성하거나 서버에서 플레이할 때, 두 저장소의 모드는 자동 해시 검증을 통해 원활하게 처리됩니다.

오프라인 싱글 플레이어 인스턴스를 만들 수 있나요?

네. 런처에는 완전한 오프라인 인스턴스 관리자가 포함되어 있습니다. Minecraft 버전(1.16부터 최신 버전까지), 모드 로더(Fabric, Quilt, Forge, NeoForge), 사용자 지정 RAM 할당량 및 로컬 모드를 선택하여 로컬 싱글 플레이어 인스턴스를 만들 수 있습니다.

스킨 커스터마이저와 커뮤니티 스킨 라이브러리는 어떻게 작동하나요?

스킨 선택기를 통해 저장된 스킨을 선택하거나 사용자 지정 PNG를 업로드하고, Steve 및 Alex 기하학 옵션으로 실시간 회전하는 3D 미리보기를 확인하며, Mojang과 직접 동기화할 수 있습니다. 또한, 커뮤니티 스킨 라이브러리를 통해 API로 실시간 가져온 수천 개의 인기 커뮤니티 스킨을 탐색하고 원클릭으로 적용할 수 있습니다.

단일 포트 멀티플렉싱은 어떻게 작동하나요?

Zircon Server Manager는 표준 Minecraft 게임 트래픽(포트 25565)과 HTTP REST 모드 매니페스트 트래픽을 동일한 단일 포트에서 멀티플렉싱합니다. 플레이어는 서버 주소(예: play.example.com)를 한 번만 입력하면 되며, 런처는 모드 매니페스트를 가져오고 보조 포트 없이 포트 25565를 통해 게임에 연결합니다.

관리자 웹 대시보드에 어떻게 접속하나요?

서버 관리자를 시작하면 관리자 비밀번호가 생성되어 콘솔에 출력됩니다. 브라우저에서 http://localhost:25564(또는 개인 IP)로 이동하여 로그인하세요. 보안을 위해 포트 25564는 로컬로 유지하거나 VPN/리버스 프록시 뒤에 배치하세요.

서버 슬립/웨이크 모드는 어떻게 작동하나요?

모든 플레이어가 서버를 떠나면 Zircon은 CPU 및 RAM을 절약하기 위해 Minecraft 서버 프로세스를 우아하게 일시 중지합니다. 플레이어가 런처에서 PLAY를 클릭하면, 게임에 입장하기 전에 서버가 웨이크업됩니다.

Modrinth 또는 CurseForge에 API 키가 필요한가요?

아니요. Modrinth와 CurseForge 지원은 사전 구성되며 Zircon에 직접 번들링됩니다. 서버 소유자와 플레이어는 API 키나 수동 설정 없이 즉시 두 플랫폼에서 모드를 검색, 다운로드 및 동기화할 수 있습니다.

관리형 클라우드 호스팅(Zircon Cloud)이 제공되나요?

네, 독점적인 Pause-to-Sleep 보존 기능을 갖춘 관리형 제로 하드웨어 호스팅이 향후 로드맵에 계획되어 있습니다. 현재 Zircon Launcher와 셀프 호스팅 서버 관리자는 100% 무료이며 소스 공개 상태로, PC, 홈랩 또는 VPS에서 비용 없이 실행할 준비가 되어 있습니다.

제 Microsoft Minecraft 계정은 안전한가요?

네. 인증은 시스템 웹 브라우저에서 표준 Microsoft OAuth 2.0 PKCE를 통해 수행됩니다. 자격 증명은 Microsoft 로그인 서버로 직접 제출됩니다. Zircon은 Microsoft 비밀번호를 절대 보거나 처리하거나 저장하지 않습니다.

Zircon은 무료이고 오픈 소스인가요?

네, Zircon은 Business Source License 1.1 (BSL 1.1)에 따라 무료이며 소스 공개 상태입니다. 전체 코드베이스(컴패니언 런처 및 셀프 호스팅 서버 관리자)는 GitHub에서 공개 검사, 감사 및 개인/커뮤니티 배포용으로 제공됩니다.

다운로드된 모드의 안전성이 검증되나요?

네. 모드 파일은 활성 인스턴스 폴더에 배치되기 전에 공식 Modrinth 및 CurseForge API에 대해 SHA-512 암호화 해시 및 CurseForge murmur2 지문으로 검증됩니다.

Windows SmartScreen에서 "Windows가 PC를 보호했습니다"라고 표시되면 어떻게 해야 하나요?

이는 아직 Microsoft SmartScreen 인증서 평판을 쌓지 않은 새로운 오픈 소스 소프트웨어에서는 일반적인 현상입니다. 추가 정보를 클릭한 다음 그래도 실행을 클릭하세요. 투명성을 위해 GitHub에서 전체 소스 코드를 확인할 수도 있습니다.

Java를 수동으로 설치해야 하나요?

아니요. Zircon은 시스템 Java를 자동으로 감지하며, 필요한 버전(예: Java 17 또는 Java 21)이 없는 경우 Adoptium에서 검증된 Eclipse Temurin JDK를 자동으로 다운로드하고 캐시합니다.

모드 적용된 Minecraft에 더 많은 RAM을 할당하려면 어떻게 해야 하나요?

Zircon Launcher에서 사이드바의 설정 아이콘을 클릭하세요. 메모리 할당 슬라이더를 사용하여 할당된 RAM을 조정합니다(중대형 모드팩의 경우 4 GB ~ 8 GB 권장).

여전히 궁금한 점이 있으신가요?

단계별 문서 가이드를 확인하거나 GitHub에서 오픈 소스 커뮤니티에 참여하세요.
