범용 원클릭 마이그레이션

CurseForge, Prism Launcher, Modrinth App 또는 ATLauncher에서 전환하시나요? Zircon은 디스크에 설치된 런처 프로필을 자동으로 감지합니다. 인스턴스를 선택하면 2초 이내에 격리된 샌드박스로 무손실 가져오기가 완료됩니다.

  • 무손실 보존: options.txt, 키 바인딩, 월드 및 커스텀 텍스처를 유지합니다.
  • 100% 로컬 & 프라이빗: 외부 클라우드 변환 없음; 전적으로 PC에서 실행됩니다.
  • 즉시 플레이: 최적의 Java 런타임 및 메모리 플래그를 자동으로 할당합니다.
범용 런처 임포터

게임패드를 활용한 4인 소파 협동 플레이

PC나 거실 TV를 분할 화면 게임 콘솔로 바꿔보세요. 최대 4개의 게임패드(Xbox, PlayStation 또는 범용 Bluetooth)를 연결하여 친구 및 가족과 나란히 Java 에디션을 플레이하세요.

  • 네이티브 게임패드 입력: 부드러운 아날로그 스틱 이동, 트리거 및 진동 지원.
  • 자동 그리드 배열: 깔끔한 2인 또는 4인 뷰포트 창 타일링.
  • 독립적인 프로필: 각 사분면에 고유한 캐릭터 스킨 및 인벤토리를 로드합니다.
4인 소파 협동 컨트롤러 설정

저장된 스킨 선택기 & 커뮤니티 라이브러리

저장된 캐릭터 스킨 중에서 선택하거나 실시간 회전 3D 뷰포트와 함께 커스텀 PNG를 업로드하세요. 새로운 영감이 필요하신가요? API를 통해 직접 가져온 수천 개의 인기 커뮤니티 스킨을 탐색하고 클릭 한 번으로 적용하세요.

  • 라이브 3D 뷰포트: 클래식 Steve와 슬림 Alex 지오메트리를 3D로 미리보기.
  • 커뮤니티 API 라이브러리: 수천 개의 인기 커뮤니티 스킨을 실시간으로 검색.
  • Mojang 계정 동기화: 클릭 한 번으로 스킨을 공식 Minecraft 서버에 푸시합니다.
스킨 커스터마이저

LAN 자동 발견 & 오프라인 월드

같은 Wi-Fi 네트워크에서 룸메이트나 친구들과 플레이하시나요? Zircon은 IP 주소 입력이나 라우터 포트 포워딩 없이 로컬 서버를 자동으로 발견합니다. 또한 전용 RAM 할당을 통해 격리된 오프라인 싱글플레이 인스턴스를 구축하세요.

  • LAN 자동 발견: 홈 네트워크에서 근처 게임과 핑 지연 시간을 찾습니다.
  • 적응형 메모리 슬라이더: 인스턴스별로 2GB에서 32GB까지 RAM을 쉽게 할당하세요.
  • 자동 Java 리졸버: 수동 경로 설정 없이 검증된 Eclipse Temurin JDK를 가져옵니다.

매끄러운 모드 플레이를 위해 설계됨

더 이상 zip 파일을 뒤지거나, 버전 충돌을 해결하거나, 몇 시간씩 크래시 로그를 분석하지 마세요.

원클릭 모드 플레이

PLAY 버튼을 누르세요. Zircon이 서버에 연결하고, 모드 매니페스트를 비교하며, Modrinth 및 CurseForge를 통해 해시를 검증하고, 병렬로 누락된 파일만 다운로드합니다.

2048 & Discord 상태 표시

300개 이상의 대규모 모드팩이 로드되는 동안 내장된 2048 게임을 하세요. Discord Rich Presence가 현재 모드팩과 서버 정보를 친구들에게 자동으로 공유합니다.

3D 스킨 스튜디오 & 라이브러리

라이브 3D 뷰포트, 공식 Mojang 계정 동기화, 그리고 API를 통해 실시간으로 인기 커뮤니티 스킨을 가져오는 앱 내 커뮤니티 스킨 탐색기를 갖춘 저장된 스킨 선택기.

UI 커스터마이징 & 테마

커스텀 색상 액센트, 세련된 다크 팔레트, 그리고 배틀스테이션 설정에 맞는 구성 가능한 뷰 밀도로 런처 외관을 개인화하세요.

오프라인 인스턴스 & 월드 가져오기

싱글플레이 월드를 가져오고 인터넷 없이 완전히 오프라인으로 플레이하세요. 인스턴스별로 커스텀 RAM 할당을 설정하고 모드팩을 별도의 샌드박스로 격리하세요.

클라이언트 측 서버 튜닝

암호화 매니페스트 동기화를 깨뜨리지 않고 모든 서버 프로필에 선택적 성능 모드, 셰이더, 키바인드 및 미니맵을 추가하세요.
