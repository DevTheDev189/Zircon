Zircon 방식: 원클릭 & 플레이

  • ✓ 파일 탐색 제로 — 친구가 서버 주소나 로컬 LAN 초대장을 알려줍니다.
  • ✓ 원클릭 — PLAY 버튼을 누르세요. Zircon이 서버의 모드 목록을 확인하고 모든 파일을 검증합니다.
  • ✓ 자동 고속 다운로드 — 누락된 모드, 설정, 텍스처가 Modrinth & CurseForge에서 수 초 만에 가져옵니다.
  • ✓ 수 초 만에 게임 내 입장 — 즉시 함께 스폰됩니다. 모드 폴더 드래그 앤 드롭이 필요 없습니다.

1. 암호화 매니페스트

서버는 포트 25565를 통해 정확한 자재 목록(BOM)을 브로드캐스트합니다 — 모드 ID, 버전 해시, 로더, 설정 등.

2. 즉각적인 해시 감사

런처는 밀리초 단위로 로컬 인스턴스를 스캔하여 이미 보유한 파일은 건너뛰고 누락된 파일만 표시합니다.

3. 병렬 검증된 가져오기

누락된 파일은 Modrinth 및 CurseForge CDN에서 병렬로 직접 다운로드됩니다. 손상된 JAR 파일이나 버전 불일치가 없습니다.

암호화 모드 동기화 & 검증 엔진

CurseForge 또는 Prism에서 전환하시나요? 모든 것을 원클릭으로 가져오세요.

월드, 키 바인딩, 모드팩 인스턴스를 포기하지 마세요. Zircon은 설치된 런처를 자동으로 감지하고 2초 이내에 손실 없이 마이그레이션합니다.

CurseForge

모드팩, 오버라이드, 사용자 지정 설정 및 월드 저장을 자동으로 감지합니다.

Prism Launcher

인스턴스 트리, JVM 인수 및 월드 저장을 가져옵니다.

Modrinth App

MR 팩, 인덱스 파일 및 사용자 지정 리소스 팩을 보존합니다.

ATLauncher

인스턴스, 사용자 지정 백업 및 텍스처 팩 폴더를 전송합니다.

데이터 손실 제로. 수동 파일 드래그 제로.

Zircon을 실행하면 네이티브 Rust 디텍터가 시스템에 설치된 프로필을 찾습니다. 가져올 인스턴스를 선택하면 Zircon이 모든 것을 깔끔하고 격리된 샌드박스로 마이그레이션합니다.

  • 100% 오프라인 로컬 감지: 외부 클라우드 업로드 없이 표준 디스크 디렉터리를 스캔합니다.
  • 완전한 인스턴스 보존: 정확한 키 바인딩, options.txt, 리소스 팩 및 월드를 그대로 유지합니다.
  • 즉시 빠른 실행: 일치하는 Java 버전과 최적의 메모리 플래그를 자동으로 구성합니다.

친구에게 컨트롤러를 건네주세요. 소파에서 플레이하세요.

PC나 거실 TV를 분할 화면 콘솔로 만드세요. 최대 4개의 Xbox, PlayStation 또는 일반 Bluetooth 게임패드를 연결하고 별도의 인벤토리, 뷰포트, 스킨으로 모드가 적용된 Java 에디션을 나란히 플레이하세요.

  • 플러그 앤 플레이 게임패드: Xbox, PlayStation & Bluetooth 컨트롤러로 부드러운 아날로그 스틱 움직임.
  • 자동 분할 화면: 깔끔한 2인 수평/수직 또는 4인 사분면 창 타일링.
  • 별도 플레이어 프로필: 각 플레이어는 자신의 캐릭터 스킨과 별도 인벤토리를 사용합니다.
4인 소파 협동 플레이 게임패드 설정

라이브 3D 미리보기로 게임 내에서 멋지게 보이세요.

게임을 로드하기 전에 스킨이 어떻게 보일지 추측하는 것을 멈추세요. 실시간 3D로 캐릭터를 회전하고, API를 통해 직접 가져온 수천 개의 인기 커뮤니티 스킨을 검색하며, 원클릭으로 공식 Mojang 서버와 동기화하세요.

  • 회전식 3D 뷰포트: 망토 미리보기가 포함된 라이브 Steve(클래식) 및 Alex(슬림) 지오메트리.
  • 인기 커뮤니티 라이브러리: 수천 개의 스킨을 검색하고 몇 초 만에 적용하세요.
  • 원클릭 Mojang 동기화: 활성 스킨을 공식 Minecraft 서버로 직접 푸시합니다.
3D 스킨 스튜디오 & Mojang 동기화

Wi-Fi 친구를 즉시 찾으세요. 코드로 참여하세요.

복사-붙여넣기 할 IP 주소가 없습니다. Hamachi 가상 네트워크가 없습니다. 라우터 방화벽 포트를 열 필요가 없습니다. 로컬 Wi-Fi에서 누군가가 월드나 서버를 실행하면 자동으로 팝업됩니다. 인터넷으로 플레이하시나요? 자동화된 UPnP 포트 포워딩으로 6자리 참여 코드를 공유하세요.

  • 로컬 Wi-Fi 자동 발견: 네트워크 전반에서 가까운 게임을 즉시 브로드캐스트하고 감지합니다.
  • 6자리 참여 코드 & UPnP: 수동 라우터 구성 없이 인터넷으로 연결하세요.
  • 라이브 핑 & 플레이어 수: 클릭하여 참여하기 전에 플레이어 수와 지연 시간을 확인하세요.
LAN 자동 발견 & 가까운 게임

300개 모드 팩이 로드되는 동안 2048을 플레이하세요.

더 이상 얼어붙은 Minecraft 로딩 화면을 응시하지 마세요. 거대한 Forge 또는 Fabric 팩이 텍스처를 초기화하는 동안 런처 창에서 내장 2048을 플레이하세요. 게임 로딩이 끝나면 바로 진입하세요. Discord Rich Presence가 친구들에게 당신이 무엇을 플레이하고 있는지 정확히 보여줍니다.

  • 내장 2048 미니 게임: 완전한 키보드 제어, 지속되는 최고 점수, 그리고 제로 메모리 오버헤드.
  • Discord Rich Presence: 활성 모드팩, 서버 IP/이름 및 경과된 게임 시간을 브로드캐스트합니다.
  • 백그라운드 스로틀링: Minecraft에 시스템 RAM의 100%를 제공하기 위해 게임플레이 중에 런처 UI를 일시 중지합니다.

활성 인터넷 연결 없이 어디서나 플레이하세요. 기존 싱글플레이 월드를 가져오고, 사용자 지정 RAM을 할당하며, 모드팩을 격리하세요.

클라이언트 측 서버 튜닝

동기화를 손상시키지 않고 모든 서버 인스턴스에 자체 옵션 클라이언트 모드, 셰이더, 리소스 팩 및 키 바인딩을 추가하세요.

다중 서버 관리, 수면 중 RAM 절약, 단일 포트 실행.

Zircon 뒤의 셀프 호스팅 관리 엔진입니다. Docker 번거로움이 없고, 다중 포트 방화벽 악몽이 없습니다. 기술 지원 없이 플레이어가 실제로 연결할 수 있는 모드 서버를 실행하세요.

  • 단일 포트 멀티플렉싱 (25565): 게임 패킷과 REST 모드 매니페스트 모두 기본 포트 25565에서 실행됩니다. 포워딩할 포트는 1개뿐입니다.
  • 비어 있을 때 잠자기 (RAM 절약): 온라인 플레이어가 0명일 때 JVM 메모리를 CPU 0%로 동결하고, 플레이어가 핑을 보내면 밀리초 만에 부활합니다.
  • 통합 모드 상점: Modrinth 및 CurseForge에서 모드, 셰이더, 리소스 팩을 원클릭으로 직접 설치하세요.
  • 라이브 콘솔 & 플레이어 관리: 색상 지정된 터미널 로그, 즉각적인 명령 발송, 시각적 화이트리스트, OP 및 밴.
  • 자동 백업 & 월드 ZIP 가져오기: 사용자 지정 보존 기간, 원클릭 롤백 및 드래그 앤 드롭 월드 가져오기가 포함된 고속 LZ4 스냅샷.
  • 라이브 2D/3D 월드 맵: 브라우저에서 렌더링된 지형, 바이옴 및 라이브 플레이어 위치를 직접 탐색하세요.

CurseForge & Modrinth 동기화

Modrinth와 CurseForge에서 모드를 검색하고 다운로드하며, 모든 실행 시 SHA-512 및 지문 검사로 검증합니다. 누락되거나 오래된 것이 없습니다.

실제 계정으로 로그인

공식 Microsoft 로그인 — 비밀번호는 Microsoft로만 전달되며 Zircon에는 절대 전달되지 않습니다. 공용 로그인, 크랙 런처, 오프라인 우회 없음.

3D 스킨 & 커뮤니티 라이브러리

라이브 3D 미리보기, 공식 Mojang 클라우드 동기화 및 API를 통해 인기 스킨을 가져오는 앱 내 커뮤니티 스킨 탐색기가 포함된 저장된 스킨 선택기.

셰이더 & 팩, 자동 적용

서버는 자체 셰이더와 리소스 팩을 제공할 수 있습니다. Zircon은 참여 시 이를 적용합니다 — 한 번만 수락하면 됩니다.

솔로 모험도 가능합니다

자체 모드, 셰이더 및 텍스처 팩이 포함된 오프라인 싱글플레이 인스턴스를 생성하세요. 서버가 필요 없습니다 — 조용히 건축하세요.

Zircon은 Minecraft 모드를 어떻게 자동으로 동기화하나요?

서버에 참여하고 PLAY를 누르면, Zircon은 서버의 공개된 자재 목록(BOM) 매니페스트를 로컬 클라이언트 폴더와 비교합니다. 누락되거나 업데이트된 모드는 Modrinth & CurseForge SHA-512 해시 및 지문으로 검증된 후, 수동 파일 드래그 없이 병렬로 즉시 다운로드됩니다.

CurseForge, Prism 또는 Modrinth에서 인스턴스를 마이그레이션할 수 있나요?

예! Zircon에는 네이티브 원클릭 범용 마이그레이션 도구가 포함되어 있습니다. CurseForge, Prism Launcher, Modrinth App 및 ATLauncher에서 설치된 디렉터리를 자동으로 감지하여 완전한 인스턴스 트리, 저장 데이터, 키 바인딩 및 모드 구성을 2초 이내에 가져올 수 있습니다.

4인 분할 화면 소파 협동 플레이는 어떻게 작동하나요?

Zircon은 최대 4개의 게임패드(Xbox, PlayStation 또는 일반 Bluetooth 컨트롤러)를 연결하고 모니터나 TV에서 매끄러운 분할 화면 그리드로 배열된 여러 개의 격리된 게임 창을 실행할 수 있게 해줍니다. 각 플레이어는 자신의 게임패드로 자신의 캐릭터를 제어합니다.

CurseForge와 Modrinth를 사용하여 모드를 찾고 다운로드할 수 있나요?

예! Zircon은 API 키 구성 없이 Modrinth와 CurseForge에서 모드를 직접 검색, 설치 및 동기화하는 것을 네이티브로 지원합니다. 두 저장소 모두 박스 오픈 상태로 완전히 통합되어 있습니다.

Zircon은 무료이고 오픈 소스인가요?

예, Zircon은 Business Source License 1.1 (BSL 1.1) 하에 소스 이용 가능합니다. 클라이언트 런처와 셀프 호스팅 서버 관리자 모두 플레이어, 홈랩 사용자 및 게이밍 네트워크를 위해 100% 무료입니다. 전체 코드베이스는 GitHub에서 공개 검사, 셀프 호스팅 및 커뮤니티 기여를 위해 열려 있습니다.

내 Microsoft / Minecraft 계정은 안전한가요?

예. 인증은 기본 시스템 브라우저에서 표준 Microsoft OAuth 2.0 PKCE를 통해 수행됩니다. 로그인 자격 증명은 직접 Microsoft 로그인 서버로 전달되며 Zircon에 의해 절대 접근, 처리 또는 저장되지 않습니다.

어떤 모드 로더와 Minecraft 버전이 지원되나요?

Zircon은 Fabric, Quilt, Forge 및 NeoForge를 네이티브로 지원합니다. 런처는 인스턴스를 실행하거나 서버에 참여할 때 필요한 모드 로더 버전과 검증된 Adoptium Temurin Java 런타임을 자동으로 설치합니다.

실제로 플레이할 준비가 되셨나요?

무료 오픈 소스 런처를 다운로드하거나 셀프 호스팅 서버 관리자를 받으세요.
