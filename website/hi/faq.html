अक्सर पूछे जाने वाले प्रश्न

Zircon Launcher, Server Manager, मॉड सिंक और सुरक्षा के बारे में आपको जो कुछ भी जानने की जरूरत है।

Zircon Minecraft मॉड्स को स्वचालित रूप से कैसे सिंक करता है?

जब आप एक सर्वर चुनते हैं और PLAY दबाते हैं, तो Zircon Launcher सर्वर से कनेक्ट होता है और उसका क्रिप्टोग्राफिक मॉड मैनिफेस्ट (BOM) प्राप्त करता है। यह इसे आपके स्थानीय इंस्टेंस फ़ोल्डर से तुलना करता है, आधिकारिक रिपॉज़िटरीज़ के खिलाफ SHA-512 हैश और CurseForge फिंगरप्रिंट्स को सत्यापित करता है, और किसी भी गुम या अपडेट किए गए मॉड्स को स्वचालित रूप से डाउनलोड करता है।

क्या मैं मॉड्स खोजने और डाउनलोड करने के लिए CurseForge या Modrinth का उपयोग कर सकता हूँ?

हाँ! Zircon शून्य API कुंजी आवश्यकता के साथ दोनों Modrinth और CurseForge को नेटिवली सपोर्ट करता है। चाहे आप Server Manager में एक इंस्टेंस कॉन्फ़िगर कर रहे हों या सर्वर पर खेल रहे हों, दोनों रिपॉज़िटरीज़ के मॉड्स स्वचालित हैश सत्यापन के साथ सहजता से संभाले जाते हैं।

क्या मैं सिंगल-प्लेयर ऑफ़लाइन इंस्टेंस बना सकता हूँ?

हाँ। लॉन्चर में एक पूर्ण ऑफ़लाइन इंस्टेंस मैनेजर शामिल है। आप Minecraft संस्करण (1.16 से नवीनतम), मॉड लोडर (Fabric, Quilt, Forge, NeoForge), कस्टम RAM आवंटन और स्थानीय मॉड्स की पसंद के साथ स्थानीय सिंगल-प्लेयर इंस्टेंस बना सकते हैं।

Skin Customizer और Community Skin Library कैसे काम करते हैं?

स्किन सिलेक्टर आपको सहेजे गए स्किन्स में से चुनने या एक कस्टम PNG अपलोड करने, Steve और Alex ज्यामिति विकल्पों के साथ लाइव घूमने वाले 3D में अपने चरित्र का पूर्वावलोकन करने और Mojang के साथ सीधे सिंक करने देता है। इसके अतिरिक्त, Community Skin Library आपको API के माध्यम से लाइव प्राप्त हजारों ट्रेंडिंग कम्युनिटी स्किन्स को ब्राउज़ करने और एक क्लिक के साथ उन्हें लागू करने देती है।

सिंगल-पोर्ट मल्टीप्लेक्सिंग कैसे काम करता है?

Zircon Server Manager मानक Minecraft गेम ट्रैफिक (पोर्ट 25565) और HTTP REST मॉड मैनिफेस्ट ट्रैफिक दोनों को एक ही सिंगल पोर्ट पर मल्टीप्लेक्स करता है। खिलाड़ी बस अपना सर्वर पता एक बार दर्ज करते हैं (उदाहरण के लिए play.example.com) और लॉन्चर मॉड मैनिफेस्ट प्राप्त करता है और बिना द्वितीयक पोर्ट्स की आवश्यकता के पोर्ट 25565 पर गेम कनेक्ट करता है।

क्या मैं Admin Web Dashboard तक कैसे पहुँच सकता हूँ?

जब आप सर्वर मैनेजर शुरू करते हैं, तो एक एडमिन पासवर्ड जनरेट किया जाता है और आपके कंसोल पर प्रिंट होता है। लॉग इन करने के लिए अपने ब्राउज़र को खोलें और http://localhost:25564 (या अपनी प्राइवेट IP) पर नेविगेट करें। सुरक्षा के लिए, पोर्ट 25564 को लोकल रखें या VPN/रिवर्स प्रॉक्सी के पीछे रखें।

सर्वर स्लीप/वेक मोड कैसे काम करता है?

जब सभी खिलाड़ी सर्वर छोड़ देते हैं, तो Zircon CPU और RAM की बचत करने के लिए Minecraft सर्वर प्रोसेस को सुचारू रूप से रोक देता है। जब कोई भी खिलाड़ी अपने लॉन्चर में PLAY क्लिक करता है, तो एक प्री-जॉइन इंटेंट खिलाड़ी के गेम में प्रवेश करने से पहले सर्वर को जगा देता है।

क्या मुझे Modrinth या CurseForge के लिए API कुंजी की आवश्यकता है?

नहीं। Modrinth और CurseForge दोनों समर्थन पूर्व-कॉन्फ़िगर हैं और सीधे Zircon में बंडल हैं। सर्वर ओनर्स और खिलाड़ी तुरंत दोनों प्लेटफ़ॉर्म से मॉड्स को खोज, डाउनलोड और सिंक कर सकते हैं, शून्य API कुंजी या मैनुअल सेटअप की आवश्यकता के बिना।

क्या वहां मैनेज्ड क्लाउड होस्टिंग (Zircon Cloud) होगी?

हाँ, हमारे भविष्य के रोडमैप पर प्रोप्राइटरी Pause-to-Sleep रिटेंशन के साथ मैनेज्ड जीरो-हार्डवेयर होस्टिंग की योजना है। आज, Zircon Launcher और सेल्फ-होस्टेड Server Manager 100% मुफ्त, सोर्स-एवेलेबल हैं और आपके अपने PC, होमलैब, या VPS पर शून्य लागत पर चलाने के लिए तैयार हैं।

क्या मेरा Microsoft Minecraft खाता सुरक्षित है?

हाँ। प्रमाणीकरण आपके सिस्टम वेब ब्राउज़र में मानक Microsoft OAuth 2.0 PKCE के माध्यम से किया जाता है। आपकी क्रेडेंशियल्स सीधे Microsoft लॉगिन सर्वर्स को सबमिट की जाती हैं। Zircon कभी भी आपके Microsoft पासवर्ड को नहीं देखता, संभालता या स्टोर करता है।

क्या Zircon मुफ्त और ओपन सोर्स है?

हाँ, Zircon Business Source License 1.1 (BSL 1.1) के तहत मुफ्त और सोर्स-एवेलेबल है। पूरा कोडबेस (साथी लॉन्चर और सेल्फ-होस्टेड सर्वर मैनेजर) GitHub पर सार्वजनिक निरीक्षण, ऑडिटिंग और व्यक्तिगत/समुदाय डिप्लॉयमेंट के लिए उपलब्ध है।

क्या डाउनलोड किए गए मॉड्स सुरक्षा के लिए सत्यापित होते हैं?

हाँ। मॉड फ़ाइलों को आधिकारिक Modrinth और CurseForge APIs के खिलाफ SHA-512 क्रिप्टोग्राफिक हैश और CurseForge murmur2 फिंगरप्रिंट्स का उपयोग करके सत्यापित किया जाता है, इससे पहले कि उन्हें आपके सक्रिय इंस्टेंस फ़ोल्डर में कभी भी रखा जाए।

Windows SmartScreen कहता है "Windows ने आपके PC की सुरक्षा की" — मुझे क्या करना चाहिए?

यह नए ओपन-सोर्स सॉफ्टवेयर के लिए मानक है जिसने अभी तक Microsoft SmartScreen सर्टिफिकेट प्रतिष्ठा नहीं बनाई है। More info पर क्लिक करें और फिर Run anyway पर क्लिक करें। आप पारदर्शिता के लिए GitHub पर पूरा सोर्स कोड भी जांच सकते हैं।

क्या मुझे Java को मैनुअली इंस्टॉल करना होगा?

नहीं। Zircon अपने आप आपके सिस्टम Java का पता लगाता है, और यदि एक आवश्यक संस्करण (उदाहरण के लिए Java 17 या Java 21) गुम है, तो यह Adoptium से सत्यापित Eclipse Temurin JDK को स्वचालित रूप से डाउनलोड और कैश करता है।

मैं मॉडेड Minecraft को अधिक RAM कैसे आवंटित करूं?

Zircon Launcher में, साइडबार में Settings आइकन पर क्लिक करें। आवंटित RAM को समायोजित करने के लिए मेमोरी आवंटन स्लाइडर का उपयोग करें (मध्यम से बड़े मॉडपैक्स के लिए 4 GB से 8 GB अनुशंसित है)।

अभी भी आपके पास प्रश्न हैं?

हमारे स्टेप-बाय-स्टेप डॉक्यूमेंटेशन गाइड्स देखें या GitHub पर ओपन-सोर्स कम्युनिटी में शामिल हों।
