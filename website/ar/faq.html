المساعدة وقاعدة المعرفة

الأسئلة الشائعة

كل ما تحتاج معرفته حول Zircon Launcher، ومدير الخادم، ومزامنة التعديلات، والأمان.

كيف يقوم Zircon بمزامنة تعديلات Minecraft تلقائيًا؟

عند اختيار خادم والنقر على PLAY، يتصل Zircon Launcher بالخادم ويستعيد قائمة التعديلات المشفرة (BOM). ويقارنها مع مجلد النسخة المحلية لديك، ويتحقق من تجزئات SHA-512 وبصمات أصابع CurseForge مقابل المستودعات الرسمية، ثم يقوم بتنزيل أي تعديلات مفقودة أو محدثة تلقائيًا.

هل يمكنني استخدام CurseForge أو Modrinth للبحث عن التعديلات وتنزيلها؟

نعم! يدعم Zircon بشكل أصلي كلًا من Modrinth وCurseForge دون الحاجة إلى أي مفاتيح API. سواء كنت تقوم بإعداد نسخة في مدير الخادم أو تلعب على خادم، يتم التعامل مع التعديلات من كلا المنصتين بسلاسة مع التحقق التلقائي من التجزئة.

هل يمكنني إنشاء نسخ فردية غير متصلة بالإنترنت؟

نعم. يتضمن المشغّل مدير نسخ غير متصل كاملًا. يمكنك إنشاء نسخ فردية محلية مع خيار إصدار Minecraft (من 1.16 حتى الإصدار الأحدث)، ومحمّل التعديلات (Fabric، Quilt، Forge، NeoForge)، وتخصيص ذاكرة RAM، والتعديلات المحلية.

كيف يعمل مخصص السكين ومكتبة السكين المجتمعية؟

يتيح لك محدد السكين الاختيار من بين السكين المحفوظة أو تحميل ملف PNG مخصص، ومعاينة شخصيتك في عرض ثلاثي الأبعاد دوّار مباشر (مع خيارات هندسة Steve وAlex)، والمزامنة مباشرة مع Mojang. بالإضافة إلى ذلك، تتيح لك مكتبة السكين المجتمعية تصفح آلاف السكين الرائجة للمجتمع التي يتم جلبها مباشرة عبر API وتطبيقها بنقرة واحدة.

كيف يعمل تعدد الإشارات على منفذ واحد؟

يقوم Zircon Server Manager بتعدد إشارات لعب Minecraft القياسية (المنفذ 25565) وإشارات HTTP REST لقائمة التعديلات على نفس المنفذ الواحد. يدخل اللاعبون ببساطة عنوان خادمك مرة واحدة (مثل play.example.com) ويقوم المشغّل بجلب قائمة التعديلات والاتصال باللعب عبر المنفذ 25565 دون الحاجة إلى منافذ ثانوية.

كيف أصل إلى لوحة التحكم الإدارية عبر الويب؟

عند بدء تشغيل مدير الخادم، يتم توليد كلمة مرور إدارية وطباعتها في وحدة التحكم الخاصة بك. افتح متصفحك وانتقل إلى http://localhost:25564 (أو عنوان IP الخاص بك) لتسجيل الدخول. للأمان، حافظ على المنفذ 25564 محليًا أو خلف VPN/وكيل عكسي.

كيف يعمل وضع النوم/الاستيقاظ للخادم؟

عندما يغادر جميع اللاعبين الخادم، يقوم Zircon بإيقاف عملية خادم Minecraft بلطف للحفاظ على CPU وRAM. عندما ينقر أي لاعب على PLAY في مشغله، يتم إيقاظ الخادم مسبقًا قبل دخول اللاعب إلى اللعبة.

هل أحتاج إلى مفتاح API لـ Modrinth أو CurseForge؟

لا. دعم كل من Modrinth وCurseForge مُهيأ مسبقًا ومدمج مباشرة في Zircon. يمكن لمالكي الخوادم واللاعبين البحث عن التعديلات وتنزيلها ومزامنتها من كلا المنصتين فورًا دون الحاجة إلى مفاتيح API أو إعداد يدوي.

هل سيكون هناك استضافة سحابية مُدارة (Zircon Cloud)؟

نعم، الاستضافة المُدارة بدون أجهزة مع تقنية الاحتفاظ بالنوم المملوكة لنا مخطط لها في خارطة طريقنا المستقبلية. اليوم، Zircon Launcher ومدير الخادم المستضاف ذاتيًا مجانيان 100% ومتاحان كمصدر مفتوح، وجاهزان لتشغيلهما على جهاز الكمبيوتر الشخصي الخاص بك، أو مختبر المنزل، أو VPS بتكلفة صفرية.

هل حساب Microsoft Minecraft الخاص بي آمن؟

نعم. يتم إجراء المصادقة عبر Microsoft OAuth 2.0 PKCE القياسي في متصفح الويب الخاص بنظامك. يتم إرسال بيانات اعتمادك مباشرة إلى خوادم تسجيل الدخول من Microsoft. لا يرى Zircon أبدًا كلمة مرور Microsoft الخاصة بك ولا يتعامل معها أو يخزنها.

هل Zircon مجاني ومفتوح المصدر؟

نعم، Zircon مجاني ومتاح كمصدر تحت رخصة Business Source License 1.1 (BSL 1.1). قاعدة البيانات الكاملة (المشغّل المرافق ومدير الخادم المستضاف ذاتيًا) متاحة للفحص العام، والتدقيق، والنشر الشخصي/المجتمعي على GitHub.

هل يتم التحقق من سلامة التعديلات المنزلة؟

نعم. يتم التحقق من ملفات التعديل باستخدام تجزئات تشفير SHA-512 وبصمات أصابع murmur2 من CurseForge مقابل واجهات برمجة التطبيقات الرسمية لـ Modrinth وCurseForge قبل وضعها في مجلد نسختك النشطة.

تقول Windows SmartScreen "قامت Windows بحماية جهازك" — ماذا يجب أن أفعل؟

هذا أمر قياسي للبرمجيات مفتوحة المصدر الجديدة التي لم تبني بعد سمعة شهادة Windows SmartScreen. انقر على مزيد من المعلومات ثم انقر على تشغيل على أي حال. يمكنك أيضًا فحص الكود المصدري الكامل على GitHub للشفافية.

هل أحتاج إلى تثبيت Java يدويًا؟

لا. يكتشف Zircon تلقائيًا Java النظام الخاص بك، وإذا كانت الإصدار المطلوب (مثل Java 17 أو Java 21) مفقودًا، فإنه يقوم بتنزيل وتخزين Eclipse Temurin JDK المتحقق منه من Adoptium تلقائيًا.

كيف أقوم بتخصيص المزيد من RAM لـ Minecraft المعدّل؟

في Zircon Launcher، انقر على أيقونة الإعدادات في الشريط الجانبي. استخدم شريط تمرير تخصيص الذاكرة لضبط RAM المخصصة (يوصى بـ 4 جيجابايت إلى 8 جيجابايت لحزم التعديلات المتوسطة إلى الكبيرة).

لا تزال لديك أسئلة؟

اطلع على أدلة التوثيق خطوة بخطوة لدينا أو انضم إلى المجتمع مفتوح المصدر على GitHub.
