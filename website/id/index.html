Penyesuaian Server Sisi Klien

Tambahkan mod klien opsional, shader, resource pack, dan keybinding milik Anda sendiri ke instance server mana pun tanpa merusak sinkronisasi.

Kelola banyak server, hemat RAM saat Anda tidur, dan jalankan pada satu port.

Mesin manajemen self-hosted di balik Zircon. Tidak ada sakit kepala Docker, tidak ada mimpi buruk firewall multi-port. Jalankan server modded yang bisa benar-benar terhubung oleh pemain Anda tanpa dukungan teknis.

  • Multiplexing Port Tunggal (25565): Paket game dan manifest mod REST keduanya berjalan di port default 25565. Hanya 1 port untuk diteruskan.
  • Tidur-Saat-Kosong (Penghemat RAM): Membekukan memori JVM ke CPU 0% ketika 0 pemain online; hidup kembali dalam milidetik ketika pemain ping.
  • Toko Mod Terintegrasi: Instal mod, shader, dan resource pack 1-klik langsung dari Modrinth dan CurseForge.
  • Konsol & Manajemen Pemain Langsung: Log terminal berwarna, pengiriman perintah instan, whitelist visual, OP, dan ban.
  • Cadangan Otomatis & Impor ZIP Dunia: Snapshot LZ4 kecepatan tinggi dengan retensi kustom, rollback 1-klik, dan impor dunia seret-dan-lepas.
  • Peta Dunia 2D/3D Langsung: Jelajahi medan yang dirender, bioma, dan lokasi pemain langsung di browser Anda.

Pertanyaan yang Sering Diajukan

Semua yang perlu Anda ketahui tentang memulai dengan Zircon.

Bagaimana Zircon secara otomatis menyinkronkan mod Minecraft?

Ketika Anda bergabung ke server dan menekan MAIN, Zircon membandingkan manifest Bill of Materials yang diterbitkan server terhadap folder klien lokal Anda. Mod yang hilang atau diperbarui diverifikasi melalui hash SHA-512 dan fingerprint Modrinth & CurseForge, lalu diunduh seketika secara paralel tanpa seret file manual.

Bisakah saya memigrasikan instance saya dari CurseForge, Prism, atau Modrinth?

Ya! Zircon mencakup alat Migrasi Universal 1-klik native. Ini secara otomatis mendeteksi direktori terinstal dari CurseForge, Prism Launcher, Modrinth App, dan ATLauncher, memungkinkan Anda mengimpor struktur instance lengkap, simpanan, keybind, dan konfigurasi mod dalam waktu kurang dari dua detik.

Bagaimana Co-op Sofa Layar Terpisah 4-Pemain bekerja?

Zircon memungkinkan Anda menghubungkan hingga 4 gamepad (controller Xbox, PlayStation, atau Bluetooth generik) dan meluncurkan beberapa jendela game terisolasi yang diatur ke dalam grid layar terpisah mulus di monitor atau TV Anda. Setiap pemain mengendalikan karakter mereka sendiri dengan gamepad mereka sendiri.

Bisakah saya menggunakan CurseForge dan Modrinth untuk mencari dan mengunduh mod?

Ya! Zircon secara native mendukung pencarian, instalasi, dan sinkronisasi mod langsung dari kedua repositori Modrinth dan CurseForge tanpa perlu konfigurasi API key. Kedua repositori terintegrasi sepenuhnya sejak awal.

Apakah Zircon gratis dan sumber terbuka?

Ya, Zircon tersedia sumbernya di bawah Business Source License 1.1 (BSL 1.1). Baik launcher klien maupun manajer server self-hosted 100% gratis untuk pemain, homelabbers, dan jaringan gaming. Seluruh basis kode terbuka untuk inspeksi publik, self-hosting, dan kontribusi komunitas di GitHub.

Apakah akun Microsoft / Minecraft saya aman?

Ya. Autentikasi dilakukan melalui Microsoft OAuth 2.0 PKCE standar di browser sistem default Anda. Kredensial login Anda pergi langsung ke server login Microsoft dan tidak pernah diakses, ditangani, atau disimpan oleh Zircon.

Loader mod dan versi Minecraft apa yang didukung?

Zircon secara native mendukung Fabric, Quilt, Forge, dan NeoForge. Launcher secara otomatis menginstal versi mod loader yang diperlukan dan runtime Java Adoptium Temurin terverifikasi ketika Anda meluncurkan instance atau bergabung ke server.
