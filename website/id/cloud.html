Dirancang untuk Multiplayer Tanpa Hambatan

Segala hal yang diperlukan untuk menjalankan komunitas modded berkinerja tinggi tanpa keahlian sysadmin Linux.

Retensi Pause-to-Sleep

Hosting tradisional membakar uang dengan menjalankan dunia kosong 24/7. Zircon Cloud menangguhkan loop game ketika 0 pemain online, melanjutkan dengan mulus saat pemain terhubung dengan 100% data chunk utuh.

Diagnostik Crash Zirky AI

Didukung oleh DeepSeek-V4-Flash. Ketika server crash karena mod tidak kompatibel atau library hilang, Zirky mengurai stack trace dan menghasilkan kartu perbaikan 1-klik langsung di konsol Anda.

Modrinth & CurseForge Dalam Browser

Cari dan instal lebih dari 100.000 mod, modpack, shader, dan resource pack langsung di panel kontrol web Anda. Tidak perlu transfer file FTP manual atau mencari jar.

Enterprise DDoS Edge Scrubbing

Semua lalu lintas Minecraft masuk dan telemetri web dirutekan melalui node scrubbing edge redundan, memfilter serangan volumetrik dan paket buruk sebelum mencapai kontainer dunia Anda.

Multiplexing Port Tunggal

Gameplay Minecraft (25565) dan REST manifest API berbagi port yang sama persis. Pemain terhubung ke domain bersih seperti yourserver.zirconmc.net tanpa memerlukan nomor port.

Snapshot Cloud LZ4 Otomatis

Backup dunia terkompresi LZ4 kecepatan tinggi berjalan sesuai jadwal tanpa stutter game. Pulihkan checkpoint sebelumnya dengan satu klik jika terjadi bencana.

FAQ Zircon Cloud

Pertanyaan yang sering diajukan tentang hosting Zircon terkelola.

Bagaimana cara kerja retensi Pause-to-Sleep?

Ketika pemain terakhir memutuskan koneksi dari server Anda, Zircon Cloud memulai hitungan mundur idle 15 menit secara halus. Jika tidak ada pemain yang bergabung, kontainer game ditangguhkan (Pause-to-Sleep). Semua status chunk, entitas, dan inventaris disimpan ke disk. Ketika pemain mengklik PLAY di Zircon Launcher, proxy edge kami membangunkan instance secara mulus untuk pemain Anda.

Apakah teman saya harus membayar sesuatu untuk terhubung?

Tidak. Terhubung ke server Zircon Cloud menggunakan Zircon Launcher adalah 100% gratis selamanya. Pemain mengunduh launcher klien, masuk dengan akun Microsoft resmi mereka, dan klik join.

Bisakah saya mengunggah dunia atau modpack saya yang sudah ada?

Ya! Zircon Cloud memiliki manajer file web terintegrasi dan pengunggah zip. Anda dapat memasukkan save dunia yang sudah ada, mengimpor zip modpack CurseForge/Modrinth, atau bermigrasi langsung dari server Zircon self-host lokal dengan 1 klik.

Loader dan versi Minecraft apa saja yang didukung?

Zircon Cloud mendukung Fabric, Quilt, NeoForge, dan Forge mulai dari Minecraft 1.7 hingga rilis modern terbaru. Instance Clean Vanilla dan Paper/Purpur juga sepenuhnya didukung.
