Tulong & Knowledge Base

Mga Madalas Itanong (FAQ)

Lahat ng kailangan mong malaman tungkol sa Zircon Launcher, Server Manager, mod sync, at security.

Paano awtomatikong na-sync ng Zircon ang mga Minecraft mods?

Kapag pinili mo ang isang server at pindutin ang PLAY, konektado ang Zircon Launcher sa server at kinukuha nito ang cryptographic mod manifest (BOM). Ikinukumpara nito ito sa iyong local instance folder, binibigyang-katiyakan ang SHA-512 hashes at CurseForge fingerprints laban sa mga opisyal na repositories, at awtomatikong dinadaownload ang anumang nawawalang o updated na mods.

Maaari ko bang gamitin ang CurseForge o Modrinth upang hanapin at i-download ang mga mods?

Oo! Suportado ng Zircon ang parehong Modrinth at CurseForge nang walang kinakailangang API keys. Kahit nagko-configure ka ng instance sa Server Manager o naglalaro sa isang server, ang mga mods mula sa parehong repositories ay hinarap nang maayos kasama ang automatic hash verification.

Maaari ko bang gumawa ng single-player offline instances?

Oo. Kasama sa launcher ang buong offline instance manager. Maaari kang gumawa ng lokal na single-player instances na may pagpili ng bersyon ng Minecraft (1.16 hanggang sa pinakabago), mod loader (Fabric, Quilt, Forge, NeoForge), custom RAM allocation, at mga lokal na mods.

Paano gumagana ang Skin Customizer at Community Skin Library?

Pinapayagan ka ng skin selector na pumili mula sa mga nakasaved na skins o mag-upload ng custom PNG, tingnan ang preview ng iyong character sa live rotating 3D (may Steve at Alex geometry options), at i-sync direkta sa Mojang. Bukod dito, pinapayagan ka ng Community Skin Library na mag-browse ng libu-libong trending community skins na kinukuha live via API at i-apply ang mga ito sa isang click.

Paano gumagana ang single-port multiplexing?

Ang Zircon Server Manager ay nag-multiplex ng parehong standard Minecraft game traffic (port 25565) at HTTP REST mod manifest traffic sa iisang port. Sapat na ipasok ng mga manlalaro ang address ng iyong server nang isang beses (hal. play.example.com) at kukunin ng launcher ang mod manifest at ikonekta ang laro sa port 25565 nang hindi nangangailangan ng secondary ports.

Paano ko ma-access ang Admin Web Dashboard?

Kapag sinimulan mo ang server manager, isang admin password ang gagawin at ipapakita sa iyong console. Buksan ang iyong browser at puntahan ang http://localhost:25564 (o ang iyong private IP) upang mag-log in. Para sa seguridad, panatilihing local ang port 25564 o likod ng VPN/reverse proxy.

Paano gumagana ang server sleep/wake mode?

Kapag umalis na ang lahat ng manlalaro sa server, tahimik na pinipigilan ng Zircon ang proseso ng Minecraft server upang makatipid ng CPU at RAM. Kapag may manlalarong nag-click ng PLAY sa kanilang launcher, ginigising ang server bago pa man pumasok ang manlalaro sa laro.

Kailangan ko ba ng API key para sa Modrinth o CurseForge?

Hindi. Ang suporta para sa parehong Modrinth at CurseForge ay pre-configured at direktang kasama sa Zircon. Maaaring hanapin, i-download, at i-sync ng mga may-ari ng server at manlalaro ang mga mods mula sa parehong platforms agad-agad nang walang kinakailangang API keys o manual setup.

Magkakaroon ba ng managed cloud hosting (Zircon Cloud)?

Oo, ang managed zero-hardware hosting na may proprietary Pause-to-Sleep retention ay nakaplano sa aming future roadmap. Sa ngayon, ang Zircon Launcher at self-hosted Server Manager ay 100% libre, source-available, at handa para i-run mo sa iyong sariling PC, homelab, o VPS nang walang bayad.

Ligtas ba ang aking Microsoft Minecraft account?

Oo. Ang authentication ay ginagawa sa pamamagitan ng standard Microsoft OAuth 2.0 PKCE sa iyong system web browser. Direkta ibinibigay ang iyong credentials sa Microsoft login servers. Hindi kailanman nakikita, hinahawakan, o iniimbak ng Zircon ang iyong Microsoft password.

Libre at open source ba ang Zircon?

Oo, ang Zircon ay libre at source-available sa ilalim ng Business Source License 1.1 (BSL 1.1). Ang buong codebase (companion launcher at self-hosted server manager) ay available para sa public inspection, auditing, at personal/community deployment sa GitHub.

Binibigyang-katiyakan ba ang safety ng mga downloaded mods?

Oo. Binibigyang-katiyakan ang mga file ng mod gamit ang SHA-512 cryptographic hashes at CurseForge murmur2 fingerprints laban sa opisyal na Modrinth at CurseForge APIs bago pa man ilagay ang mga ito sa iyong aktibo na instance folder.

Sinasabi ng Windows SmartScreen na "Windows protected your PC" — ano ang dapat kong gawin?

Ito ay karaniwan para sa bagong open-source software na hindi pa nagtatayo ng Microsoft SmartScreen certificate reputation. Pindutin ang More info at pagkatapos ay pindutin ang Run anyway. Maaari mo ring suriin ang buong source code sa GitHub para sa transparency.

Kailangan ko bang i-install ang Java manually?

Hindi. Awtomatikong nadetect ng Zircon ang iyong system Java, at kung kulang ang kinakailangang bersyon (hal. Java 17 o Java 21), awtomatikong dinadaownload at ini-cache ang verified Eclipse Temurin JDK mula sa Adoptium.

Paano ko ia-allocate ang mas maraming RAM para sa modded Minecraft?

Sa Zircon Launcher, pindutin ang Settings icon sa sidebar. Gamitin ang memory allocation slider upang i-adjust ang allocated RAM (4 GB hanggang 8 GB ang recommended para sa medium-to-large modpacks).

May iba pang tanong?

Tingnan ang aming step-by-step documentation guides o sumali sa open-source community sa GitHub.
