Client-Side Server Tweaks

Idagdag ang iyong own optional client mods, shaders, resource packs, at keybindings sa anumang server instance nang hindi sinisira ang synchronization.

Pamahalaan ang maraming servers, i-save ang RAM habang natutulog, at mag-run sa isang port.

Ang self-hosted management engine sa likod ng Zircon. Walang Docker headaches, walang multi-port firewall nightmare. Patakbuhin ang modded servers na talagang makakakonekta ng mga players nang walang tech support.

  • Single-Port Multiplexing (25565): Ang game packets at REST mod manifests ay parehong tumatakbo sa default port 25565. Isang port lang ang kailangang i-forward.
  • Sleep-When-Empty (RAM Saver): Pinipigilan ang JVM memory sa 0% CPU kapag 0 players ang online; binubuhay sa loob ng milliseconds kapag may nag-ping.
  • Integrated Mod Store: 1-click install mods, shaders, at resource packs direkta mula sa Modrinth and CurseForge.
  • Live Console & Player Management: Colorized terminal logs, instant command dispatch, visual whitelists, OPs, at bans.
  • Auto-Backups & World ZIP Import: High-speed LZ4 snapshots na may custom retention, 1-click rollback, at drag-and-drop world import.
  • Live 2D/3D World Map: Galugarin ang rendered terrain, biomes, at live player locations direkta sa iyong browser.

Frequently Asked Questions

Lahat ng kailangan mong malaman tungkol sa pagsisimula sa Zircon.

Paano awtomatikong sini-sync ng Zircon ang Minecraft mods?

Kapag sumali ka sa server at pinindot ang PLAY, ini-compare ng Zircon ang published Bill of Materials manifest ng server laban sa iyong lokal na client folder. Ang anumang kulang o updated na mods ay v-verify via Modrinth & CurseForge SHA-512 hashes at fingerprints, pagkatapos ay ididownload agad nang parallel nang walang manual na pag-drag ng file.

Maaari ko bang i-migrate ang aking instances mula sa CurseForge, Prism, o Modrinth?

Oo! Kasama sa Zircon ang native 1-click Universal Migration tool. Awtomatikong nadetect nito ang installed directories mula sa CurseForge, Prism Launcher, Modrinth App, at ATLauncher, kaya maaari mong i-import ang iyong complete instance trees, saves, keybinds, at mod configurations sa loob ng dalawang segundo.

Paano gumagana ang 4-Player Split-Screen Couch Co-op?

Pinapayagan ka ng Zircon na kumonekta ng hanggang 4 gamepads (Xbox, PlayStation, o generic Bluetooth controllers) at mag-launch ng maraming isolated game windows na inayos sa seamless split-screen grid sa iyong monitor o TV. Kontrolado ng bawat player ang sarili nilang character gamit ang sarili nilang gamepad.

Maaari ko bang gamitin ang CurseForge at Modrinth upang hanapin at i-download ang mods?

Oo! Suportado ng Zircon ang native searching, installing, at synchronizing ng mods direkta mula sa parehong Modrinth at CurseForge nang walang kailangang API key configuration. Parehong repositories ay fully integrated out of the box.

Libre at open source ba ang Zircon?

Oo, ang Zircon ay source-available sa ilalim ng Business Source License 1.1 (BSL 1.1). Parehong client launcher at self-hosted server manager ay 100% libre para sa players, homelabbers, at gaming networks. Ang buong codebase ay bukas para sa public inspection, self-hosting, at community contribution sa GitHub.

Ligtas ba ang aking Microsoft / Minecraft account?

Oo. Ang authentication ay ginagawa sa pamamagitan ng standard Microsoft OAuth 2.0 PKCE sa iyong default system browser. Ang iyong login credentials ay direkta napupunta sa Microsoft's login servers at hindi kailanman naa-access, hinahawakan, o iniimbak ng Zircon.

Anong mod loaders at Minecraft versions ang suportado?

Suportado ng Zircon ang native Fabric, Quilt, Forge, at NeoForge. Awtomatikong ini-install ng launcher ang kinakailangang mod loader version at verified Adoptium Temurin Java runtime kapag binuksan mo ang instance o sumali sa server.
