Často kladené otázky

Vše, co potřebujete vědět o Zircon Launcher, Správci serveru, synchronizaci modů a zabezpečení.

Jak Zircon automaticky synchronizuje mody Minecraft?

Když vyberete server a kliknete na HRÁT, Zircon Launcher se připojí k serveru a načte jeho kryptografický manifest modů (BOM). Porovná ho s vaší lokální složkou instance, ověří SHA-512 hashe a otisky prstů CurseForge proti oficiálním repozitářům a automaticky stáhne chybějící nebo aktualizované mody.

Mohu používat CurseForge nebo Modrinth pro hledání a stahování modů?

Ano! Zircon nativně podporuje jak Modrinth, tak CurseForge bez nutnosti API klíčů. Ať už konfigurujete instanci ve Správci serveru, nebo hrajete na serveru, mody z obou repozitářů jsou zpracovávány plynule s automatickým ověřením hashů.

Mohu vytvořit offline instance pro jednoho hráče?

Ano. Launcher obsahuje plnohodnotný správce offline instancí. Můžete vytvářet lokální instance pro jednoho hráče s volbou verze Minecraftu (od 1.16 po nejnovější), loaderu modů (Fabric, Quilt, Forge, NeoForge), vlastním přidělením RAM a lokálními mody.

Jak fungují Skin Customizer a Knihovna komunitních skinů?

Výběr skinu vám umožňuje vybrat si z uložených skinů nebo nahrát vlastní PNG, náhled postavy v živém rotujícím 3D (s možnostmi geometrie Steve a Alex) a přímo synchronizovat s Mojangem. Kromě toho Knihovna komunitních skinů umožňuje procházet tisíce trendových komunitních skinů načítaných živě přes API a aplikovat je jedním kliknutím.

Jak funguje multiplexování na jednom portu?

Zircon Server Manager multiplexuje standardní herní provoz Minecraftu (port 25565) i HTTP REST provoz manifestu modů na stejném jediném portu. Hráči jednoduše zadají adresu vašeho serveru jednou (např. play.example.com) a launcher načte manifest modů a připojí hru přes port 25565 bez nutnosti sekundárních portů.

Jak se dostanu do Admin Web Dashboardu?

Při spuštění správce serveru je vygenerováno heslo administrátora a vypsáno do konzole. Otevřete prohlížeč a přejděte na http://localhost:25564 (nebo vaše privátní IP) pro přihlášení. Pro bezpečnost udržujte port 25564 lokální nebo za VPN/reverzním proxy.

Jak funguje režim spánku/buzení serveru?

Když všichni hráči opustí server, Zircon elegantně pozastaví proces serveru Minecraft, aby šetřil CPU a RAM. Když kterýkoli hráč klikne v launcheru na HRÁT, před-připojovací úmysl probudí server ještě před vstupem hráče do hry.

Potřebuji API klíč pro Modrinth nebo CurseForge?

Ne. Podpora Modrinth i CurseForge je předkonfigurována a zabalená přímo v Zirconu. Vlastníci serverů a hráči mohou okamžitě vyhledávat, stahovat a synchronizovat mody z obou platforem bez nutnosti API klíčů nebo ručního nastavení.

Budou existovat spravované cloudové hostingy (Zircon Cloud)?

Ano, spravovaný hosting bez hardwaru s proprietární funkcí zachování stavu Pause-to-Sleep je plánován na našem budoucím roadmapu. Dnes jsou Zircon Launcher a self-hosted Server Manager 100% zdarma, zdrojově dostupné a připravené k běhu na vašem PC, home-labu nebo VPS bez nákladů.

Je můj účet Microsoft Minecraft v bezpečí?

Ano. Autentizace je prováděna prostřednictvím standardního Microsoft OAuth 2.0 PKCE ve vašem systémovém webovém prohlížeči. Vaše přihlašovací údaje jsou odesílány přímo na servery Microsoft login. Zircon nikdy nevidí, nezpracovává ani neukládá vaše heslo Microsoft.

Je Zircon zdarma a open source?

Ano, Zircon je zdarma a zdrojově dostupný pod licencí Business Source License 1.1 (BSL 1.1). Celý kód (spolupracující launcher a self-hosted server manager) je veřejně dostupný pro inspekci, audit a osobní/komunitní nasazení na GitHubu.

Jsou stažené mody ověřeny pro bezpečnost?

Ano. Soubory modů jsou ověřovány pomocí kryptografických hashů SHA-512 a otisků prstů murmur2 CurseForge proti oficiálním API Modrinth a CurseForge, než jsou umístěny do vaší aktivní složky instance.

Windows SmartScreen hlásí „Windows chránil váš počítač“ – co mám dělat?

To je standardní u nového open-source softwaru, který ještě nevybudoval reputaci certifikátu Microsoft SmartScreen. Klikněte na Další informace a poté na Spustit přesto. Pro transparentnost můžete také nahlédnout do celého zdrojového kódu na GitHubu.

Musím instalovat Javu ručně?

Ne. Zircon automaticky detekuje systémovou Javu a pokud chybí požadovaná verze (např. Java 17 nebo Java 21), automaticky stáhne a uloží do cache ověřený Eclipse Temurin JDK od Adoptium.

Jak přidělím více RAM pro modovaný Minecraft?

V Zircon Launcheru klikněte na ikonu Nastavení v postranním panelu. Použijte posuvník alokace paměti pro úpravu přidělené RAM (pro střední až velké modpacky se doporučuje 4 GB až 8 GB).
