Abi ja teadmistebaas

Korduma kippuvad küsimused

Kõik, mida pead teadma Zircon Launcher, Server Manager, modide sünkroniseerimise ja turvalisuse kohta.

Kuidas Zircon sünkroniseerib Minecrafti mode automaatselt?

Kui valid serveri ja vajutad MÄNGI, ühendub Zircon Launcher serveriga ja laadib selle krüptograafilise modide manifesti (BOM). See võrdleb seda sinu kohaliku instantsi kaustaga, kontrollib SHA-512 räsi ja CurseForge'i sõrmejälgi ametlikest hoidlatest ning laadib puuduvad või uuendatud modid automaatselt alla.

Kas saan kasutada CurseForge'i või Modrinthi modide leidmiseks ja allalaadimiseks?

Jah! Zircon toetab natuaalselt nii Modrinthi kui ka CurseForge'i ilma API-võtmeid nõudmata. Olgu tegemist instantsi seadistamisega Server Manageris või mängimisega serveril, mõlemast platvormist pärit modid töödeldakse sujuvalt koos automaatse räsi kontrolliga.

Kas saan luua üksikmängija offline-instantsse?

Jah. Käivitaja sisaldab täielikku offline-instantsi haldurit. Saad luua kohalikke üksikmängija instantse, valides Minecrafti versiooni (1.16 kuni uusim), modilaadija (Fabric, Quilt, Forge, NeoForge), kohandatud RAM-jaotuse ja kohalikud modid.

Kuidas Skin Customizer ja Community Skin Library töötavad?

Naha valija võimaldab valida salvestatud nahkadest või üles laadida kohandatud PNG, eelvaadata oma tegelast elavas pöörlevas 3D-s (Steve'i ja Alexi geomeetriavalikutega) ning sünkroniseerida otse Mojangiga. Lisaks võimaldab Community Skin Library sirvida tuhandeid populaarseid kogukonna nahku, mis hangitakse reaalajas API kaudu, ja rakendada neid ühe klõpsuga.

Kuidas ühe pordi multiplexing töötab?

Zircon Server Manager multiplexib nii standardset Minecrafti mänguliiklust (port 25565) kui ka HTTP REST modide manifestiliiklust samal ühel pordil. Mängijad sisestavad lihtsalt sinu serveri aadressi korra (nt play.example.com) ja käivitaja hangib modide manifesti ning ühendab mängu üle pordi 25565 ilma sekundaarseid porte nõudmata.

Kuidas pääsen ligi Admin Web Dashboardile?

Kui käivitatad serverihalduri, genereeritakse admin parool ja trükitsee sinu konsoolile. Ava brauser ja navigeerige aadressile http://localhost:25564 (või sinu privaatne IP) sisselogimiseks. Turvalisuse huvides hoia port 25564 lokaalne või VPN/reverse proxy taga.

Kuidas serveri sleep/wake režiim töötab?

Kui kõik mängijad lahkuvad serverist, peatab Zircon graatsiliselt Minecrafti serveriprotsessi CPU ja RAM säästmiseks. Kui mõni mängija klõpsab oma käivitajas MÄNGI, äratab pre-join intent serveri üles enne, kui mängija siseneb mängu.

Kas mul on vaja API-võtit Modrinthi või CurseForge'i jaoks?

Ei. Nii Modrinthi kui ka CurseForge'i tugi on eelseadistatud ja pakitud otse Zirconisse. Serveri omanikud ja mängijad saavad otsida, alla laadida ja sünkroniseerida mode mõlemalt platvormilt kohe, ilma et oleks vaja API-võtmeid või manuaalset seadistamist.

Kas tuleb hallatud pilvehosting (Zircon Cloud)?

Jah, hallatud zero-hardware hosting koos patenteeritud Pause-to-Sleep säilitamisega on planeeritud meie tulevases tegevuskavas. Täna on Zircon Launcher ja isehostitud Server Manager 100% tasuta, lähtekoodiga saadaval ja valmis jooksmaks sinu enda PC-l, homelabis või VPS-is nullkuluga.

Kas minu Microsofti Minecrafti konto on ohutu?

Jah. Autentimine toimub standardse Microsoft OAuth 2.0 PKCE kaudu sinu süsteemi veebibrauseris. Sinu volitused esitatakse otse Microsofti loginserveritele. Zircon ei näe, käsitle ega salvesta kunagi sinu Microsofti parooli.

Kas Zircon on tasuta ja avatud lähtekoodiga?

Jah, Zircon on tasuta ja lähtekoodiga saadaval Business Source License 1.1 (BSL 1.1) alusel. Kogu koodibaas (kaasaskantav käivitaja ja isehostitud serverihaldur) on avalikult vaadatav, auditeeritav ja personaalse/kogukonna deployimiseks saadaval GitHubis.

Kas allalaaditud modid verifitseeritakse ohutuse osas?

Jah. Modifailid verifitseeritakse kasutades SHA-512 krüptograafilisi räsi ja CurseForge murmur2 sõrmejälgi ametlike Modrinthi ja CurseForge'i API-de vastu enne, kui need paigutatakse sinu aktiivsesse instantsi kausta.

Windows SmartScreen ütleb "Windows protected your PC" — mida peaksin tegema?

See on tavapärane uue avatud lähtekoodiga tarkvara puhul, mis pole veel Microsoft SmartScreen sertifikaadi mainet kogunud. Klõpsa Rohem info ja seejärel klõpsa Käivita ikkagi. Saad lähtekoodi täielikult uurida GitHubis läbipaistvuse huvides.

Kas pean Java manuaalselt installima?

Ei. Zircon tuvastab automaatselt sinu süsteemi Java ja kui vajalik versioon (nt Java 17 või Java 21) puudub, laadib see automaatselt alla ja vahemällu salvestab verifitseeritud Eclipse Temurin JDK Adoptiumist.

Kuidas eraldada moditud Minecraftile rohkem RAM-i?

Zircon Launcheris klõpsa külgribal Seaded ikooni. Kasuta mälu jaotamise liblikat eraldatud RAM-i reguleerimiseks (keskmise-suure modipaki jaoks soovitatav 4 GB kuni 8 GB).
